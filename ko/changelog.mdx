  ## Kimi, DeepSeek, Antigravity

  **새로운 기능**

  - **Kimi**와 **DeepSeek**이 상태 탭, 상태 알림, 위젯에 추가되었습니다
  - **Kimi Code** 사용량을 위젯과 70%, 90%, 100% 알림으로 확인할 수 있습니다. **제공업체** 탭에서 연결하면 Nomo가 짧은 코드를 보여 주고, Kimi 로그인 페이지에서 그 코드를 승인하면 됩니다
  - Gemini 사용량이 **Antigravity**로 바뀌었습니다. Google Antigravity 할당량을 읽으며, 앱과 위젯 어디서나 Antigravity로 표시됩니다. 작은 사용량 위젯에서는 **Claude & GPT** 한도도 볼 수 있습니다. Gemini를 연결해 두었다면 다시 로그인하십시오
  - **설정 → 알림**의 각 제공업체에 스위치가 생겨, 그곳의 상태 알림을 한 번에 끄거나 다시 켤 수 있습니다
  - iPad와 iPhone Duo에서는 제공업체 탭과 세션 탭이 목록과 세부 정보를 나란히 보여 줍니다

  **개선**

  - 사용량 알림 행에도 상태 행처럼 제공업체 아이콘이 붙습니다
  - 환영 가이드에 계정을 연결하는 **사용량 추적** 페이지가 새로 생겼고, 알림에 붙어 있던 Beta 표시가 사라졌습니다

  **수정**

  - iPhone Duo의 좁고 세로로 긴 Dynamic Island에서 세션 아이콘이 가운데에 놓이고, 계속 올라가는 타이머 대신 짧은 시간 표시가 나옵니다
</Update>

  ## 사용량 위젯의 Grok Bot

  **새로운 기능**

  - Cursor 사용량 위젯에 움직이는 Grok 봇이 표시됩니다. 표정은 요금제 포함 사용량에 따라 바뀌어, 70%부터는 걱정하고, 100%에서는 고장 나고, 0%이거나 로그인하지 않았을 때는 잠듭니다
  - 기존 로고가 좋다면 위젯을 편집해 **Cursor 아이콘**을 **Cursor 로고**로 바꾸십시오

  **개선**

  - Cursor 사용량이 더 이상 월 단위 주기를 전제로 하지 않습니다. X Subscription 요금제는 포함 사용량을 주 단위로, 다른 요금제는 월 단위로 계산하며, 문구는 둘 다에 맞습니다
</Update>

  ## Cursor와 세션 중단

  **새로운 기능**

  - **Cursor**가 Claude Code, Codex, OpenCode에 이어 추가되었습니다 — Cursor 데스크톱 앱과 `cursor-agent`의 세션이 세션 탭과 Dynamic Island에 실시간으로 표시되며, Cursor가 붙인 채팅 제목과 모델이 함께 나옵니다. 이 버전에서는 읽기 전용입니다. 휴대폰에서는 지켜보고, 답은 컴퓨터에서 합니다. `bunx nomo-ai --cursor`로 설치합니다
  - 컴퓨터에 표시할 에이전트를 고를 수 있습니다 — 드로어의 **+** 버튼(**에이전트 선택**)으로 탭을 최대 세 개까지 고릅니다
  - 실행 중인 Claude Code 또는 Codex 턴을 휴대폰에서 멈출 수 있습니다 — 세션 행의 **Mac에서 열기** 옆에 있는 **중단**입니다. 턴만 멈추고 세션은 열린 채로 남습니다. Codex는 즉시, Claude Code는 다음 도구 호출에서 멈춥니다
  - 중단은 컴퓨터에 플러그인 **2.3.0**이 있어야 합니다 — Claude Code와 Codex 플러그인을 모두 업데이트하십시오
  - 중단은 **로컬 네트워크**가 켜져 있고 두 기기가 같은 네트워크에 있어야 합니다. 직접 연결로 전송되며 중계 서버는 거치지 않습니다
  - Cursor의 ‘Grok Bot’으로 설정한 위젯에 Cursor 로고 대신 움직이는 Grok 봇이 표시됩니다. 상태에 따라 밤에는 잠들고, 서비스가 느려지면 걱정하고, 장애 중에는 시무룩해집니다

  **개선**

  - Codex에서 Esc를 누르면 20초 뒤가 아니라 곧바로 휴대폰에 반영됩니다
  - 플러그인이 Codex Hook을 세 개 더 등록합니다. 업데이트한 뒤 Codex에서 `/hooks`를 실행해 새 항목을 신뢰하십시오 — 모두 열 개입니다
  - 위젯에 표시되는 Cursor 상태 글자를 조금 작게 바꿔, ‘심각한 장애’ 같은 긴 상태가 더 잘 들어갑니다

  **수정**

  - API 오류로 끝난 Claude Code 턴이 최대 30분 동안 **실행 중**으로 표시되던 문제. 이제 **완료**로 바뀝니다
  - 도구가 실패하면 Claude Code 세션이 이미 다음으로 넘어간 뒤에도 사용자를 기다리는 것으로 남을 수 있던 문제
  - 백그라운드 서브에이전트를 기다리는 Claude Code 세션이 너무 일찍 **완료**로 바뀌지 않고 계속 작업 중으로 표시됩니다
  - OpenCode 서브에이전트의 요청이 해당 세션에 표시되고, 답하는 즉시 세션이 작업 중으로 돌아갑니다
  - 연결이 느리면 턴 도중에 Dynamic Island가 **연결 끊김?**으로 멈출 수 있던 문제. 이제 플러그인이 전달되지 않은 내용을 다시 보내고, Mac이 세션이 살아 있음을 확인하면 세션 탭이 멈춘 Dynamic Island를 되살립니다
  - 상태 탭과 알림, 위젯이 xAI의 새 상태 페이지를 따릅니다. xAI의 API 중 하나로 설정한 위젯이 어느 것을 골라도 목록의 첫 번째 API를 표시하던 문제도 해결되었습니다
</Update>

  ## 더 다양해진 답변 방법

  **새로운 기능**

  - Claude Code의 계획을 승인하면서 그 뒤의 진행 방식까지 고를 수 있습니다 — 일반 승인만이 아니라 **승인 후 편집 자동 수락** 또는 **승인 후 자동 모드**를 선택합니다. Claude Code의 다른 요청에는 **승인 후 자동 모드로 전환**이 추가되었습니다
  - 목록에서 고르기만 하는 대신, **기타…**로 질문에 직접 답을 입력하고 **메모 추가**로 메모를 덧붙일 수 있습니다
  - 자유 입력 답변을 받는 Codex 질문에도 **기타…**가 표시됩니다
  - 미리 보기가 딸린 선택지는 고르면 목록 아래에 미리 보기가 표시됩니다
  - 위 기능은 모두 컴퓨터에 플러그인 **2.2.2**가 있어야 합니다 — 그 전까지는 앱이 숨겨 둡니다
  - 한도가 100%에 도달하면 사용량 탭이 해당 제공업체의 사용량 설정으로 연결됩니다 — **Claude에서 사용량 관리** — Claude, Codex, Cursor, xAI가 대상이며 미국, EU, 일본에서 제공됩니다

  **개선**

  - 계획에서는 **메모와 함께 거부…**가 실제 동작에 맞게 **계속 계획하기…**로 표시됩니다

  **수정**

  - 열거나 재개한 뒤 빈 프롬프트에 그대로 둔 Claude Code 세션이 최대 30분 동안 **실행 중**으로 표시되던 문제. 이제 약 20초 만에 **완료**로 바뀝니다
  - 프롬프트 없이 만들어진 OpenCode 세션 — 포크, 또는 다른 클라이언트가 연 세션 — 이 **실행 중**에 머물던 문제
  - 사용량이 오래된 스냅샷에 멈춘 채 최신 값인 것처럼 표시되던 문제
</Update>

  ## OpenCode

  **새로운 기능**

  - **OpenCode**가 Claude Code, Codex에 이어 추가되었습니다. 세션이 잠금 화면과 Dynamic Island에 실시간으로 표시되며, 고유한 마크와 색상, 서체를 사용합니다
  - OpenCode의 권한 요청과 질문에도 다른 두 에이전트와 똑같이 잠금 화면에서 허용하거나 거부할 수 있습니다. OpenCode는 거부하면 그 턴이 끝나기 때문에, 카드가 거부의 결과를 함께 알려줍니다
  - OpenCode 세션은 계획 에이전트가 작업하는 동안 ‘계획 중’으로 표시되고, ‘계획 보기’로 할 일 목록을 열 수 있습니다
  - **명령 하나로 설치** — `bunx nomo-ai`(또는 `npx nomo-ai`)가 컴퓨터에 설치된 Claude Code, Codex, OpenCode를 찾아, 선택한 에이전트에 Nomo를 설치합니다

  **개선**

  - 결제 화면이 세 에이전트를 모두 보여주고, 승인 기능이 실제로 무엇을 하는지 설명합니다. 알림만 받는 것이 아니라 잠금 화면에서 직접 답할 수 있습니다
  - 모델 제공자가 재시도하는 동안 세션은 원본 오류 문자열 대신 ‘다시 연결 중…’으로 표시됩니다

  **보안**

  - `nomo://` 링크만으로는 컴퓨터가 페어링되지 않습니다. 어떤 페어링인지, 어떤 서버에 연결하는지 보여준 다음 확인을 기다립니다
  - 구독 상태는 페어링된 컴퓨터마다 따로 전달되므로, 한 컴퓨터가 다른 컴퓨터의 존재를 알게 되지 않습니다
  - Cursor 연결을 해제하면 쿠키까지 지워집니다. 모르는 사이에 다시 로그인될 수 있는 세션이 남지 않습니다

  **수정**

  - 페어링된 컴퓨터에 표시되던 ‘로컬’이 한 글자로 잘리던 문제
</Update>

  ## 수정과 다듬기

  **새로운 기능**

  - 사용량 알림이 **xAI/Grok**과 **Gemini**까지, 그리고 Claude의 모델별 주간 한도까지 확대되었습니다

  **개선**

  - 모든 언어의 번역을 손봤습니다. 뜻이 틀린 라벨이 있었고, 같은 개념에 두 가지 단어가 섞여 있었습니다
  - 권한 카드가 원본 셸 명령 대신 에이전트가 하려는 일을 먼저 보여줍니다

  - 다운로드 용량 감소

  **수정**

  - 유료 도입 혜택이 있는데도 결제 화면에 무료 체험만 표시되던 문제

  - Cursor의 두 사용량 구간을 작은 위젯에서 다시 볼 수 있습니다
  - 첫 실행 가이드에서 발생하던 크래시
