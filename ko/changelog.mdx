  ## OpenCode

  **새로운 기능**

  - **OpenCode**가 Claude Code, Codex에 이어 추가되었습니다. 세션이 잠금 화면과 Dynamic Island에 실시간으로 표시되며, 고유한 마크와 색상, 서체를 사용합니다
  - OpenCode의 권한 요청과 질문에도 다른 두 에이전트와 똑같이 잠금 화면에서 허용하거나 거부할 수 있습니다. OpenCode는 거부하면 그 턴이 끝나기 때문에, 카드가 거부의 결과를 함께 알려줍니다
  - OpenCode 세션은 계획 에이전트가 작업하는 동안 ‘계획 중’으로 표시되고, ‘계획 보기’로 할 일 목록을 열 수 있습니다
  - **명령 하나로 설치** — `bunx nomo-ai`(또는 `npx nomo-ai`)가 컴퓨터에 설치된 Claude Code, Codex, OpenCode를 찾아, 선택한 에이전트에 Nomo를 설치합니다

  **개선**

  - 결제 화면이 세 에이전트를 모두 보여주고, 승인 기능이 실제로 무엇을 하는지 설명합니다. 알림만 받는 것이 아니라 잠금 화면에서 직접 답할 수 있습니다
  - 모델 제공자가 재시도하는 동안 세션은 원본 오류 문자열 대신 ‘다시 연결 중…’으로 표시됩니다

  **보안**

  - `nomo://` 링크만으로는 컴퓨터가 페어링되지 않습니다. 어떤 페어링인지, 어떤 서버에 연결하는지 보여준 다음 확인을 기다립니다
  - 구독 상태는 페어링된 컴퓨터마다 따로 전달되므로, 한 컴퓨터가 다른 컴퓨터의 존재를 알게 되지 않습니다
  - Cursor 연결을 해제하면 쿠키까지 지워집니다. 모르는 사이에 다시 로그인될 수 있는 세션이 남지 않습니다

  **수정**

  - 페어링된 컴퓨터에 표시되던 ‘로컬’이 한 글자로 잘리던 문제
</Update>

<Update label="2026년 8월 19일" description="2.1.1">
  ## 수정과 다듬기

  **새로운 기능**

  - 사용량 알림이 **xAI/Grok**과 **Gemini**까지, 그리고 Claude의 모델별 주간 한도까지 확대되었습니다
  - 계획을 휴대폰에서 **전문**으로 읽을 수 있습니다. 이전에는 앞부분만 보였습니다

  **개선**

  - 모든 언어의 번역을 손봤습니다. 뜻이 틀린 라벨이 있었고, 같은 개념에 두 가지 단어가 섞여 있었습니다
  - 권한 카드가 원본 셸 명령 대신 에이전트가 하려는 일을 먼저 보여줍니다
  - Dynamic Island에서 세션 제목과 타이머가 눌리거나 잘리지 않습니다
  - iPad에서 화면 끝까지 늘어나지 않고 읽기 좋은 폭으로 유지됩니다
  - 다운로드 용량 감소

  **수정**

  - 유료 도입 혜택이 있는데도 결제 화면에 무료 체험만 표시되던 문제
  - Codex 세션에서 **Mac에서 열기**가 동작하지 않던 문제
  - Cursor의 두 사용량 구간을 작은 위젯에서 다시 볼 수 있습니다
  - 첫 실행 가이드에서 발생하던 크래시
</Update>

<Update label="2026년 8월 11일" description="2.1">
  ## 잠금 화면에서 에이전트에 답하기

  **신규**

  - 권한 요청이 잠금 화면과 Dynamic Island에 표시됩니다 — 책상으로 돌아가지 않고 승인하거나 거부합니다
  - 현재 플랜과 남은 사용량을 세션에서 한눈에 확인합니다
  - **LAN 모드** — iPhone과 컴퓨터가 같은 Wi-Fi 네트워크에 있으면 업데이트가 두 기기 사이를 직접 오갑니다. 종단 간 암호화는 그대로입니다
  - Claude, OpenAI, Cursor에 이어 Grok(xAI)과 Gemini(Google) 추가

  **수정**

  - 위젯에서 일본어 등 비라틴 문자가 잘리던 문제
  - 위젯, 알림, 실시간 현황 전반의 레이아웃과 안정성
</Update>

<Update label="2026년 7월" description="2.0">
  ## 세션

  **신규**

  - **세션** 탭 — QR 스캔으로 컴퓨터를 페어링하고, Claude Code와 Codex 세션이 잠금 화면과 Dynamic Island에서 돌아가는 모습을 실시간으로 지켜봅니다
  - 작업 중, 완료, 확인 필요 상태와 함께 사용 중인 모델과 세션 제목 표시
  - AES-256-GCM 종단 간 암호화 — 키는 기기를 벗어나지 않으며 중계 서버는 암호문만 봅니다
  - Nomo Pro에서 실시간 세션을 사용할 수 있습니다

  **개선**

  - 사용량에 **사용됨**과 **남음**을 함께 표시

  **수정**

  - OpenAI 주간 사용량 집계
</Update>
