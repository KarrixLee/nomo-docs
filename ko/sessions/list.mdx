**세션** 탭은 세션이 아니라 **컴퓨터** 목록입니다. 페어링한 Mac 하나마다 카드
하나가 놓입니다. 세션은 그 한 단계 아래에 있으므로, 컴퓨터를 탭해서 엽니다.

방금 시작한 세션을 찾으려고 이 탭을 훑어보면 당황하게 되는 부분입니다. 세션은
카드 위, 개수 안에 들어 있습니다.

## 컴퓨터 목록

카드마다 컴퓨터 이름, 한 줄 요약, 그리고 연결 상태를 나타내는 색 점이 들어갑니다.

| 점 | 요약 줄 | 의미 |
| --- | --- | --- |
| 초록 | `최근 활성` | 지난 10분 안에 이 Mac에서 무언가 일어났습니다. |
| 회색 | `최근 활동 없음` | 페어링도 정상이고 문제도 없으며, 그저 조용한 상태입니다. |
| 주황 | `다시 연결 중…` | 마지막 조회에서 Nomo가 이 컴퓨터의 중계 서버에 닿지 못했습니다. 스스로 재시도합니다. |
| 스피너 | `연결 중…` | 막 페어링되어 첫 세션이 도착하기를 기다리는 중입니다. |
| 회색 | `페어링 해제됨` | 이 페어링이 교체되었거나 제거되었습니다. [문제 해결](/ko/sessions/troubleshooting)을 참고하십시오. |
| 회색 | `일시 중지됨 — 갱신하여 다시 연결` | Nomo Pro가 만료되었습니다. |

요약 줄에는 `활성 세션 없음`, `세션 1개`, `활성 3개 · 세션 7개`와 같이
표시됩니다. 여기서 "활성"은 끝난 세션, 읽을 수 없는 세션, 그리고 작업 중이라고
주장하지만 10분 넘게 조용한 세션을 제외한 값입니다.

오른쪽 위의 칩은 페어링한 컴퓨터가 몇 대인지 보여 줍니다. 한도에 도달하면 주황색으로
바뀝니다.

<Note>
  카드를 길게 터치하면 **이름 변경** 또는 **이 컴퓨터 삭제**를 선택할 수 있습니다.
  이름 변경은 휴대폰에만 적용됩니다. 삭제하면 해당 컴퓨터가 여기에 표시되지
  않습니다 — 언제든지 다시 페어링할 수 있고, Mac 쪽에는 아무 영향도 주지 않습니다.
</Note>

## 컴퓨터 상세 화면

카드를 탭하면 위쪽에 **Claude Code**와 **Codex** 분할 컨트롤이 있는 드로어가
열립니다. Nomo는 가장 최근에 활동한 에이전트를 먼저 엽니다.

그 안의 세션은 **프로젝트 폴더별**로 묶이며, 폴더의 git 분기가 머리글 옆에
표시됩니다. 폴더가 하나면 **세션** 카드 하나로 묶이고, 둘 이상이면 폴더 이름을
딴 카드가 하나씩 생깁니다.

위쪽 컴퓨터 이름 아래에는 `활성`, `마지막 활동`, `다시 연결 중…` 중 하나가
표시됩니다. 그리고 Nomo가 중계 서버를 거치지 않고 네트워크를 통해 Mac에 직접
연결되어 있으면 초록색 **⚡ 로컬** 칩이 함께 표시됩니다.
[로컬 네트워크](/ko/sessions/settings#로컬-네트워크)를 참고하십시오.

</ResponseField>

<ResponseField name="제목">

  바뀝니다. 폴더 이름이 **아닙니다** — 다만 에이전트가 아직 아무것도 요약하지

</ResponseField>

<ResponseField name="상태 줄">
  상태, 그리고 에이전트가 보고한 경우 지금 하고 있는 일 — `실행 중 · 편집 중`,
  `권한 필요 · Bash`.
</ResponseField>

<ResponseField name="상대 시간">

  `2분 전`은 Nomo가 2분 전에 마지막으로 소식을 들었다는 뜻입니다. 실제 실행 시간은

## 세션 상태

| 레이블 | 색 | 의미 |
| --- | --- | --- |
| `실행 중` | 주황 점 | 작업 중입니다. 사용자가 할 일은 없습니다. |
| `주의 필요` | 주황 손 | 멈춰서 사용자를 기다리지만, 휴대폰에서 답할 수 있는 것은 없습니다. |
| `권한 필요 · Bash` | 보라 손 | 특정 동작에 대한 권한을 요청합니다. **이것은 여기에서 답할 수 있습니다** — [휴대폰에서 답변하기](/ko/sessions/approvals)를 참고하십시오. |
| `답변 필요` | 보라 손 | 객관식 질문을 합니다. 이것도 휴대폰에서 답할 수 있습니다. |
| `완료` | 초록 체크 | 세션이 끝났습니다. |
| `다시 연결 중…` | 주황 | Mac이 세션 도중 중계 서버와의 연결을 잃었거나, Nomo가 아직 이 행을 복호화하지 못한 상태입니다. 일시적이며 재시도합니다. |
| `확인 불가` | 회색 점 | 10분이 지나도 Nomo가 복호화하지 못한 행입니다. `암호화된 세션`으로 표시됩니다. |
| `보내는 중…` | 스피너 | 답변이 Mac으로 가는 중입니다. |

요청이 처리되고 나면 행에 어떻게 처리되었는지가 작은 캡션으로 붙습니다.
`허용됨`, `거부됨`, `항상 허용됨`, `답변됨`, 또는 `만료됨 — 컴퓨터에서 계속하세요`
같은 솔직한 실패 표시입니다. 전체 목록은
[휴대폰에서 답변하기](/ko/sessions/approvals#캡션의-의미)에 있습니다.

행은 최근 활동 순으로 정렬됩니다. Nomo는 행을 숨기지 않습니다 — 이 목록은 중계
서버가 가진 내용을 그대로 비춥니다.

## 행을 탭해 자세히 보기

행의 글자 쪽을 탭하면 펼쳐집니다. 여기 있는 항목은 모두 선택해서 복사할 수 있고,
단어 대신 기호로 표시됩니다.

- **모델** — `Fable`, `Opus 4.8`, `GPT 5.6 Sol`. 에이전트가 보고하지 않았으면 표시되지 않습니다.
- **전체 제목** — 잘리지 않은 형태입니다.
- **폴더**와 **세션 ID** — 앞 여덟 글자를 고정폭으로 표시합니다.
- 대기 중인 **질문**이 있으면 그 전문.
- **계획 보기** — 계획을 엽니다. Claude Code에서는 답변할 수 있고, [Codex](/ko/sessions/codex)에서는 읽기 전용입니다.
- **Mac에서 열기** — Mac에서 해당 세션의 터미널 창을 앞으로 가져옵니다. Nomo가 [로컬 네트워크](/ko/sessions/settings#로컬-네트워크)로 직접 연결되어 있을 때만 표시됩니다.

<Tip>
  요청에 **답변**하려면 행을 탭하지 말고 길게 터치하십시오. 탭하면 펼쳐지고,
  길게 터치하면 허용 / 거부 메뉴가 열립니다.
</Tip>

## 한도

| | 한도 |
| --- | --- |
| 컴퓨터당 세션 | 두 에이전트를 합쳐 **20개** |
| 페어링 컴퓨터 | **5대** |
| Dynamic Island의 세션 | 기기 전체에서 **한 번에 하나** |

두 숫자 모두 앱에 컴파일되지 않고 Nomo 쪽에서 정하므로, 앱 업데이트 없이 바뀔 수
있습니다. 세션 개수는 첫 번째 세션 카드에 `N/20` 칩으로, 컴퓨터 개수는 탭에
`N/5` 칩으로 표시됩니다. 둘 다 한도에 도달하면 주황색으로 바뀝니다.

여섯 번째 컴퓨터를 페어링하면 **컴퓨터 한도 도달**로 실패합니다. 더 이상 쓰지
않는 컴퓨터를 삭제하고 다시 시도하십시오 — 이미 페어링한 컴퓨터가 자리를 내주기
위해 해제되는 일은 없습니다.

컴퓨터가 세션 한도에 도달하면 Nomo는 끝난 행과 오래 조용한 행부터 정리합니다.
살아 있는 세션을 밀어내는 대신 새 세션을 거절하지만, 권한 요청을 안고 도착한
세션은 언제나 우선합니다.

## 사라지는 행

끝났거나 조용한 세션은 마지막 실제 활동으로부터 약 한 시간 뒤에 스스로
사라집니다. 행이 저절로 없어지는 것은 정상이며, 무언가 잘못되었다는 뜻이
아닙니다.

해제된 페어링은 다른 문제입니다 — 그 Mac을 다시 페어링했거나, 그 Mac에서
[`/nomo-cc:unpair`](/ko/sessions/commands#unpair)를 실행한 경우입니다. Nomo는
실패가 충분히 이어진 뒤에야 이를 사실로 받아들이고, 카드를 `페어링 해제됨`으로
바꾸면서 한 번 탭으로 처리하는 **제거**를 함께 보여 준 다음, 1분쯤 뒤에
정리합니다. Wi-Fi가 잠깐 불안정했다는 이유로 컴퓨터를 조용히 지우지는 않습니다.
