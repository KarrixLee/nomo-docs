Devin 세션을 iPhone의 잠금 화면과 Dynamic Island에서 볼 수 있습니다. Devin이
권한을 요청하면, 휴대폰이 **허용**할지 **거부**할지 물어봅니다. Devin이
질문하면 휴대폰에서 답할 수도 있습니다.

Devin CLI, 즉 터미널의 `devin` 명령과 [Devin Desktop](#devin-desktop)에서
동작합니다.

<Note>
  세션은 Nomo Pro에 포함됩니다. 휴대폰에는 Nomo **2.5.0** 이상, Mac에는
  플러그인 **2.5.0** 이상이 필요합니다.
</Note>

## 설정 {#set-it-up}

Devin에 Nomo를 추가하는 방법은 **Devin 플러그인**과 **Nomo 설치 도구** 두
가지입니다. 둘 중 하나만 설치하십시오. 둘 다 설치하면 Nomo는 설치 도구 쪽을
사용하고, 플러그인은 아무것도 하지 않습니다.

<Tabs>
  <Tab title="Devin 플러그인">
    <Steps>
      <Step title="터미널 열기">
        Mac에서 **터미널** 앱을 엽니다. **응용 프로그램 > 유틸리티**에
        있습니다.
      </Step>

      <Step title="Devin CLI 설치">
        이미 설치되어 있다면 이 단계는 건너뜁니다.

        아래 줄을 복사해 터미널에 붙여 넣고 Return 키를 누릅니다.

        ```bash
        brew install --cask devin-cli
        ```

        Homebrew가 없다면 대신 다음을 사용하십시오.

        ```bash
        curl -fsSL https://cli.devin.ai/install.sh | bash
        ```

        그런 다음 `devin`을 입력하고 Return 키를 누릅니다. Devin이 로그인을
        요청하면 안내에 따릅니다.
      </Step>

      <Step title="Nomo 플러그인 설치">
        Devin 안이 아니라 터미널에 입력합니다. Devin이 열려 있다면 먼저 새
        터미널 창을 엽니다(**⌘N**을 누릅니다).

        아래 줄을 복사해 터미널에 붙여 넣고 Return 키를 누릅니다.

        ```bash
        devin plugins install KarrixLee/nomo
        ```

        Devin Desktop을 사용한다면 **Customize → Plugins → From repository**로
        이동해 `KarrixLee/nomo`를 입력합니다.
      </Step>

      <Step title="Devin 시작">
        터미널에 `devin`을 입력하고 Return 키를 누릅니다.
      </Step>

      <Step title="/nomo:pair 입력">
        `devin`에 다음을 입력해 보냅니다.

        ```
        /nomo:pair
        ```

        Devin이 브라우저에 QR 코드가 있는 페이지를 엽니다.
      </Step>

      <Step title="QR 코드 스캔">
        iPhone에서 Nomo를 열고 **세션** → **컴퓨터 페어링**으로 이동해 QR 코드를
        스캔합니다.
      </Step>

      <Step title="확인">
        `devin`에 다음을 입력해 보냅니다.

        ```
        /nomo:status
        ```

        `!`로 시작하는 줄이 있으면 그 아래 `→` 줄의 안내를 따릅니다.
      </Step>

      <Step title="Devin에서 메시지 보내기">
        `devin`에서 아무 메시지나 보냅니다.

        Nomo에서 컴퓨터의 **Devin** 탭 아래에 세션이 나타납니다. Devin 탭이
        없다면 **+** 버튼(**에이전트 선택**)을 탭해 Devin을 켭니다.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Nomo 설치 도구">
    <Steps>
      <Step title="터미널 열기">

        있습니다.

        이미 설치되어 있다면 이 단계는 건너뜁니다.


        그런 다음 `devin`을 입력하고 Return 키를 누릅니다. Devin이 로그인을

      </Step>

      <Step title="Nomo 설치 도구 실행">
        아래 줄을 복사해 터미널에 붙여 넣고 Return 키를 누릅니다.

        ```bash
        bunx nomo-ai --devin
        ```

        `bunx`가 없다면 대신 `npx nomo-ai --devin`을 사용하십시오.

        출력되는 줄 가운데 다음 줄이 보여야 합니다.

        ```

        ```
      </Step>

      <Step title="Devin 재시작">
        열려 있는 `devin`을 모두 닫은 다음 다시 시작합니다. Devin Desktop을

        <Warning>
          이 단계를 건너뛰지 마십시오. Devin을 재시작하기 전까지 Nomo는
          동작하지 않습니다.
        </Warning>
      </Step>

      <Step title="/nomo-pair 입력">
        `devin`에 다음을 입력해 보냅니다.

        ```
        /nomo-pair
        ```

        Devin이 Nomo 명령을 실행할지 물으면 허용하십시오. Devin이 브라우저에
        QR 코드가 있는 페이지를 엽니다.
      </Step>

      <Step title="QR 코드 스캔">
        iPhone에서 Nomo를 열고 **세션** → **컴퓨터 페어링**으로 이동해 QR 코드를
        스캔합니다.
      </Step>

      <Step title="확인">
        `devin`에 다음을 입력해 보냅니다.

        ```
        /nomo-status
        ```

        `!`로 시작하는 줄이 있으면 그 아래 `→` 줄의 안내를 따릅니다.
      </Step>

      <Step title="Devin에서 메시지 보내기">
        `devin`에서 아무 메시지나 보냅니다.

        Nomo에서 컴퓨터의 **Devin** 탭 아래에 세션이 나타납니다. Devin 탭이
        없다면 **+** 버튼(**에이전트 선택**)을 탭해 Devin을 켭니다.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Tip>
  **Claude Code, Codex, OpenCode, Cursor 또는 Antigravity에서 이미 페어링했나요?**
  페어링 한 번이 컴퓨터 전체에 적용됩니다. 페어링 단계는 건너뛰십시오.
</Tip>

<Tip>
  **이 컴퓨터에 브라우저가 없나요?** QR 코드 대신 짧은 코드를 요청합니다.
  Devin에 `/nomo-pair code`를 입력합니다(플러그인을 쓴다면 `/nomo:pair code`).
  iPhone에서 Nomo를 열고
  **세션** → **컴퓨터 페어링** → **코드 입력**으로 이동해 그 코드를 입력합니다.
  코드는 10분 뒤에 만료됩니다.
</Tip>

<Note>
  **Devin Desktop의 Restricted Mode는 Nomo를 끕니다.** Nomo에 필요한 Hook을
  끄기 때문에, 켜져 있는 동안에는 세션이 휴대폰에 전달되지 않습니다.
</Note>

## 명령 {#commands}

Devin에 다음을 입력합니다. Devin 플러그인을 쓴다면 명령이 `/nomo-` 대신
`/nomo:`로 시작합니다 — 예를 들어 `/nomo:pair`입니다.

| 입력 | Devin 플러그인 | 하는 일 |
| --- | --- | --- |
| `/nomo-pair` | `/nomo:pair` | 이 컴퓨터를 휴대폰에 연결합니다 |
| `/nomo-pair code` | `/nomo:pair code` | 위와 같지만, QR 코드 대신 입력할 짧은 코드를 받습니다 |
| `/nomo-status` | `/nomo:status` | 모든 것이 잘 동작하는지 확인합니다 |
| `/nomo-approvals off` | `/nomo:approvals off` | 휴대폰에 묻지 않습니다 — 대신 Mac에서 Devin이 묻습니다 |
| `/nomo-approvals on` | `/nomo:approvals on` | 다시 휴대폰에 묻습니다 |
| `/nomo-reset` | `/nomo:reset` | 연결은 유지한 채 휴대폰에서 멈춘 세션을 정리합니다 |
| `/nomo-unpair` | `/nomo:unpair` | 이 컴퓨터를 휴대폰에서 연결 해제합니다 |

<Note>
  Cursor에서도 Nomo를 쓰십니까? 그렇다면 Devin에는 이 명령이 `/devin:nomo-pair`,
  `/devin:nomo-status` 등으로 표시됩니다. 그 이름으로 입력하십시오.
  `/nomo-approvals`는 이름이 그대로입니다.
</Note>

이 컴퓨터를 연결한 뒤에는 Devin이 Nomo 자체 명령을 묻지 않고 실행합니다. 단,
`/nomo-approvals off`, `/nomo-unpair`, `/nomo-pair code`는 원격 승인이 켜져 있는
동안 휴대폰에서 먼저 묻습니다. Devin이 Nomo 명령을 실행할지 물으면 허용하십시오. Devin이 명령을 알지 못한다면
설치 도구를 다시 실행하고 Devin을 재시작하거나, [고급](#advanced)에 있는 대로
터미널에서 실행하십시오.

연결과 원격 승인 스위치는 이 컴퓨터의 모든 코딩 앱이 공유합니다. 여기서 원격
승인을 끄면 Claude Code와 Codex에서도 꺼집니다.

## 표시되는 것 {#what-you-see}

- 세션은 **첫 메시지**를 보낼 때 나타납니다.
- Devin이 작업하는 동안에는 **실행 중**, 끝나면 **완료**로 표시됩니다.
- 이름은 Devin이 붙인 세션 제목입니다. Devin이 제목을 만들기 전까지는 첫
  메시지가 표시됩니다.
- 배지에는 Devin이 사용하는 모델이 표시됩니다.
- [Dynamic Island](/ko/sessions/island)는 다른 에이전트와 똑같이 동작합니다.

## 휴대폰에서 답변하기 {#answering-from-your-phone}

Devin이 권한을 요청하면 — 예를 들어 명령을 실행하려 할 때 — 휴대폰이
물어봅니다.

세션을 길게 터치하거나 Dynamic Island를 사용해 다음 중 하나를 선택합니다.

<Frame caption="명령 실행을 요청하는 Devin 세션.">
  <div className="device-frame">
    <img className="only-light" src="/images/devin-approval-card.png" alt="Devin 세션 Fix token refresh race의 승인 카드. bun test 실행을 요청하며 거부, 허용, 메모와 함께 거부 버튼이 있음" />
    <img className="only-dark" src="/images/devin-approval-card-dark.png" alt="Devin 세션 Fix token refresh race의 승인 카드. bun test 실행을 요청하며 거부, 허용, 메모와 함께 거부 버튼이 있음" />
  </div>
</Frame>

- **허용** — Devin이 그대로 진행합니다.
- **… 항상 허용(이 세션)** — Devin이 그대로 진행하고, 이 세션이 끝날 때까지
  Nomo는 같은 작업을 다시 묻지 않습니다. [아래](#always-allow)를 참고하십시오.
- **거부** — Devin이 그 작업을 하지 않습니다.
- **메모와 함께 거부…** — Devin이 그 작업을 하지 않고, 이유를 적은 메모를
  받습니다.

자세한 내용은 [휴대폰에서 답변하기](/ko/sessions/approvals)에 있습니다.

알아 두면 좋은 것:

- **Devin은 휴대폰의 답을 기다립니다.** 시간이 초과되면 Devin이 대신 Mac에서
  묻습니다.
- **휴대폰이 없어도 괜찮습니다.** 휴대폰에 연결할 수 없거나 원격 승인이
  [일시 중지](/ko/sessions/approvals#pausing-it)되어 있으면, Devin은 Nomo가
  없을 때와 똑같이 Mac에서 묻습니다.

### 항상 허용 {#always-allow}

**항상 허용**은 **이 세션에서만** 유효합니다. 세션이 끝나면 Nomo는 이를 잊고,
다음 세션에서는 다시 묻습니다.

- **단순한 명령**은 명령 이름으로 기억됩니다. `touch b.txt`를 항상 허용하면
  `touch c.txt`도 허용됩니다 — 하지만 다른 명령은 허용되지 않습니다.
- **연결된 명령** — `&&`, `;`, `|`, `>`가 들어간 명령 — 은 이미 허용한 것과
  완전히 같은 명령이 아니면 매번 휴대폰으로 옵니다. 그래서
  `touch x && rm -rf ~`는 여전히 묻습니다.
- **그 밖의 작업**(파일 쓰기 등)은 세션이 끝날 때까지 허용됩니다.

Nomo는 이를 컴퓨터에 보관하며, Devin 자체 설정은 바꾸지 않습니다. 원격 승인을
일시 중지해도 세션이 끝날 때까지는 계속 적용됩니다.

### Devin의 질문에 답하기 {#questions}

Devin이 질문하면 세션에 `답변 필요`가 표시됩니다. 세션을 길게 터치하고
**답변하기…**를 선택합니다.

1. 선택지를 탭합니다. Devin이 허용하는 경우 여러 개를 고를 수 있습니다.
2. 맞는 것이 없다면 **기타…**를 탭하고 직접 답변을 입력합니다.
3. **보내기**를 탭합니다.

**메모 추가**로 답변에 코멘트를 붙일 수 있습니다. **거부**를 선택하면 답하지
않기로 했다는 것이 Devin에 전달됩니다.

<Note>
  **Mac에서는 질문이 rejected로 표시됩니다. 정상입니다.** Devin은
  Nomo로부터 답을 직접 받을 방법이 없어서, Nomo는 답변을 Devin의 질문을 닫는
  이유로 보냅니다. 그래서 질문에 **rejected**가 표시되고, 그 옆에 답변이
  적힙니다. Devin은 답변을 읽고 작업을 이어 갑니다.
</Note>

## 중단 {#interrupt}

**실행 중**인 Devin 세션에서
**[중단](/ko/sessions/list#interrupt-a-running-session)**을 탭하면 멈춥니다.
초록색 **⚡ 로컬** 칩이 필요합니다 — iPhone과 Mac이 같은 네트워크에 있어야
합니다.

Devin은 진행 중인 단계를 마친 뒤에 멈춥니다. 명령이나 답변을 중간에 끊을 수는
없습니다. 세션은 **완료**로 표시되고 Devin은 열린 채로 남으므로, 새 메시지를
보내면 이어서 진행합니다.

## Devin Desktop {#devin-desktop}

Devin 문서에 따르면 Devin Desktop의 **Devin Local** 에이전트는 Devin CLI와
같은 엔진으로 동작하므로, Nomo도 똑같이 동작합니다. Nomo는 Devin CLI와 Devin의
ACP 서버로 테스트되었습니다.

- **휴대폰이 먼저 답합니다.** 휴대폰에 권한 요청이나 질문이 와 있는 동안에는
  Devin Desktop에 그에 대한 자체 버튼이 표시되지 않습니다. 휴대폰에서
  답하십시오. Mac에서 답하려면 Devin의 다음 프롬프트 전에
  [원격 승인을 일시 중지](/ko/sessions/approvals#pausing-it)하십시오.
- **휴대폰으로 오는 것.** Devin Desktop의 기본 **Code** 모드에서 Devin은 명령
  실행, 웹 페이지 가져오기, 프로젝트 밖에 쓰기 전에만 묻습니다. 휴대폰에서 보게
  되는 권한 요청은 이것들입니다.
- **Restricted Mode는 Nomo를 끕니다.** Restricted Mode를 끝낼 때까지 세션이
  휴대폰에 오지 않습니다.

## Devin에서 다른 점 {#whats-different-for-devin}

- **Mac의 Devin만 표시됩니다.** Devin Cloud 세션은 나타나지 않습니다 — Nomo는
  Mac에서 실행되는 Devin만 보여 줍니다.
- **짧은 세션에는 모델 배지가 없을 수 있습니다.** Devin은 세션이 끝날 때만
  모델을 저장합니다.
- **Devin에서 사용할 수 없음:**
  [답장](/ko/sessions/antigravity#reply-from-your-phone), **Mac에서 열기**.

## 문제 해결 {#troubleshooting}

  <Accordion title="휴대폰에 아무것도 표시되지 않음">
    1. 열려 있는 `devin`을 모두 닫고 다시 시작합니다.
    2. Nomo를 확인합니다. Devin에 `/nomo-status`를 입력합니다(플러그인을 쓴다면
       `/nomo:status`).

    3. `→`로 시작하는 줄의 안내를 따릅니다.

    Devin Desktop을 사용한다면 **Restricted Mode**가 꺼져 있는지 확인하십시오.

    그래도 표시되지 않나요? Nomo에서 **+** 버튼(**에이전트 선택**)을 탭해
    Devin을 켭니다.

    Devin 탭에 **아직 Devin 세션이 없습니다**라고 표시되면 먼저 Devin에서
    메시지를 보내십시오. 세션은 첫 메시지를 보낸 뒤에야 나타납니다.
  </Accordion>

  <Accordion title="설치 도구가 설정 파일에 주석이 있었다고 알림">
    괜찮습니다. Nomo가 항목을 추가하면 Devin 설정 파일은 주석을 유지할 수
    없으므로, 설치 도구가 먼저 원래 파일을 바로 옆에 저장해 두었습니다.

    ```
    ~/.config/devin/config.json.nomo-backup
    ```

    설정은 모두 그대로 있습니다. 주석만 제거되었습니다.
  </Accordion>

  <Accordion title="Devin에 답변이 rejected로 표시됨">
    정상입니다. Nomo는 답변을 Devin의 질문을 닫는 이유로 보내므로, Mac에서는
    질문이 **rejected**로 표시되고 그 옆에 답변이 적힙니다. Devin은 답변을 읽고
    작업을 이어 갑니다.
  </Accordion>

  <Accordion title="Devin Desktop에 권한 요청 버튼이 없음">
    그 요청은 휴대폰에 와 있습니다. 휴대폰에서 답하십시오. Mac에서 답하려면
    Devin의 다음 프롬프트 전에
    [원격 승인을 일시 중지](/ko/sessions/approvals#pausing-it)하십시오.
  </Accordion>

  <Accordion title="중단해도 Devin이 바로 멈추지 않음">
    Devin은 진행 중인 단계를 먼저 마칩니다 — 이미 실행 중인 명령이나 답변은
    끝날 때까지 계속됩니다. 그런 다음 멈춥니다.

    **중단** 버튼이 없다면, iPhone과 Mac이 같은 네트워크에 있고 초록색
    **⚡ 로컬** 칩이 표시되어 있어야 합니다.
  </Accordion>

  <Accordion title="휴대폰에서 승인을 묻지 않음">
    Devin에 `/nomo-approvals on`을 입력합니다(플러그인을 쓴다면
    `/nomo:approvals on`).

    원격 승인이 이미 켜져 있었다면
    [설정](/ko/sessions/settings#remote-approvals)에서 **iPhone에서 답변**을
    확인하십시오.
  </Accordion>

  <Accordion title="세션이 실행 중에서 멈춰 있음">
    Devin에 `/nomo-reset`을 입력합니다(플러그인을 쓴다면 `/nomo:reset`).
  </Accordion>
</AccordionGroup>

더 많은 도움말은 [문제 해결](/ko/sessions/troubleshooting)에 있습니다.

## 업데이트 {#updating}

설치 도구를 썼다면 다시 실행한 다음 Devin을 재시작합니다.

```bash
bunx nomo-ai --devin
```

## 제거 {#uninstalling}

**Devin 플러그인:** 아래 줄을 복사해 터미널에 붙여 넣고 Return 키를 누릅니다.

```bash
devin plugins remove nomo
```

**Nomo 설치 도구:**

<Steps>
  <Step title="터미널에서 실행">
    ```bash
    bunx nomo-ai --uninstall --devin
    ```

    다음과 같이 표시됩니다.

    ```
    devin-install: removed Nomo's hooks from Devin — restart devin
    ```

    `bunx`가 없다면 `npx nomo-ai --uninstall --devin` 또는
    `node ~/.nomo/plugin/scripts/devin-install.mjs --uninstall`을 사용하십시오.
  </Step>

  <Step title="Devin 재시작">
    열려 있는 `devin`을 모두 닫고 다시 시작합니다.
  </Step>
</Steps>

다른 코딩 앱을 위한 휴대폰 연결은 그대로 유지됩니다. 이 컴퓨터를 휴대폰에서
연결 해제까지 하려면, 제거하기 **전에** Devin에서 `/nomo-unpair`를
입력하십시오.

## 고급 {#advanced}

<AccordionGroup>
  <Accordion title="터미널에서 실행하기" icon="terminal">
    같은 명령을 Devin 채팅 대신 터미널에서 실행합니다(Nomo 설치 도구를 쓴
    경우).

    | | |
    | --- | --- |
    | 페어링 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs` |
    | 입력할 코드로 페어링 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs --show-code` |
    | 상태 확인 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/status-cmd.mjs devin` |
    | 원격 승인 일시 중지 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs off` |
    | 원격 승인 재개 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs on` |
    | 멈춘 세션 정리 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/reset.mjs` |
    | 페어링 해제 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/unpair.mjs` |

    터미널에서 페어링한 뒤에는
    `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs wait`를 실행하고
    QR 코드를 스캔합니다. 설치 도구에 `--verbose`를 붙이면 무엇을 바꾸는지 볼 수
    있습니다.
  </Accordion>

  <Accordion title="동작 방식" icon="gear">
    - **설치 도구가 바꾸는 것.** 플러그인을 `~/.nomo`에 클론하고,
      `~/.config/devin/config.json`의 `"hooks"` 키에 Nomo 항목을 추가합니다.
      다른 Devin 설정은 그대로 둡니다. 또한 `/nomo-*` 명령을 Devin Skill로
      `~/.config/devin/skills/`에 추가하며, 같은 이름의 Skill이 이미 있으면
      건드리지 않습니다. 다시 실행해도 아무것도 바뀌지 않습니다.
      파일에 주석이 있으면 먼저 `config.json.nomo-backup`으로 복사합니다.
      제거하면 Nomo 항목과 Skill만 삭제됩니다. `devin`에서 `/hooks`를 입력하면
      무엇을 불러왔는지 볼 수 있습니다.
    - **플러그인이 추가하는 것.** Devin 플러그인은 같은 두 Hook과, 같은 명령을
      `/nomo:pair`, `/nomo:status`, `/nomo:approvals`, `/nomo:reset`,
      `/nomo:unpair`로 추가합니다. 규칙, MCP 서버, 에이전트는 추가하지
      않으며, 로컬 Devin 세션에서만 실행되고 Devin Cloud에서는 절대 실행되지
      않습니다. 설치 도구의 항목이 있는 동안에는 플러그인의 Hook이 아무것도
      보내지 않습니다.
    - **상태.** `UserPromptSubmit`, `PostToolUse`, `Stop`, `SessionEnd`의 Hook이
      상태를 보고합니다. 아무것도 출력하지 않으므로 프롬프트를 막거나 도구
      호출을 바꿀 수 없습니다 — 단, **중단**을 탭한 뒤에는 예외로, 다음
      `PostToolUse`가 `{"continue":false}`를 출력해 그 턴을 끝냅니다.
    - **승인.** `PermissionRequest` Hook이 도구 이름과 그 명령 또는 파일 경로를
      종단 간 암호화해 휴대폰으로 보냅니다. 페어링된 휴대폰에서 바로 그 요청을
      허용했을 때만 `approve`로, 거부하면 메모를 담아 `block`으로 응답합니다.
      그 밖의 모든 경우 — 페어링되지 않음, 원격 승인 일시 중지, 오프라인, 시간
      초과, 오류 — 에는 아무것도 출력하지 않아, 결정을 Devin 자체의 요청에
      맡깁니다.
    - **질문.** 같은 Hook이 `PreToolUse`(`ask_user_question`에만)에서 Devin의
      질문과 선택지를 종단 간 암호화해 휴대폰으로 보냅니다. 답변은 답변을
      이유로 담은 `block`으로 돌아오고, Devin의 모델이 이를 읽습니다.
    - **항상 허용.** 허용 내용은
      `~/.config/cc-status/sessions/<session>.devin-allow`에 저장됩니다. 이
      파일은 본인만 읽을 수 있으며, 세션이 끝나면 삭제됩니다. Devin 자체 설정
      파일에는 아무것도 쓰지 않습니다.
    - **행 중복 없음.** Devin은 Claude Code Hook도 실행합니다. Nomo의 Claude
      Code 플러그인은 Devin 안에서는 아무것도 하지 않으므로, Devin 세션이 Claude
      Code 세션으로 표시되는 일은 없습니다.

    자세한 내용은 플러그인의
    [README](https://github.com/KarrixLee/nomo#install--devin)에 있습니다.
  </Accordion>
</AccordionGroup>
