Nomo는 Grok Bot 채팅을 세션으로 보여 주지 않습니다. Grok Bot은 세션 목록에도,
Dynamic Island에도 나타나지 않습니다. 대신 상태, 사용량, 그리고 Grok Bot을 쓴
날과 토큰을 볼 수 있습니다. 모두 iPhone에서 됩니다. 컴퓨터는 필요 없습니다.

## 볼 수 있는 것

| | 요금제 | 필요한 것 |
| --- | --- | --- |
| Grok Bot의 상태(위젯과 알림) | 무료 | 없음 |
| 사용량(위젯과 알림) | 무료 | Nomo에 Cursor 연결 |
| 사용 속도 줄과 Nomo 사용 속도 위젯 | Nomo Pro | Nomo에 Cursor 연결 |
| Nomo 활동과 Nomo 토큰에 Grok Bot을 쓴 날과 토큰 표시 | Nomo Pro | Nomo에 Cursor 연결 |

## iPhone에서 쓰기 {#iphone-only}

각 줄을 설명하는 페이지가 따로 있습니다.

- **상태**: 위젯에서 Cursor의 **Grok Bot** 서비스를 고릅니다.
  [상태](/ko/status)와 [위젯](/ko/widget)을 참고하십시오.
- **사용량**: Cursor를 연결합니다.
  [Cursor와 Grok](/ko/usage#cursor-and-grok)을 참고하십시오.
- **알림**: [알림](/ko/notifications)을 참고하십시오.
- **사용 속도**: [사용 속도](/ko/usage#pace)와
  [Nomo 사용 속도](/ko/widgets#nomo-pace)를 참고하십시오.
- **쓴 날과 토큰**: 다음 섹션을 참고하십시오.

## 연속 기록에 Grok Bot 더하기 {#streak}

Nomo 2.4.2와 Nomo Pro가 필요합니다.

<Warning>
  Grok이 아니라 **Cursor**를 연결하십시오. Nomo에서 **Grok**을 연결하면 주간
  한도는 보이지만, Grok Bot을 쓴 날과 토큰은 보이지 않습니다. 이것은 Cursor를
  통해서만 가져옵니다.
</Warning>

<Steps>
  <Step title="Cursor 연결">
    1. Nomo를 엽니다.
    2. **제공업체** 탭을 탭합니다.
    3. **Cursor**를 탭합니다.
    4. 위쪽의 **사용량**을 탭합니다.
    5. **Cursor 계정 연결**을 탭합니다.
    6. iOS가 **cursor.com**으로 로그인해도 되는지 묻습니다. **계속**을 탭합니다.
    7. Cursor 페이지에서 Grok Bot에 쓰는 계정과 같은 계정으로 로그인합니다.
       Grok 계정이나 X 계정입니다.

    페이지는 저절로 닫힙니다. 이미 그 계정으로 Cursor를 연결했습니까? 그렇다면
    이 단계를 건너뛰십시오.
  </Step>

  <Step title="활동 화면 열기">
    [활동 화면](/ko/widgets#activity-screen)을 엽니다. 열 때 Grok Bot을 쓴 날과
    토큰을 가져옵니다. 아래로 당겨서 다시 가져올 수도 있습니다.
  </Step>

  <Step title="위젯 추가">
    Nomo 활동 위젯이나 Nomo 토큰 위젯을 추가합니다. 위젯을 길게 터치하고
    **위젯 편집**을 탭한 뒤 **캐릭터**를 탭하고 **Grok Bot**을 고릅니다.
    [Nomo 활동](/ko/widgets#nomo-activity)을 참고하십시오.
  </Step>
</Steps>

## 집계되는 것

- 그날 Grok Bot이 토큰을 조금이라도 썼다면 그날을 셉니다. 그래서 예약된
  루틴도 셉니다.
- Grok Bot 휴대폰 앱에서 쓴 것도 셉니다.
- Nomo 토큰과 활동 화면에는 Grok Bot의 실제 토큰 수가 표시됩니다.
- Cursor 편집기나 명령줄에서 직접 쓴 Cursor 사용도 **Cursor**라는 별도의 줄에
  표시됩니다.
- The X Subscription에서는 Grok Bot과 Cursor가 주간 한도 하나를 함께 쓰며,
  Nomo가 이 한도를 보여 줍니다. 예전 Cursor 요금제에서는 Grok Bot에 별도의
  한도가 있으며, Nomo는 이 한도를 읽지 않습니다.

## 개인정보 {#privacy}

- Nomo는 1시간 단위 토큰 수만 읽습니다. 메시지나 직접 쓴 내용은 절대 읽지
  않습니다.
- 토큰 수는 Cursor 서버에서 휴대폰으로 바로 옵니다. 다른 곳에 업로드되지
  않습니다.
- Cursor 로그인 정보는 iPhone 키체인에 저장되며 Cursor에만 전송됩니다.

그만 쓰려면 **제공업체** 탭에서 Cursor를 열고 **사용량**을 탭한 뒤
**연결 해제**를 탭하십시오. 그러면 Nomo의 Cursor 사용량도 더 이상 표시되지
않습니다.
