Nomo에서 컴퓨터 페어링은 무료입니다. 연속 기록, 코딩 시간, 각 컴퓨터의 상태도
무료입니다.

Nomo Pro는 실시간 기능입니다. 잠금 화면과 Dynamic Island의 실시간 세션, 그리고
휴대폰에서 에이전트에 응답하는 기능이 포함됩니다.

상태, 사용량, 알림에는 컴퓨터가 전혀 필요 없습니다.
[상태와 사용량](/ko/status-usage)을 참고하십시오.

## 포함된 기능 {#what-you-get}

| | 무료 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| 페어링 컴퓨터 | 1대 | 더 많이 |
| **홈**의 [활동](/ko/activity): 연속 기록과 코딩 시간 | ✓ | ✓ |
| 활동 달력 | 최근 30일 | 최근 26주 |
| [토큰](/ko/activity#tokens-chart): 합계와 차트 | | ✓ |
| [나의 결산](/ko/activity#wrapped) | **주**와 **월** | **년**과 토큰 추가 |
| 위젯 | [무료 위젯](/ko/free-widgets#free-and-pro) 참고 | 모두 |
| **세션** 탭 | 컴퓨터 목록. 컴퓨터마다 에이전트가 지금 무엇을 하는지 알려 주는 한 줄 | 실시간 세션 하나하나 |
| Dynamic Island와 잠금 화면의 실시간 현황 | | ✓ |
| 권한 요청과 질문에 응답, 답장, 턴 중단, 전체 텍스트 읽기 | | ✓ |
| [Grok Bot과 Cursor](/ko/widgets#grok-bot) 활동 | | ✓ |

<Note>
  무료 페어링은 Pro 페어링보다 컴퓨터에서 보내는 정보가 적습니다. 정확히 무엇을
  보내는지는 플러그인 README의
  [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer)에
  있습니다.
</Note>

## 무료로 시작하기 {#get-the-free-part}

<Steps>
  <Step title="플러그인 설치">
    컴퓨터에 Nomo 플러그인을 설치합니다. [설치](/ko/setup/install)를 참고하십시오.
  </Step>

  <Step title="컴퓨터 페어링">
    Nomo의 **홈**에서 **Mac 페어링**을 탭합니다. [페어링](/ko/setup/pairing)을
    참고하십시오.
  </Step>

  <Step title="평소처럼 코딩">
    평소처럼 에이전트를 사용합니다. 연속 기록과 코딩 시간이 **홈**의
    [활동](/ko/activity)에 표시됩니다.
  </Step>
</Steps>

## 다른 컴퓨터 사용하기 {#use-a-different-computer}

Nomo Free는 컴퓨터 1대를 연결합니다. 다른 컴퓨터로 바꾸려면 먼저 이전 컴퓨터를
삭제하십시오.

<Steps>
  <Step title="이전 컴퓨터 삭제">
    Nomo에서 **세션**을 엽니다. 컴퓨터를 길게 터치한 뒤 **이 컴퓨터 삭제**를
    탭합니다.
  </Step>

  <Step title="확인">
    **이 컴퓨터 삭제**를 다시 탭합니다.
  </Step>

  <Step title="새 컴퓨터 페어링">
    첫 번째 컴퓨터와 같은 방법으로 페어링합니다. [페어링](/ko/setup/pairing)을
    참고하십시오.
  </Step>
</Steps>

컴퓨터 여러 대를 동시에 쓰고 싶다면 Nomo Pro를 이용하십시오.

## Nomo Pro 추가 {#add-nomo-pro}

**세션** 탭에서 컴퓨터 하나를 탭하면 Nomo Pro가 더하는 기능을 볼 수 있습니다.

컴퓨터는 페어링된 상태로 남습니다. 구독하면 1분쯤 뒤에 실시간 세션이
시작됩니다.
