Nomo에서 컴퓨터 페어링은 무료입니다. 연속 기록, 코딩 시간, 각 컴퓨터의 상태도
무료입니다.

Nomo Pro는 실시간 기능입니다. 잠금 화면과 Dynamic Island에 표시되는 실시간
세션, 그리고 휴대폰에서 에이전트에 응답하는 기능이 포함됩니다.

상태, 사용량, 알림에는 컴퓨터가 필요하지 않습니다.
[상태와 사용량](/ko/status-usage)을 참고하십시오.

## 기능 비교

| | 무료 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| 페어링할 수 있는 컴퓨터 | 1대 | 여러 대 |
| 현재 연속 기록과 최장 연속 기록. 모든 에이전트가 포함됩니다 | ✓ | ✓ |
| 활동 기록(히트맵) | 최근 30일 | 전체 |
| 코딩 시간, 오늘과 이번 주 | ✓ | ✓ |
| 토큰: 합계, 차트, 모델별 또는 에이전트별 | | ✓ |
| 공유용 **결산** 카드 | **주**와 **월**, **게시물**(4:5) 또는 **스토리**(9:16)로. 큰 숫자는 연속 기록이나 코딩 시간입니다 | **년**과, 큰 숫자로 토큰이 추가됩니다 |
| Pro 위젯 | **Nomo 활동** 소형(연속 기록) | 5개 모두, 모든 크기 |
| **세션** 탭 | 컴퓨터 목록. 컴퓨터마다 에이전트가 지금 무엇을 하는지 한 줄로 표시됩니다 | 실시간 세션을 하나씩 표시 |
| Dynamic Island와 잠금 화면의 실시간 현황 | | ✓ |
| 권한 요청과 질문에 응답, 답장, 턴 중단, 전체 텍스트 보기 | | ✓ |
| Cursor 대시보드에서 가져오는 Cursor와 Grok Bot 활동 | | ✓ |

**Nomo** 상태 위젯과 **Nomo 사용량** 위젯은 누구나 무료로 쓸 수 있습니다.
[모든 위젯](/ko/widgets)을 참고하십시오.

<Note>
  무료 페어링은 Pro 페어링보다 컴퓨터에서 보내는 데이터가 적습니다. 정확히
  무엇을 보내는지는 플러그인 README의
  [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer)에
  있습니다.
</Note>

## 무료로 시작하기

<Steps>
  <Step title="플러그인 설치">
    컴퓨터에 Nomo 플러그인을 설치합니다. [설치](/ko/setup/install)를
    참고하십시오.
  </Step>

  <Step title="컴퓨터 페어링">
    Nomo에서 **홈**의 **Mac 연결** 또는 **세션**의 **+**를 탭합니다.
    [페어링](/ko/setup/pairing)을 참고하십시오.
  </Step>

  <Step title="평소처럼 코딩">
    평소처럼 에이전트를 사용하십시오. 연속 기록과 코딩 시간이 Nomo의 **홈**에
    표시됩니다.
  </Step>
</Steps>

## 다른 컴퓨터 사용하기

Nomo Free에서는 컴퓨터 1대를 페어링할 수 있습니다. 다른 컴퓨터로 바꾸려면 먼저
지금 컴퓨터를 삭제합니다.

<Steps>
  <Step title="지금 컴퓨터 삭제">
    Nomo에서 **세션**을 엽니다. 컴퓨터를 길게 터치한 다음 **이 컴퓨터 삭제**를
    탭합니다.
  </Step>

  <Step title="확인">
    **이 컴퓨터 삭제**를 한 번 더 탭합니다.
  </Step>

  <Step title="새 컴퓨터 페어링">
    첫 번째 컴퓨터와 같은 방법으로 페어링합니다.
    [페어링](/ko/setup/pairing)을 참고하십시오.
  </Step>
</Steps>

여러 대를 동시에 쓰고 싶다면 Nomo Pro를 이용하십시오.

## Nomo Pro 추가하기

**세션** 탭에서 컴퓨터를 탭하면 Nomo Pro가 더하는 기능을 볼 수 있습니다.

컴퓨터 페어링은 그대로 유지됩니다. 구독하면 1분 정도 안에 실시간 세션이
시작됩니다.
