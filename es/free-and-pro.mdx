Vincular un ordenador a Nomo es gratis. Tu racha, tu tiempo programando y el
estado de cada ordenador también son gratis.

Nomo Pro es la parte en tiempo real: tus sesiones en directo en la pantalla de
bloqueo y en la Dynamic Island, y responder a tus agentes desde el teléfono.

El estado, el uso y las alertas no necesitan ningún ordenador. Consulta
[Estado y uso](/es/status-usage).

## Qué incluye cada uno

| | Gratis | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| Vincular un ordenador | ✓ | ✓ |
| Tu racha, la actual y la más larga. Cuentan todos los agentes | ✓ | ✓ |
| Historial de actividad (el mapa de calor) | Últimos 30 días | Todo |
| Tiempo programando, hoy y esta semana | ✓ | ✓ |
| Tokens: totales, gráficos, por modelo o por agente | | ✓ |
| Tarjeta Wrapped para compartir | **Semana** y **Mes**, como **Publicación** (4:5) o **Historia** (9:16). El número grande es tu racha o tu tiempo programando | Añade **Año**, y los tokens como número grande |
| Widgets Pro | **Actividad de Nomo**, tamaño pequeño (tu racha) | Los cinco, en todos los tamaños |
| Pestaña **Sesiones** | Tus ordenadores, cada uno con una línea que dice qué están haciendo sus agentes ahora | Cada sesión en directo, una a una |
| Dynamic Island y actividad en directo en la pantalla de bloqueo | | ✓ |
| Responder solicitudes de permiso y preguntas, contestar, detener un turno, leer el texto completo | | ✓ |
| Actividad de Cursor y Grok Bot, desde tu panel de Cursor | | ✓ |

Los dos tienen el mismo límite de 5 ordenadores vinculados.

El widget de estado **Nomo** y el widget **Uso de Nomo** son gratis para todos.
Consulta [Todos los widgets](/es/widgets).

<Note>
  Una vinculación gratis envía menos datos desde tu ordenador que una Pro. Qué
  envía exactamente está en el README del plugin, en
  [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer).
</Note>

## Empezar gratis

<Steps>
  <Step title="Instala el plugin">
    Instala el plugin de Nomo en tu ordenador. Consulta
    [Instalación](/es/setup/install).
  </Step>

  <Step title="Vincula tu ordenador">
    En Nomo, abre **Sesiones** y toca **Vincular un ordenador**. Consulta
    [Vinculación](/es/setup/pairing).
  </Step>

  <Step title="Programa como siempre">
    Usa tu agente como siempre. Tu racha y tu tiempo programando aparecen en
    **Inicio**, en Nomo.
  </Step>
</Steps>

## Añadir Nomo Pro

En la pestaña **Sesiones**, toca uno de tus ordenadores para ver qué añade
Nomo Pro.

Tus ordenadores siguen vinculados. Cuando te suscribas, las sesiones en directo
empiezan en más o menos un minuto.
