**用量**的用法和[状态](/zh-Hans/status)一样 —— 一个小组件加一套通知 —— 只多一步：它要从你的账号里读数字，所以需要登录一次。Mac 上依然什么都不用装，这一块也只在手机上跑。

## 支持哪些服务商

六家：**Claude**、**Codex**、**Cursor**、**xAI**、**Antigravity** 和 **Kimi**——[状态](/zh-Hans/status)覆盖的服务商里，只有只看状态的 DeepSeek 不在其中。

六家也都能在各自窗口的 70%、90%、100% 给你**提醒**——见[用量提醒](/zh-Hans/notifications#usage-alerts)。

两个小组件之间有一处名称不同。用量这边显示 **Codex**，而状态那边盯的是整个 **OpenAI**——你消耗的是 Codex 的套餐，会挂掉的却是 OpenAI。

**Antigravity** 读的是你的 **Google Antigravity** 配额，包括单独的 **Claude & GPT** 限额，走 Google 登录，而不是你粘贴的令牌。

**Kimi** 读的是你 **Kimi Code** 套餐的 5 小时限额和每周限额。连接时会显示一个短码，在 Kimi 的登录页面上批准就完成了。

## 登录 {#signing-in}

在**服务商**标签页里打开对应的服务商，接上你本来就在付费的那个账号。Nomo 读到的，就是这个账号自己能看到的那些数字 —— 它不是 API key，你也不用往里粘贴任何东西。

<Note>
  **你的登录信息只留在手机上。**令牌保存在设备的钥匙串里，并且只会发给它所属的那家服务商 —— Claude 的令牌只发给 Anthropic，OpenAI 的令牌只发给 OpenAI。用量在设备本地获取，绝不经过 Nomo 的服务器。
</Note>

Nomo 是非官方应用，与它读取数据的任何一家服务商都没有关联。

### Cursor 和 Grok {#cursor-and-grok}

Cursor 和 Grok 通过 Safari 登录，所以你的通行密钥、密码管理器，以及已经在 Safari 里登录的账号都能直接用。

**Cursor**

1. 轻点“连接”。
2. iOS 会询问是否允许使用 **cursor.com** 登录。轻点“继续”。
3. 在 Cursor 的页面上登录。

页面会自动关闭，接着就会显示用量。大约每 60 天需要重新登录一次。

**Grok**

1. 轻点“连接”。
2. iOS 会询问是否允许使用 **x.ai** 登录。轻点“继续”。
3. xAI 的页面会打开，Nomo 会显示一个短码，例如 `ABCD-1234`。
4. 确认它和 xAI 页面上的代码一致。
5. 在 xAI 的页面上批准。

Nomo 会自动续期 Grok 的登录。

查看 Grok 用量需要付费 Grok 套餐，例如 SuperGrok 或 X 订阅。免费账号会保持连接，但不会显示用量条，而是显示“查看 Grok 用量需要付费 Grok 套餐”。

<Note>
  更新到 Nomo 2.4.0 后，请再登录一次 Grok。之前的 Grok 登录不会保留。
</Note>

## 用量速度 <span className="pro-pill" /> {#pace}

有了 Nomo Pro，“用量”页面的每个限额下面会多出一行，告诉你用量能不能撑到限额重置。

<Frame caption="两个限额都用得比时间过得快，所以两行都是琥珀色。">
  <div className="device-frame">
    <img className="only-light" src="/images/usage-pace-light.webp" alt="Claude 的“你的用量”卡片：会话为 82%，下面一行是 82% used · 60% time · Runs out in ~39m；每周为 68%，下面一行是 68% used · 39% time · Runs out in ~1d 7h，两行都是琥珀色" />
    <img className="only-dark" src="/images/usage-pace-dark.webp" alt="Claude 的“你的用量”卡片：会话为 82%，下面一行是 82% used · 60% time · Runs out in ~39m；每周为 68%，下面一行是 68% used · 39% time · Runs out in ~1d 7h，两行都是琥珀色" />
  </div>
</Frame>

这一行开头是两个数字，例如 `已用 45%・时间 60%`：

- **已用**：限额已经用了多少。
- **时间**：这个时段已经过去了多少。

已用比时间低，就没问题。数字后面会显示下面其中一种：

- “够用到重置”：没问题。
- “用完倒计时”和剩余时间：显示为琥珀色。照现在的速度，你会在重置前用完。前面带 `~` 表示这是估算。
- “现在还看不出来”：时段才刚开始。
- “已达限额”：整个限额已经用完。

这一行跟随**设置 → 用量 → 用量显示方式**。选**剩余**时，显示 `剩余 55%・剩余时间 40%`。

部分 Cursor 套餐没有用量速度。这些限额下面不会显示这一行。

在主屏幕上，[Nomo 用量速度](/zh-Hans/widgets#nomo-pace)小组件会显示同样的内容。

**没有 Nomo Pro 时**，第一个限额下面只会显示一行“看看会不会在重置前用完”，旁边有 **PRO** 标签。轻点它会打开 Nomo Pro。

## 达到限额时 {#when-you-hit-a-limit}

任何一个窗口到了 100%，用量卡片下方就会出现一条**已达限额**提示，上面只有一个按钮——**在 Claude 管理用量**，或者换成你正在看的那家服务商。它会在浏览器里打开那家服务商自己的用量设置，你的套餐也许能在那里获得额外用量。

Nomo 看不到那边提供些什么，自己也不卖任何东西。它只是一条捷径，省得你自己去找那个页面。

这条提示对 Claude、Codex、Cursor 和 xAI 显示，且仅限美国、欧盟和日本的 App Store 账号。

## 多个账户 <span className="pro-pill" /> {#more-than-one-account}

### 添加其他账户 {#add-another-account}

1. 打开 Nomo。
2. 轻点“服务商”标签页。
3. 轻点服务商，例如 **Claude**。
4. 轻点顶部的“用量”。
5. 确认你已经登录了第一个账户。
6. 在你的账户下方，轻点“添加其他账户”。
7. 轻点“继续”。
8. 用另一个账户登录。请使用与第一个账户不同的邮箱。

Nomo 会打开一个全新的私密登录页面，所以不会沿用你已经登录的账户。已经添加的账户会保持登录。

如果是 Claude，登录后 Claude 会显示一个代码：

1. 复制代码。
2. 回到 Nomo。Nomo 会自动粘贴代码并连接。
3. 如果没有反应，轻点“粘贴”，再轻点“连接”。

如果服务商提供邮箱，新账户会以邮箱地址命名。如果你登录的账户已经在 Nomo 里，会显示“此账户已添加”，什么都不会改变。

一个服务商有 5 个账户后，“添加其他账户”会变成灰色。

### 管理账户 {#manage-accounts}

轻点账户旁边的 **···**，然后轻点以下其中一项：

- “重命名”：给账户起个短名字，例如 `工作` 或 `个人`。
- “设为默认”：把它设为默认账户。默认账户带有“默认”标签。
- “移除”：在 Nomo 中退出这个账户。其他账户会保持登录。原本显示它的小组件会显示“账户已移除”，并提示你选择其他账户。它们不会改为显示默认账户。

顶部的“你的用量”卡片打开时显示默认账户。要在这里查看其他账户，在列表中轻点该账户。正在显示的账户会以浅色突出显示。

### 小组件中的账户 {#accounts-in-widgets}

除非你另选一个，小组件会显示默认账户：

1. 按住小组件。
2. 轻点“编辑小组件”。
3. 轻点“账户”，选一个。

[Nomo 用量](/zh-Hans/widgets#nomo-usage)和 [Nomo 用量速度](/zh-Hans/widgets#nomo-pace)都有“账户”选项。[Nomo 账户](/zh-Hans/widgets#nomo-accounts)会一次显示所有账户。

### 没有 Nomo Pro 时 {#without-nomo-pro}

没有 Nomo Pro 时，每个服务商只能有一个账户。“添加其他账户”旁会显示 **PRO** 标签。轻点它会打开 Nomo Pro。订阅后，Nomo 会直接继续添加账户。演示模式不会解锁额外的账户。

如果你的 Nomo Pro 到期，额外的账户会被暂停，不会被移除。它们会显示“已暂停 · PRO”，只有默认账户会继续更新。默认账户永远不会被暂停。轻点已暂停的账户会打开 Nomo Pro。要接着使用，轻点“重新订阅”。

设为已暂停账户的 Nomo 用量小组件会显示“已暂停 · Nomo Pro”和 `你的 Nomo Pro 已结束。在 Nomo 中重新订阅即可查看此账户。`。轻点它会打开 Nomo Pro。
