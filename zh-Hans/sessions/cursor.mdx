Cursor 的会话出现在同一个列表里、同一个灵动岛上，走同一份配对——无论来自 Cursor 桌面应用里的智能体，还是来自 `cursor-agent` CLI。在这个版本里它们是**只读**的：你在手机上看着 Cursor 的会话，在电脑上答复它。

<Note>
  会话功能属于 Nomo Pro，Cursor 和其他每个智能体都一样。Cursor 会话还需要你手机上的 Nomo 是最新版本。
</Note>

## 相同的部分 {#what-works-the-same}

会话、文件夹和[灵动岛](/zh-Hans/sessions/island)的用法和其他智能体一样。共用的内容都集中在一处：

- **安装** → [安装](/zh-Hans/setup/install)，**Cursor** 标签页。一次安装同时覆盖桌面应用和 `cursor-agent`。
- **配对** → [配对](/zh-Hans/setup/pairing)。一次配对覆盖这台电脑上的所有智能体。
- **命令、更新和卸载** → [命令](/zh-Hans/sessions/commands)，包括 [update](/zh-Hans/sessions/commands#update) 和 [uninstall](/zh-Hans/sessions/commands#uninstall)。
- **每个智能体能做什么** → [功能一览](/zh-Hans/sessions/features)。
- **出了问题** → [故障排查](/zh-Hans/sessions/troubleshooting)。

## 四个 skill，没有 approvals 命令 {#four-skills-no-approvals-command}

Nomo 的 Cursor 命令是不带前缀的 skill。在 Cursor 里输入 `/` 来挑选：`/nomo-pair`、`/nomo-status`、`/nomo-reset` 和 `/nomo-unpair`。

Cursor 没有 approvals 命令——没有远程审批可以暂停。

## 会显示的内容 {#what-you-see}

- 会话在你发出一个聊天的**第一条提示**时出现——只是打开聊天并不会出现。
- 聊天、窗口或 CLI 关闭时，它会被移除。
- 标题是 Cursor 给这个聊天起的名称——也就是聊天标签页和历史记录里的那个。它一开始是你的第一条提示，在这一轮进行中或结束后不久，换成 Cursor 起的名称。
- 模型徽标显示的是 Cursor 报告的模型。

## 这个版本的限制 {#what-this-version-doesnt-do}

- **没有远程审批**。你没法在手机上**允许**或**拒绝** Cursor 的 Run / Skip 请求，手机也不会显示 Cursor 正在等你。Cursor 没有把这些开放给插件。
- **没有提问和计划审批**。Cursor 的提问和计划审批不会显示，也没法在手机上答复。
- **没有“在 Mac 上打开”**。这个按钮在 Cursor 会话上不可用。
- **没有“停止”**。[**停止**](/zh-Hans/sessions/list#interrupt-a-running-session)按钮在 Cursor 会话上同样不可用。
- **没有云端智能体**。Cursor 的云端智能体和后台智能体不会显示——只显示在你 Mac 上运行的智能体。
- **标题可能一直是你的第一条提示**。如果读不到 Cursor 给聊天起的名称，标题就保持第一条提示——这一轮结束后，Nomo 还会继续检查大约两分钟。用 `cursor-agent` CLI 运行的聊天，标题始终是第一条提示。Nomo 只从 Cursor 的本地数据库读取聊天名称，其中的其他内容一概不会发送。
- **崩溃可能留下一个会话**。如果 Cursor 被强制退出或崩溃，会话不会立刻结束。会停多久、怎么清掉，见[故障排查](/zh-Hans/sessions/troubleshooting)。

如果有东西没有显示出来，先看[故障排查](/zh-Hans/sessions/troubleshooting)里关于 Cursor 的那几条。

## 技术细节与安全 {#technical-details-and-security}

Nomo 只把会话在做什么发到你的手机，并且端到端加密。

内部如何运作，见插件的 README：[Nomo 如何与 Cursor 配合](https://github.com/KarrixLee/nomo#cursor-integration)、[hook 与安全](https://github.com/KarrixLee/nomo#cursor-hooks)。
