**会话**标签页列的是**电脑**，不是会话。每台配对过的 Mac 一张卡片。会话在下面一层——轻点一台电脑就能打开。

这一点常让人意外：不少人打开这个标签页找刚起的会话，怎么也找不到。它就在卡片上，藏在计数里。

## 电脑列表 {#the-computer-list}

每张卡片上有电脑名称、一行摘要，以及一个表示连接状态的彩色圆点。

| 圆点 | 摘要文字 | 含义 |
| --- | --- | --- |
| 绿色 | `最近活跃` | 这台 Mac 在过去 10 分钟内有过动静。 |
| 灰色 | `没有近期活动` | 配对正常，只是没在干活。 |
| 琥珀色 | `重新连接中…` | 上一轮轮询时，Nomo 没能通过中继服务器联系上这台电脑。它会自己重试。 |
| 转圈 | `正在连接…` | 刚配对好，还在等第一个会话到达。 |
| 灰色 | `已解除配对` | 这份配对已被替换或移除。见[故障排查](/zh-Hans/sessions/troubleshooting)。 |
| 灰色 | `已暂停——续订以重新连接` | Nomo Pro 已失效。 |

摘要文字会写成 `没有进行中的会话`、`1 个会话`，或者 `3 个进行中 · 共 7 个会话`。“进行中”不算已完成的会话、读不出来的会话，以及那些声称在干活、却已经超过 10 分钟没动静的会话。

右上角有一个角标，显示你配对了多少台电脑。到达上限时它会变成橙色。

<Note>
  按住卡片可以**重命名**或**移除此电脑**。重命名只在你手机上生效。移除后这台电脑不再出现在这里——你随时可以重新配对，而且 Mac 上什么都不会动。
</Note>

## 电脑内部 {#inside-a-computer}

轻点卡片会打开一个详情页，顶部是一个分段控件，每个智能体一段：**Claude Code**、**Codex** 和 **OpenCode**。Nomo 会打开最近活跃的那个智能体。

里面的会话按**项目文件夹**分组，文件夹的 git 分支显示在分组标题旁边。只有一个文件夹时，就是一张**会话**卡片；两个及以上时，每个文件夹各一张，以文件夹命名。

顶部的电脑名称下面会写着它是 `进行中`、`上次活动` 还是 `重新连接中…`——如果 Nomo 是绕开中继服务器、直接通过你的网络和这台 Mac 通信的，那里还会有一个绿色的 **⚡ 本地**角标。见[本地网络](/zh-Hans/sessions/settings#local-network)。

## 会话行的组成 {#what-a-session-row-shows}

<ResponseField name="状态图标" type="左侧">
  一个圆点、一只手、一个对勾，或者一个转圈。**颜色**才是信号——见下面的表格。
</ResponseField>

<ResponseField name="标题">
  智能体自己对手头工作的概括，所以它会随着会话切换任务而变化。它**不是**文件夹名——只有在智能体还没概括出任何东西时，才会退回用文件夹名顶上。
</ResponseField>

<ResponseField name="状态行">
  状态，外加智能体报告过的当前动作——`运行中 · 编辑中`、`需要权限 · Bash`。
</ResponseField>

<ResponseField name="相对时间">
  距**最后一个事件**过了多久，而不是会话已经跑了多久。`2m ago` 的意思是 Nomo 上一次收到它的消息在两分钟前。已运行时长只出现在[灵动岛](/zh-Hans/sessions/island)上。
</ResponseField>

<ResponseField name="开关" type="右侧">
  把这个会话放到灵动岛上。默认关闭——见[设置](/zh-Hans/sessions/settings#dynamic-island)。
</ResponseField>

## 会话状态 {#session-states}

| 标签 | 颜色 | 含义 |
| --- | --- | --- |
| `运行中` | 橙色圆点 | 正在干活。不需要你做什么。 |
| `需要关注` | 橙色的手 | 已经停下等你，而且手机上没有你能答复的东西。 |
| `需要权限 · Bash` | 紫色的手 | 正在为某个具体操作请求权限。**这种你可以在这里答复**——见[在手机上回答](/zh-Hans/sessions/approvals)。 |
| `需要回答` | 紫色的手 | 正在问一道选择题。同样可以在手机上答复。 |
| `完成` | 绿色对勾 | 会话结束了。 |
| `重新连接中…` | 琥珀色 | 要么是 Mac 在会话途中和中继服务器断了，要么是 Nomo 还没能解开这一行。都是暂时的，它会重试。 |
| `无法获取` | 灰色圆点 | 过了 10 分钟仍然解不开的行。它会显示成 `加密会话`。 |
| `发送中…` | 转圈 | 你的答复正在发往 Mac 的路上。 |

一条请求有了结果之后，这一行会带上一句小字说明它是怎么结束的：`已允许`、`已拒绝`、`已设为始终允许`、`已回答`，或者一个诚实的失败，比如 `已过期——请在电脑上继续`。完整清单在[在手机上回答](/zh-Hans/sessions/approvals#what-the-caption-tells-you)。

会话行按最近活动排序。Nomo 从不隐藏任何一行——这个列表原样映射中继服务器上的内容。

## 展开详情 {#tap-a-row-for-detail}

轻点会话行的文字那一侧就会展开。这里的内容都可以选中，而且用符号而不是文字来标注：

- **模型**——`Fable`、`Opus 4.8`、`GPT 5.6 Sol`。智能体没报告时不显示。
- **完整标题**——不截断。
- **文件夹**和**会话 ID**——ID 取前八位，等宽字体。
- **待答复的问题**，有的话就完整显示。
- **查看计划**——打开计划。Claude Code 的可以答复，[Codex](/zh-Hans/sessions/codex) 的只能读，[OpenCode](/zh-Hans/sessions/opencode#plan-mode) 的通常是这个会话的待办清单，而不是一份文档。
- **在 Mac 上打开**——把这个会话的终端窗口在 Mac 上调到最前。只有当 Nomo 有一条直连的[本地网络](/zh-Hans/sessions/settings#local-network)链路时才会出现，而且 [OpenCode](/zh-Hans/sessions/opencode#no-open-on-mac) 会话上永远不会出现，因为它们没有自己的窗口。

<Tip>
  想**答复**一条请求，请按住这一行，而不是轻点。轻点是展开；按住才会打开“允许 / 拒绝”菜单。
</Tip>

## 数量上限 {#how-many}

| | 上限 |
| --- | --- |
| 每台电脑的会话数 | **20** 个，所有智能体合计 |
| 已配对的电脑数 | **5** 台 |
| 灵动岛上的会话数 | **同时 1 个**，全设备范围 |

这两个数字都放在 Nomo 服务端，没有编进 App 里，所以不更新 App 也能调整。会话计数以 `N/20` 角标显示在第一张会话卡片上，电脑计数以 `N/5` 角标显示在标签页上。两者到达上限都会变橙。

配对第六台电脑会失败，提示**已达电脑数量上限**。移除一台你不再用的，然后再试——已经配对的电脑绝不会为了腾位置而被撤销。

一台电脑的会话数到顶时，Nomo 会先清掉已完成的和长时间没动静的行。真正的新会话会被拒绝，而不是把一个还活着的挤下去——除非它是带着权限请求来的，那种永远优先。

## 自动消失的行 {#rows-that-disappear}

已完成和长时间没动静的会话会自己退出，大约在最后一次真实活动之后一小时。某一行自己消失是正常的，不代表哪里出了问题。

被撤销的配对是另一回事——你重新配对了那台 Mac，或者在上面运行了 [`/nomo-cc:unpair`](/zh-Hans/sessions/commands#unpair)。Nomo 会等到连续多次失败之后才相信这件事，然后把卡片翻成 `已解除配对`，附带一个轻点一下就能用的**移除**按钮，一分钟后清掉。它不会因为 Wi-Fi 抖了一分钟就悄悄丢掉一台电脑。
