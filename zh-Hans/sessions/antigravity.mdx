在 iPhone 上看你的 Google Antigravity 会话——锁定屏幕上、灵动岛里都能看到。Antigravity 想运行命令或改动文件时，手机会问你要**允许**还是**拒绝**。你还可以在手机上停止一个会话，或者给它发消息。

Antigravity 桌面应用和 `agy` 命令行工具都支持。

<Note>
  会话功能属于 Nomo Pro。你需要手机上的 Nomo **2.3.5** 或更高版本，以及 Mac 上的插件 **2.3.5** 或更高版本。
</Note>

## 配置步骤 {#set-it-up}

<Steps>
  <Step title="打开终端">
    在 Mac 上打开**终端** App。它在**应用程序 → 实用工具**里。
  </Step>

  <Step title="运行安装工具">
    复制下面这一行，粘贴到终端里，然后按回车：

    ```bash
    bunx nomo-ai --antigravity
    ```

    没有 `bunx`？改用 `npx nomo-ai --antigravity`。

    你应该会看到：

    ```
    ✅ Antigravity is connected to Nomo. Restart Antigravity, then type /nomo-pair.
    ```
  </Step>

  <Step title="重启 Antigravity">
    完全退出 Antigravity，再重新打开。如果你用 `agy`，也把它关掉再重新启动。

    <Warning>
      别跳过这一步。Antigravity 重启之前，Nomo 不会生效。
    </Warning>
  </Step>

  <Step title="输入 /nomo-pair">
    在 Antigravity 的对话里输入下面这条并发送：

    ```
    /nomo-pair
    ```
  </Step>

  <Step title="选择 Allow">
    Antigravity 运行 Nomo 命令前会先问你。选择 **Allow**（允许）。

    你应该会看到浏览器里打开一个带二维码的页面。
  </Step>

  <Step title="扫描二维码">
    在 iPhone 上打开 Nomo → **会话** → **配对电脑**，扫描这个二维码。

    你应该会在 Antigravity 里看到：“Done! This computer is connected to your phone.”（完成！这台电脑已连接到你的手机。）
  </Step>

  <Step title="在 Antigravity 里发一条消息">
    开始一个对话，随便发点什么。

    你应该会看到这个会话出现在 Nomo 里，在你这台电脑的 **Antigravity** 标签页下。没有 Antigravity 标签页？轻点 **+** 按钮（**选择智能体**），把 Antigravity 打开。

    <Frame caption="从 + 按钮打开的“选择智能体”。Antigravity 已勾选，所以它有自己的标签页。">
      <div className="device-frame">
        <img className="only-light" src="/images/agent-chooser-antigravity.png" alt="“选择智能体”菜单，Claude Code、Codex 和 Antigravity 已勾选，OpenCode 和 Cursor 未勾选" />
        <img className="only-dark" src="/images/agent-chooser-antigravity-dark.png" alt="“选择智能体”菜单，Claude Code、Codex 和 Antigravity 已勾选，OpenCode 和 Cursor 未勾选" />
      </div>
    </Frame>
  </Step>
</Steps>

<Tip>
  **已经在 Claude Code、Codex、OpenCode 或 Cursor 里配对过？**一次配对覆盖整台电脑。跳过第 4–6 步——安装工具会改为提示你“type /nomo-status to check”（输入 /nomo-status 检查一下）。
</Tip>

<Tip>
  **这台电脑上没有浏览器？**改为输入 `/nomo-pair code`。Antigravity 会显示一段短码。在 iPhone 上打开 Nomo → **会话** → **配对电脑** → **输入代码**，把它输进去。这段代码 10 分钟后失效。
</Tip>

<Warning>
  **不要把 Nomo 的 Claude Code 插件导入 Antigravity**（比如用 `agy plugin import claude`）。否则每个会话都会出现两次。如果你已经导入了，安装工具会提醒你：

  ```
  ⚠️ Antigravity also has the Claude Code version of Nomo ("nomo-cc") imported. It would show every session twice — please remove it by running: agy plugin uninstall nomo-cc
  ```

  要修复，在终端里运行下面这条，然后重启 Antigravity：

  ```bash
  agy plugin uninstall nomo-cc
  ```
</Warning>

## 命令 {#commands}

在 Antigravity 的对话里输入这些。每次 Antigravity 都会先问你——选择 **Allow**。

| 输入 | 作用 |
| --- | --- |
| `/nomo-pair` | 把这台电脑连接到你的手机 |
| `/nomo-pair code` | 同上，但改用一段短码代替二维码 |
| `/nomo-status` | 检查一切是否正常 |
| `/nomo-status verbose` | 同上，显示全部细节 |
| `/nomo-approvals off` | 不再问手机——改由 Antigravity 在电脑上问你 |
| `/nomo-approvals on` | 重新问手机 |
| `/nomo-approvals status` | 查看手机审批是开着还是已暂停 |
| `/nomo-reset` | 清掉手机上卡住的会话，连接保持不变 |
| `/nomo-unpair` | 断开这台电脑和手机的连接 |

一切正常时，`/nomo-status` 只显示一行，像这样：

```
✅ Connected to your phone as “MacBook Pro” · Phone approvals: on · Last activity: 2 min ago
```

如果有问题，它会多加一行，告诉你该怎么做。

连接和审批开关由这台电脑上的所有编程工具共用。在这里关掉审批，Claude Code 和 Codex 的审批也会一起关掉。

这些命令只在 Antigravity 里询问你，永远不会在手机上弹出卡片。

## 会显示的内容 {#what-you-see}

- 会话在你发出**第一条消息**时出现——只是打开一个对话并不会出现。
- Antigravity 工作时显示**运行中**，结束后显示**完成**。
- 名称是 Antigravity 自己给这个对话起的标题。在它起好之前，会用你的第一条消息，或者文件夹名称。
- 徽标显示 Antigravity 正在使用的模型。
- [灵动岛](/zh-Hans/sessions/island)和其他智能体一样可用。

## 在手机上回答 {#answering-from-your-phone}

Antigravity 想**运行命令**或**创建、改动文件**时，手机会问你。读取和搜索文件永远不会送到手机。

按住那一行会话，或者用灵动岛，然后选择：

  <div className="device-frame">
    <img className="only-light" src="/images/agy-approval-card.png" alt="Antigravity 会话 Fix token refresh race 的审批卡片，请求运行 npm test，带有“拒绝”“允许”和“拒绝并附注…”按钮" />
    <img className="only-dark" src="/images/agy-approval-card-dark.png" alt="Antigravity 会话 Fix token refresh race 的审批卡片，请求运行 npm test，带有“拒绝”“允许”和“拒绝并附注…”按钮" />
  </div>
</Frame>

- **允许**——Antigravity 继续执行。
- **拒绝**——Antigravity 跳过这一步，接着往下做。
- **拒绝并附注…**——跳过这一步，并用你自己的话告诉 Antigravity 原因。

更多内容见[在手机上回答](/zh-Hans/sessions/approvals)。

小提示：

- **你自己的 Antigravity 规则优先。**被你的规则拦下的操作始终会被拦下——在手机上轻点允许也推翻不了。在 `agy` 里，你的规则已经允许的命令会直接运行，不会问手机。
- **桌面应用里，每样都会问手机。**Nomo 读不到桌面应用的权限设置，所以每条命令、每次文件改动都会送到你的手机。
- **手机不在身边也没关系。**如果手机连不上，或者远程审批已[暂停](/zh-Hans/sessions/approvals#pausing-it)，Antigravity 会在电脑上问你，和没有 Nomo 时一样。
- **在电脑上停掉了对话？**手机上的卡片会自己消失。

## 停止这一轮 {#interrupt}

在**运行中**的 Antigravity 会话上轻点[**停止**](/zh-Hans/sessions/list#interrupt-a-running-session)，就能让它停下。需要绿色的 **⚡ 本地**角标。Antigravity 会做完当前这一步再停下，会话显示**完成**。对话仍然开着——发一条新消息就能接着来。

### 消息下方状态的含义 {#reply-statuses}

| 你看到的 | 含义 |
| --- | --- |
| `发送中…` | 手机正在发送。 |
| `等待下一步` | 你的 Mac 已经收到。Antigravity 会在下一步读到它。在那之前，你可以轻点气泡上的 **×** 取消。 |
| `已送达` | Antigravity 已经读到了。 |
| `正在 Mac 上唤醒…` | 会话已经结束，所以你的 Mac 正带着你的消息重新启动它。这时已经不能取消。 |
| `已在 Mac 上继续` | 会话带着你的消息又跑起来了。 |
| `重新连接中…` | 手机暂时连不上你的 Mac。它会自己一直重试——不用再发一次。 |

### 在哪些情况下能用 {#where-reply-works}

**使用 `agy` 命令行工具时：**

- **正在工作**——消息会在它的下一步送到。
- **已结束，`agy` 已关闭**——你的 Mac 会带着你的消息重新启动会话。你会先看到 `正在 Mac 上唤醒…`，然后是 `已在 Mac 上继续`。
- **已结束，但 `agy` 还开着**——消息会等着。在你于 Mac 上的 `agy` 里发出下一条消息之前，它一直显示 `等待下一步`；发出之后，Antigravity 会把两条一起读到。

**使用 Antigravity 桌面应用时：**

- **正在工作**——消息会在它的下一步送到。
- **已结束**——只能在 Mac 上继续。**回复**会变灰，下面那一行会说明原因。

须知：

- **每条消息最多 4000 个字符。**输入框到这里就不再接收文字。
- **停止永远优先。**如果在有消息排队时轻点[**停止**](#interrupt)，Antigravity 会先停下。这条消息绝不会交给你停掉的那一轮。
- **消息只在 Nomo 开着时保留。**如果你彻底关闭 Nomo，下次打开时表单是空的。你的 Mac 已经收到的消息照样会送到。

## 这个版本的限制 {#what-this-version-doesnt-do}

- **没有提问和计划。**Antigravity 的提问和计划审批不会显示在你的手机上。
- **没有“在 Mac 上打开”。**这个按钮在 Antigravity 会话上不可用。
- **没有“始终允许”。**每次回答都是一次性的**允许**或**拒绝**。

## 卸载 {#uninstalling}

<Steps>
  <Step title="在终端里运行这条">
    ```bash
    node ~/.nomo/plugin/scripts/antigravity-install.mjs --uninstall
    ```

    你应该会看到：

    ```
    ✅ Nomo is removed from Antigravity. Restart Antigravity to finish. Your phone stays connected for your other coding apps.
    ```
  </Step>

  <Step title="重启 Antigravity">
    退出 Antigravity，再重新打开。
  </Step>
</Steps>

如果还想断开这台电脑和手机的连接，请在卸载**之前**在 Antigravity 里输入 `/nomo-unpair`。

## 进阶 {#advanced}

<AccordionGroup>
  <Accordion title="在终端里运行" icon="terminal">
    同样的命令，改在终端里运行，而不是在 Antigravity 对话里：

    | | |
    | --- | --- |
    | 配对 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs` |
    | 用手输代码配对 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs --show-code` |
    | 检查状态 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/status-cmd.mjs antigravity` |
    | 暂停审批 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs off` |
    | 恢复审批 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs on` |
    | 清理卡住的会话 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/reset.mjs` |
    | 解除配对 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/unpair.mjs` |

    给安装工具加上 `--verbose`，可以看到它改了哪些东西。
  </Accordion>

  <Accordion title="工作原理" icon="gear">
    - **安装工具改了什么。**它把插件克隆到 `~/.nomo`，在 `~/.gemini/config/hooks.json` 里加入一个名为 `nomo` 的区块（其他区块原样不动），并把一个小小的 Antigravity 插件 `nomo`——带五条 `/nomo-*` 命令——复制到 `~/.gemini/config/plugins/nomo`。如果 `hooks.json` 不是有效的 JSON，或者那里的 `nomo` 插件文件夹不是它自己的，它会拒绝执行，什么都不改。卸载只删掉那个区块和那个文件夹。
    - **Hook。**`SessionStart`、`PreInvocation`、`PostInvocation`、`Stop` 和 `PostToolUse` 负责上报状态。它们立刻回答 `{}`，在后台完成自己的工作，所以 Antigravity 从不等待 Nomo。一行会话从第一次 `PreInvocation` 开始，而不是 `SessionStart`。
    - **审批。**`PreToolUse` hook 只匹配 shell 命令和文件的写入与编辑（`run_command`、`write_file`、`write_to_file`、`edit_file`、`replace_file_content`、`multi_replace_file_content`），超时时间为 24 小时。允许回答 `auto_approve`；拒绝回答 `deny`，并把你的附注作为理由。其他所有结果都回答 `allow`，也就是把决定交还给 Antigravity 自己的设置和权限请求。`agy` 的 `~/.gemini/antigravity-cli/settings.json` 里任何 `deny` 规则可能匹配的操作永远不会送到手机；被纯前缀 `allow` 规则覆盖、且没有任何 `ask` 规则涉及的调用会直接放行。
    - **故障保护。**每条 hook 命令都会先检查它的脚本是否还在。如果 `~/.nomo` 被移动或删除，它会自己作答，所以永远不会挡住任何操作。审批 hook 里出任何错误，也会退回到 Antigravity 自己的权限请求。
    - **停止。**你的手机设置一个一次性标记；下一次 `PostInvocation` 会结束这一轮。标记存在期间，正在等手机答复的 shell 命令或文件写入会以“Stopped from phone”被拒绝。没用上的标记 10 分钟后丢弃。Nomo 从不向 `agy` 进程发送信号。
    - **没有事件就结束的轮次。**当你取消一轮，或者一次运行退出时，Nomo 会盯着运行 hook 的那个进程和 Antigravity 自己的对话索引，把这一行标为完成。安静 30 分钟的会话会作为最后手段被清掉。卡片还在手机上时取消，卡片会被撤回。
    - **回复。**手机把一条 `send-message` 命令（一个消息 ID 和最多 4000 个字符）加密封装，同时经本地连接和中继服务器发出。Mac 为每条消息写一个只有所有者能读的文件（`<conversation>.<id>.agy-inbox`）。下一次 `PreInvocation` 会把所有排队的消息作为用户消息交给智能体；在这一轮最后一步期间送达的消息，会让这一轮的 `Stop` 继续一次。回执（排队、唤醒中、已送达、已继续、已取消、已拒绝）随会话的加密更新返回。对于已经结束、且 `agy` 已退出的 `agy` 对话，Nomo 会在该对话的文件夹里运行 `agy --conversation <id> --print=<message>`（消息是单独一个参数，从不经过 shell 解析）。已结束但仍开着的 `agy` 会把消息留到它的下一轮——Nomo 绝不会在同一个对话上启动第二个 `agy`。停止标记永远优先：消息绝不会交给正在被停止的那一轮。没人取走的消息一天后删除。Nomo 自己的 `/nomo-*` 命令永远不会在手机上弹出卡片。
    - **标题。**用系统自带的 `sqlite3` 以只读方式读取 Antigravity 的 `conversation_summaries.db`。在它出现之前：用对话记录的第一行，再不行就用工作区文件夹名称。
    - **命令。**`/nomo-*` 命令只运行 Nomo 自己的本地命令——配对、状态、审批开关、重置、解除配对——每条都要先经过 Antigravity 自己的运行命令请求。它们从不输出配对链接或二维码密钥。

    完整细节见插件的 [README](https://github.com/KarrixLee/nomo#install--antigravity)。
