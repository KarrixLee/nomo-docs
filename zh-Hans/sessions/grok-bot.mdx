Nomo 不会把 Grok Bot 的聊天显示成会话。Grok Bot 不在会话列表里，也不在灵动岛上。你能看到的是它的状态、你的用量，以及你用过它的日子和 Token。这些都在 iPhone 上就能用，不需要电脑。

## 能看到什么

| | 套餐 | 需要什么 |
| --- | --- | --- |
| Grok Bot 的状态，显示在小组件和提醒里 | 免费 | 什么都不需要 |
| 你的用量，显示在小组件和提醒里 | 免费 | 在 Nomo 里连接 Cursor |
| 用量速度那一行和 Nomo 用量速度小组件 | Nomo Pro | 在 Nomo 里连接 Cursor |
| Nomo 活动和 Nomo Token 里的 Grok Bot 日子和 Token | Nomo Pro | 在 Nomo 里连接 Cursor |

## 在 iPhone 上 {#iphone-only}

每一项都有自己的页面：

- **状态**：在小组件里选 Cursor 的 **Grok Bot** 服务。见[状态](/zh-Hans/status)和[小组件](/zh-Hans/widget)。
- **用量**：连接 Cursor。见[Cursor 和 Grok](/zh-Hans/usage#cursor-and-grok)。
- **提醒**：见[通知](/zh-Hans/notifications)。
- **用量速度**：见[用量速度](/zh-Hans/usage#pace)和[Nomo 用量速度](/zh-Hans/widgets#nomo-pace)。
- **日子和 Token**：见下一节。

## 把 Grok Bot 计入连续记录 {#streak}

你需要 Nomo 2.4.2 和 Nomo Pro。

<Warning>
  要连接的是 **Cursor**，不是 Grok。在 Nomo 里连接 **Grok** 能看到每周限额，但看不到你用 Grok Bot 的日子和 Token。这些只能通过 Cursor 获取。
</Warning>

<Steps>
  <Step title="连接 Cursor">
    1. 打开 Nomo。
    2. 轻点“服务商”标签页。
    3. 轻点 **Cursor**。
    4. 轻点顶部的“用量”。
    5. 轻点“连接 Cursor 账户”。
    6. iOS 会询问是否允许使用 **cursor.com** 登录。轻点“继续”。
    7. 在 Cursor 的页面上，用你登录 Grok Bot 的同一个账户登录，也就是你的 Grok 或 X 账户。

    页面会自动关闭。已经用这个账户连接过 Cursor？跳过这一步。
  </Step>

  <Step title="打开活动页面">
    打开[活动页面](/zh-Hans/widgets#activity-screen)。它一打开就会获取你用 Grok Bot 的日子和 Token。你也可以下拉再获取一次。
  </Step>

  <Step title="添加小组件">
    添加 Nomo 活动或 Nomo Token 小组件。按住它，轻点“编辑小组件”，轻点“角色”，然后选 **Grok Bot**。见[Nomo 活动](/zh-Hans/widgets#nomo-activity)。
  </Step>
</Steps>

## 怎样才算

- 只要当天 Grok Bot 用了 Token，那一天就算。所以定时例程也算。
- 在 Grok Bot 手机应用里的使用也算。
- Nomo Token 和活动页面会显示 Grok Bot 真实的 Token 数。
- 你自己用 Cursor（在 Cursor 编辑器或它的命令行里）也会显示，单独占一行：**Cursor**。
- 使用 The X Subscription 时，Grok Bot 和 Cursor 共用一个每周限额，Nomo 会显示它。使用旧版 Cursor 套餐时，Grok Bot 有自己的限额，Nomo 读不到它。

## 隐私 {#privacy}

- Nomo 只读取每小时的 Token 数。它从不读取你的消息，也不读取你写的任何内容。
- 这些数字直接从 Cursor 的服务器发到你的手机，不会上传到任何地方。
- 你的 Cursor 登录信息保存在 iPhone 的钥匙串里，只会发给 Cursor。

想停止的话，在“服务商”标签页打开 Cursor，轻点“用量”，再轻点“断开连接”。这样 Nomo 里的 Cursor 用量也会一起停止。
