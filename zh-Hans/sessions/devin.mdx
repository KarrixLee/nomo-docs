在 iPhone 上看你的 Devin 会话——锁定屏幕上、灵动岛里都能看到。Devin 请求权限时，手机会问你要**允许**还是**拒绝**。Devin 向你提问时，也可以在手机上回答。

支持 Devin CLI，也就是终端里的 `devin` 命令，以及 [Devin Desktop](#devin-desktop)。

<Note>
  会话功能属于 Nomo Pro。你需要手机上的 Nomo **2.5.0** 或更高版本，以及 Mac 上的插件 **2.5.0** 或更高版本。
</Note>

## 配置步骤 {#set-it-up}

把 Nomo 加进 Devin 有两种方式：**Devin 插件**，或者 **Nomo 安装工具**。二选一即可。如果两个都装了，Nomo 会用安装工具那一份，插件则保持安静。

        brew install --cask devin-cli

        curl -fsSL https://cli.devin.ai/install.sh | bash

## 命令 {#commands}

在 Devin 里输入这些。用 Devin 插件时，它们以 `/nomo:` 开头，而不是 `/nomo-`——比如 `/nomo:pair`。

| 输入 | 用 Devin 插件时 | 作用 |
| --- | --- | --- |
| `/nomo-pair` | `/nomo:pair` | 把这台电脑连接到你的手机 |
| `/nomo-pair code` | `/nomo:pair code` | 同上，但改用一段要手动输入的短码代替二维码 |
| `/nomo-status` | `/nomo:status` | 检查一切是否正常 |
| `/nomo-approvals off` | `/nomo:approvals off` | 不再问手机——改由 Devin 在 Mac 上问你 |
| `/nomo-approvals on` | `/nomo:approvals on` | 重新问手机 |
| `/nomo-reset` | `/nomo:reset` | 清掉手机上卡住的会话，连接保持不变 |
| `/nomo-unpair` | `/nomo:unpair` | 断开这台电脑和手机的连接 |

如果 Devin 问你要不要运行 Nomo 命令，允许即可。Devin 不认识这些命令？再运行一次安装工具并重启 Devin——或者在终端里运行它们，见[进阶](#advanced)。

连接和审批开关由这台电脑上的所有编程工具共用。在这里关掉审批，Claude Code 和 Codex 的审批也会一起关掉。

## 会显示的内容 {#what-you-see}

- 会话在你发出**第一条消息**时出现。
- Devin 工作时显示**运行中**，结束后显示**完成**。
- 名称是 Devin 自己给这个会话起的标题。在它起好之前，会用你的第一条消息。
- 徽标显示 Devin 正在使用的模型。
- [灵动岛](/zh-Hans/sessions/island)和其他智能体一样可用。

## 在手机上回答 {#answering-from-your-phone}

Devin 请求权限时——比如要运行一条命令——手机会问你。

按住那一行会话，或者用灵动岛，然后选择：

<Frame caption="一个请求运行命令的 Devin 会话。">
  <div className="device-frame">
    <img className="only-light" src="/images/devin-approval-card.png" alt="Devin 会话 Fix token refresh race 的审批卡片，请求运行 bun test，带有“拒绝”“允许”和“拒绝并附注…”按钮" />
    <img className="only-dark" src="/images/devin-approval-card-dark.png" alt="Devin 会话 Fix token refresh race 的审批卡片，请求运行 bun test，带有“拒绝”“允许”和“拒绝并附注…”按钮" />
  </div>
</Frame>

- **允许**——Devin 继续执行。
- **始终允许 …（本次会话）**——Devin 继续执行，在这个会话结束前，同样的操作 Nomo 不会再问你。见[下文](#always-allow)。
- **拒绝**——Devin 不做这件事。
- **拒绝并附注…**——Devin 不做这件事，并收到你写的附注，告诉它原因。

更多内容见[在手机上回答](/zh-Hans/sessions/approvals)。

小提示：

- **Devin 会等你的手机。**如果超时，Devin 会改在 Mac 上问你。
- **手机不在身边也没关系。**如果手机连不上，或者远程审批已[暂停](/zh-Hans/sessions/approvals#pausing-it)，Devin 会在 Mac 上问你，和没有 Nomo 时一样。

### 始终允许 {#always-allow}

**始终允许**只在**本次会话**内有效。会话结束后 Nomo 就会忘掉它，下一个会话会重新问你。

- **简单的命令**按命令名记住。对 `touch b.txt` 选了始终允许，`touch c.txt` 也会被允许——但换一条命令就不行。
- **串起来的命令**——带有 `&&`、`;`、`|` 或 `>` 的命令——每次都会送到手机上，除非和你已经允许过的命令一字不差。所以 `touch x && rm -rf ~` 照样会问你。
- **其他操作**，比如写入文件，在这个会话剩下的时间里都会被允许。

Nomo 把它保存在你的电脑上，从不改动 Devin 自己的设置。即使你暂停了审批，它在会话结束前也依然有效。

### 回答 Devin 的提问 {#questions}

Devin 向你提问时，那一行会话会显示`需要回答`。按住它，选择**回答…**：

1. 轻点一个选项。Devin 允许的话，可以选多个。
2. 都不合适？轻点**其他…**，输入你自己的回答。
3. 轻点**提交**。

**添加附注**可以给回答附上一段说明。**拒绝**会告诉 Devin 你选择不回答。

<Note>
  **在 Mac 上，这个问题会显示为 rejected。这是正常的。**Devin 没法直接从 Nomo 接收回答，所以 Nomo 把你的回答作为关闭 Devin 提问的理由发过去。你会看到问题被标成 **rejected**，旁边写着你的回答。Devin 会读到你的回答，然后继续工作。
</Note>

## 停止这一轮 {#interrupt}

在**运行中**的 Devin 会话上轻点[**停止**](/zh-Hans/sessions/list#interrupt-a-running-session)，就能让它停下。需要绿色的 **⚡ 本地**角标——也就是 iPhone 和 Mac 在同一个网络里。

Devin 会做完当前这一步再停下，没法把一条命令或一段回复从中间切断。会话显示**完成**，Devin 仍然开着——发一条新消息就能接着来。

## Devin Desktop {#devin-desktop}

Devin 的文档说，Devin Desktop 的 **Devin Local** 智能体和 Devin CLI 用的是同一个引擎，所以 Nomo 在那里的用法也一样。Nomo 已经在 Devin CLI 和 Devin 的 ACP 服务器上测试过。

- **手机先回答。**手机上有权限请求或提问时，Devin Desktop 不会显示它自己的按钮。请在手机上回答。想改在 Mac 上回答，就在 Devin 的下一个提示之前[暂停审批](/zh-Hans/sessions/approvals#pausing-it)。
- **哪些会送到手机。**在 Devin Desktop 默认的 **Code** 模式下，Devin 只在运行命令、抓取网页、在项目之外写入之前才会问你。手机上看到的就是这些权限请求。
- **Restricted Mode 会让 Nomo 停止工作。**在你退出它之前，会话不会送到手机。

## Devin 的不同之处 {#whats-different-for-devin}

- **只显示 Mac 上的 Devin。**Devin Cloud 的会话不会出现——Nomo 只显示在你 Mac 上运行的 Devin。
- **短会话可能没有模型徽标。**Devin 只在会话结束时才保存模型。
- **Devin 不支持的功能：**[回复](/zh-Hans/sessions/antigravity#reply-from-your-phone)和**在 Mac 上打开**。

## 出了问题 {#troubleshooting}

<AccordionGroup>
  <Accordion title="手机上什么都没显示">
    1. 关掉每一个开着的 `devin`，再重新启动。
    2. 检查 Nomo。在 Devin 里输入 `/nomo-status`（用插件的话，输入 `/nomo:status`）。

    3. 照着以 `→` 开头的那一行去做。

    用的是 Devin Desktop？确认 **Restricted Mode** 已关闭。

    还是没有？在 Nomo 里轻点 **+** 按钮（**选择智能体**），把 Devin 打开。

    如果 Devin 标签页显示**还没有 Devin 会话**，先在 Devin 里发一条消息——会话只有在你发出第一条消息后才会出现。
  </Accordion>

  <Accordion title="安装工具说我的配置文件里有注释">
    没关系。Nomo 往 Devin 的设置文件里添加内容后，这个文件就留不住注释了，所以安装工具先把你的原始文件另存了一份，就放在它旁边：

    ```
    ~/.config/devin/config.json.nomo-backup
    ```

    你的设置全都还在，只是注释被去掉了。
  </Accordion>

  <Accordion title="Devin 把我的回答显示为 rejected">
    这是正常的。Nomo 把你的回答作为关闭 Devin 提问的理由发过去，所以 Mac 上这个问题会显示为 **rejected**，旁边写着你的回答。Devin 会读到你的回答，然后继续工作。
  </Accordion>

  <Accordion title="Devin Desktop 没有显示权限请求的按钮">
    这个请求在你的手机上。请在手机上回答。想改在 Mac 上回答，就在 Devin 的下一个提示之前[暂停审批](/zh-Hans/sessions/approvals#pausing-it)。
  </Accordion>

  <Accordion title="轻点停止后 Devin 没有马上停下">
    Devin 会先做完当前这一步——已经在运行的命令或回复会一直进行到结束，然后才停下。

    没有**停止**按钮？iPhone 和 Mac 需要在同一个网络里，并且显示绿色的 **⚡ 本地**角标。
  </Accordion>

  <Accordion title="手机不再问我审批了">
    在 Devin 里输入 `/nomo-approvals on`（用插件的话，输入 `/nomo:approvals on`）。

    如果审批本来就是开着的，检查[设置](/zh-Hans/sessions/settings#remote-approvals)里的**在 iPhone 上回答**。
  </Accordion>

  <Accordion title="会话一直卡在运行中">
    在 Devin 里输入 `/nomo-reset`（用插件的话，输入 `/nomo:reset`）。
  </Accordion>
</AccordionGroup>

更多帮助见[故障排查](/zh-Hans/sessions/troubleshooting)。

## 更新 {#updating}

如果你用的是安装工具，再运行一次，然后重启 Devin：

```bash
bunx nomo-ai --devin
```

## 卸载 {#uninstalling}

**Devin 插件：**复制下面这一行，粘贴到终端里，然后按回车：

```bash
devin plugins remove nomo
```

**Nomo 安装工具：**

<Steps>
  <Step title="在终端里运行这条">
    ```bash
    bunx nomo-ai --uninstall --devin
    ```

    你应该会看到：

    ```
    devin-install: removed Nomo's hooks from Devin — restart devin
    ```

    没有 `bunx`？改用 `npx nomo-ai --uninstall --devin`，或者 `node ~/.nomo/plugin/scripts/devin-install.mjs --uninstall`。
  </Step>

  <Step title="重启 Devin">
    关掉每一个开着的 `devin`，再重新启动。
  </Step>
</Steps>

你的手机仍会和你的其他编程工具保持连接。如果还想断开这台电脑和手机的连接，请在卸载**之前**在 Devin 里输入 `/nomo-unpair`。

## 进阶 {#advanced}

<AccordionGroup>
  <Accordion title="在终端里运行命令" icon="terminal">
    同样的命令，改为在终端里运行，而不是在 Devin 的对话里输入（用 Nomo 安装工具时）：

    | | |
    | --- | --- |
    | 配对 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs` |
    | 改用手动输入的配对码配对 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs --show-code` |
    | 检查状态 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/status-cmd.mjs devin` |
    | 暂停审批 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs off` |
    | 恢复审批 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs on` |
    | 清理卡住的会话 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/reset.mjs` |
    | 解除配对 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/unpair.mjs` |

    在终端里开始配对后，运行 `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs wait`，然后扫描二维码。给安装工具加上 `--verbose`，可以看到它改动了什么。
  </Accordion>

  <Accordion title="工作原理" icon="gear">
    - **安装工具改了什么。**它把插件克隆到 `~/.nomo`，并把 Nomo 的条目加进 `~/.config/devin/config.json` 的 `"hooks"` 键。Devin 的其他设置原样不动。它还会把 `/nomo-*` 命令作为 Devin skill 加进 `~/.config/devin/skills/`；你自己的同名 skill 不会被动。再运行一次不会改动任何东西。如果文件里有注释，它会先把文件复制成 `config.json.nomo-backup`。卸载只删掉 Nomo 的条目和 skill。在 `devin` 里输入 `/hooks` 可以看到它加载了什么。
    - **插件添加了什么。**Devin 插件添加同样的两个 hook，以及同样的命令：`/nomo:pair`、`/nomo:status`、`/nomo:approvals`、`/nomo:reset` 和 `/nomo:unpair`。它不添加任何规则、MCP 服务器或智能体，而且只在本地的 Devin 会话里运行，绝不在 Devin Cloud 里运行。只要安装工具的条目还在，插件的 hook 就什么都不发送。
    - **状态。**`UserPromptSubmit`、`PostToolUse`、`Stop` 和 `SessionEnd` 上的 hook 负责上报状态。它什么都不输出，所以既不会挡住提示，也不会改动工具调用——只有一个例外：你轻点**停止**之后，它的下一个 `PostToolUse` 会输出 `{"continue":false}`，结束这一轮。
    - **审批。**`PermissionRequest` 上的 hook 把工具名称及其命令或文件路径发到你的手机，全程端到端加密。只有当你配对的手机针对这一条请求选择了允许时，它才回答 `approve`；拒绝时回答 `block`，并附上你的附注。其他所有情况——未配对、审批已暂停、离线、超时、出错——它都什么都不输出，也就是把决定交还给 Devin 自己的权限请求。
    - **提问。**同一个 hook 在 `PreToolUse`（只针对 `ask_user_question`）上把 Devin 的问题和选项发到你的手机，全程端到端加密。你的回答会以 `block` 的形式传回，理由就是你的回答，Devin 的模型会读到它。
    - **始终允许。**授权保存在 `~/.config/cc-status/sessions/<session>.devin-allow`，只有你自己能读，会话结束时删除。Devin 自己的设置文件从不写入。
    - **不会出现重复的行。**Devin 也会运行 Claude Code 的 hook。Nomo 的 Claude Code 插件在 Devin 里保持安静，所以 Devin 会话绝不会显示成 Claude Code 会话。

    完整细节见插件的 [README](https://github.com/KarrixLee/nomo#install--devin)。
