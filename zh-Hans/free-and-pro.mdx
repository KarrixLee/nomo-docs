用 Nomo 配对电脑是免费的。你的连续记录、编程时长和每台电脑的状态也都免费。

Nomo Pro 是实时的部分：锁定屏幕和灵动岛上的实时会话，以及在手机上回复你的智能体。

状态、用量和提醒完全不需要电脑。见[状态与用量](/zh-Hans/status-usage)。

## 功能对比 {#what-you-get}

| | 免费 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| 已配对的电脑数 | 一台 | 更多 |
| **首页**上的[活动](/zh-Hans/activity)：连续记录和编程时长 | ✓ | ✓ |
| 活动日历 | 最近 30 天 | 最近 26 周 |
| [Token](/zh-Hans/activity#tokens-chart)：总数和图表 | | ✓ |
| [你的回顾](/zh-Hans/activity#wrapped) | **周**和**月** | 增加**年**和 Token |
| 小组件 | 见[免费小组件](/zh-Hans/free-widgets#free-and-pro) | 全部 |
| **会话**标签页 | 你的电脑，每台都有一行说明它的智能体正在做什么 | 每个实时会话，逐一显示 |
| 灵动岛和锁定屏幕上的实时活动 | | ✓ |
| 回复权限请求和问题、回复消息、停止本轮、阅读全文 | | ✓ |
| [Grok Bot 和 Cursor](/zh-Hans/widgets#grok-bot) 的活动 | | ✓ |

<Note>
  免费配对从你的电脑发送的内容比 Pro 配对少。具体发送什么，见插件 README 里的
  [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer)。
</Note>

## 免费开始 {#get-the-free-part}

<Steps>
  <Step title="安装插件">
    在电脑上安装 Nomo 插件。见[安装](/zh-Hans/setup/install)。
  </Step>

  <Step title="配对电脑">
    在 Nomo 中，轻点**首页**上的**配对你的 Mac**。见[配对](/zh-Hans/setup/pairing)。
  </Step>

  <Step title="照常写代码">
    像平时一样用你的智能体。连续记录和编程时长会出现在**首页**的[活动](/zh-Hans/activity)里。
  </Step>
</Steps>

## 换一台电脑 {#use-a-different-computer}

Nomo Free 只连接一台电脑。想换到另一台，先移除旧的那台。

<Steps>
  <Step title="移除旧电脑">
    在 Nomo 中打开**会话**。按住那台电脑，然后轻点**移除此电脑**。
  </Step>

  <Step title="确认">
    再轻点一次**移除此电脑**。
  </Step>

  <Step title="配对新电脑">
    用和第一台一样的方式配对。见[配对](/zh-Hans/setup/pairing)。
  </Step>
</Steps>

想同时用多台电脑？订阅 Nomo Pro。

## 添加 Nomo Pro {#add-nomo-pro}

在**会话**标签页，轻点你的一台电脑，就能看到 Nomo Pro 增加了什么。

你的电脑会保持配对。订阅后，实时会话大约一分钟内就会开始。
