在 Nomo 中配对电脑是免费的。你的连续记录、编程时间和每台电脑的状态也都免费。

Nomo Pro 是实时的那部分：锁定屏幕和灵动岛上的实时会话，以及在手机上回应你的智能体。

状态、用量和通知完全不需要电脑。见[状态与用量](/zh-Hans/status-usage)。

## 功能对比

| | 免费 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| 配对电脑 | ✓ | ✓ |
| 当前连续记录和最长连续记录，每个智能体都算 | ✓ | ✓ |
| 活动历史（热力图） | 最近 30 天 | 全部 |
| 编程时间：今天和本周 | ✓ | ✓ |
| Token：总计、图表、按模型或按智能体 | | ✓ |
| 用于分享的**回顾**卡片 | **周**和**月**，可以是**帖子**（4:5）或**快拍**（9:16）。大数字是你的连续记录或编程时间 | 增加**年**，大数字也可以是 Token |
| Pro 小组件 | **Nomo 活动**小号（你的连续记录） | 全部五个，所有尺寸 |
| **会话**标签页 | 你的电脑列表，每台电脑有一行文字，显示它的智能体现在在做什么 | 逐个显示每个实时会话 |
| 灵动岛和锁定屏幕上的实时活动 | | ✓ |
| 回应权限请求和问题、回复、停止本轮、查看全文 | | ✓ |
| 从 Cursor 控制台获取的 Cursor 和 Grok Bot 活动 | | ✓ |

两者都最多可以配对 5 台电脑。

**Nomo** 状态小组件和 **Nomo 用量**小组件对所有人免费。见[全部小组件](/zh-Hans/widgets)。

<Note>
  免费配对从你的电脑发送的数据比 Pro 配对少。具体发送哪些内容，见插件 README 中的 [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer)。
</Note>

## 免费开始

<Steps>
  <Step title="安装插件">
    在你的电脑上安装 Nomo 插件。见[安装](/zh-Hans/setup/install)。
  </Step>

  <Step title="配对电脑">
    在 Nomo 中打开**会话**，轻点**配对电脑**。见[配对](/zh-Hans/setup/pairing)。
  </Step>

  <Step title="照常编程">
    像平时一样使用你的智能体。你的连续记录和编程时间会显示在 Nomo 的**首页**上。
  </Step>
</Steps>

## 添加 Nomo Pro

在**会话**标签页中轻点你的一台电脑，就能看到 Nomo Pro 增加了什么。

你的电脑会保持配对。订阅后，大约一分钟内实时会话就会开始。
