<Update label="2026年8月11日" description="2.1">
  ## 在 Lock Screen 上答复你的 agent

  **新增**

  - 权限请求会出现在 Lock Screen 和 Dynamic Island 上 —— 不用回到工位就能批准或拒绝
  - 在会话卡片上一眼看到当前套餐和剩余用量
  - **LAN mode**（局域网模式）—— iPhone 和电脑处在同一个 Wi-Fi 下时，更新直接在两者之间传输，依然是端到端加密
  - Grok（xAI）和 Gemini（Google）加入 Claude、OpenAI 和 Cursor 的行列

  **修复**

  - 日文等非拉丁文字在小组件中被截断
  - 小组件、通知和实时活动的布局与稳定性问题
</Update>

<Update label="2026年7月" description="2.0">
  ## Sessions

  **新增**

  - **Sessions**（会话）标签页 —— 扫码配对电脑，在 Lock Screen 和 Dynamic Island 上实时看着 Claude Code 与 Codex 会话运行
  - 进行中、已完成、待你处理三种状态，外加当前模型与会话标题
  - 采用 AES-256-GCM 端到端加密；密钥永不离开你的设备，中继只看得到密文
  - Nomo Pro 解锁实时 Sessions

  **改进**

  - Usage 同时显示 Used（已用）和 Left（剩余）

  **修复**

  - OpenAI 每周用量的统计
</Update>
