<Update label="2026年8月" description="2.2">
  ## OpenCode

  **新增**

  - **OpenCode** 加入 Claude Code 和 Codex——它的会话会实时出现在锁定屏幕和灵动岛上，有自己的标志、配色和字体
  - OpenCode 的权限请求和提问都能在锁定屏幕上允许或拒绝，和另外两个智能体一样。卡片会说明拒绝的后果，因为在 OpenCode 里一旦拒绝，这一轮就结束了
  - OpenCode 会话在规划智能体工作时显示“规划中”，轻点“查看计划”就能打开它的待办列表
  - **一键安装**——`bunx nomo-ai`（或 `npx nomo-ai`）会找出电脑上的 Claude Code、Codex 和 OpenCode，把 Nomo 装进你选中的那些

  **改进**

  - 付费页列出了三个智能体，也说清楚了批准到底是做什么的：你可以在锁定屏幕上直接回答，而不只是收到通知
  - 模型提供方正在重试时，会话会显示“重新连接中…”，不再是一串原始错误

  **安全**

  - 单靠一个 `nomo://` 链接不能再配对电脑了——它会先说明这次配对和要连接的服务器，等你确认
  - 订阅状态会分别报给每一台已配对的电脑，任何一台都不会知道其他电脑的存在
  - 断开 Cursor 连接时会一并清除它的 cookie，不会再留下一个可能悄悄把你重新登录的会话

  **修复**

  - 已配对电脑上显示的“本地”被截断成一个字
</Update>

<Update label="2026年8月19日" description="2.1.1">
  ## 修复与打磨

  **新增**

  - 用量提醒扩展到 **xAI/Grok** 和 **Gemini**，同时支持 Claude 按模型计算的每周上限
  - 可以在手机上读**完整的计划**，不再只有开头一段

  **改进**

  - 所有语言的翻译都做了订正——有些标签意思是错的，还有些对同一个概念用了两种说法
  - 权限卡片先说 agent 想做什么，而不是直接甩出原始的 shell 命令
  - 灵动岛上的会话标题和计时器不会再被挤压或截断
  - iPad 上页面会限制在易读的宽度，不再拉满整个屏幕
  - 安装包更小了

  **修复**

  - 明明有付费的优惠方案，付费页却只显示免费试用
  - Codex 会话里**在 Mac 上打开**不起作用
  - Cursor 的两个用量额度在小号小组件上又能看到了
  - 首次启动引导里的一处崩溃
</Update>

<Update label="2026年8月11日" description="2.1">
  ## 在锁定屏幕上答复你的智能体

  **新增**

  - 权限请求会出现在锁定屏幕和灵动岛上 —— 不用回到工位就能批准或拒绝
  - 在会话卡片上一眼看到当前套餐和剩余用量
  - **LAN mode**（局域网模式）—— iPhone 和电脑处在同一个 Wi-Fi 下时，更新直接在两者之间传输，依然是端到端加密
  - Grok（xAI）和 Gemini（Google）加入 Claude、OpenAI 和 Cursor 的行列

  **修复**

  - 日文等非拉丁文字在小组件中被截断
  - 小组件、通知和实时活动的布局与稳定性问题
</Update>

<Update label="2026年7月14日" description="2.0">
  ## 会话

  **新增**

  - **会话**标签页 —— 扫码配对电脑，在锁定屏幕和灵动岛上实时看着 Claude Code 与 Codex 会话运行
  - 进行中、已完成、待你处理三种状态，外加当前模型与会话标题
  - 采用 AES-256-GCM 端到端加密；密钥永不离开你的设备，中继只看得到密文
  - Nomo Pro 解锁实时会话

  **改进**

  - 用量同时显示已用和剩余

  **修复**

  - OpenAI 每周用量的统计
</Update>
