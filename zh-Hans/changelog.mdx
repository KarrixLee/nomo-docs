  ## 登录会等你回来

  **修复**

</Update>

<Update label="2026年10月18日" description="2.3.1">

  **新增**

<Update label="2026年10月" description="2.3">
  ## Cursor 与停止这一轮

  **新增**

  - **Cursor** 加入 Claude Code、Codex 和 OpenCode——来自 Cursor 桌面应用和 `cursor-agent` 的会话会实时出现在“会话”标签页和灵动岛上，带着 Cursor 自己的聊天标题和模型。这个版本里是只读的：你在手机上看着，在电脑上答复。用 `bunx nomo-ai --cursor` 安装
  - 可以挑一台电脑显示哪些智能体——它详情页里的 **+** 按钮（**选择智能体**）最多选三个标签页
  - 在手机上停掉正在运行的 Claude Code 或 Codex 这一轮——会话行里**在 Mac 上打开**旁边的**停止**。这一轮停下，会话仍然开着：Codex 立刻停，Claude Code 在下一次工具调用处停
  - **停止**需要电脑上的插件 **2.3.0**——请把 Claude Code 和 Codex 的插件都更新
  - **停止**需要打开**本地网络**，并且两台设备在同一个网络上：它走直连，绝不经过中继服务器
  - 设成 Cursor **Grok Bot** 的小组件，现在会用一个会动的 Grok 机器人代替 Cursor 标志。它跟着状态变化：夜里打盹，服务变慢时一脸担心，发生中断时垂头丧气

  **改进**

  - 在 Codex 里按 Esc，手机上立刻就能看到，不用再等 20 秒
  - 插件多注册了三个 Codex hook。更新之后，请在 Codex 里运行 `/hooks` 并信任新增的条目——一共十个
  - 小组件上 Cursor 的状态文字稍微调小了，“严重中断”这类较长的状态更容易放得下

  **修复**

  - 因 API 错误而结束的 Claude Code 这一轮，会显示**运行中**长达半小时。现在会落定为**完成**
  - 某个工具失败后，Claude Code 会话明明已经继续往下走了，却可能还显示在等你
  - 正在等后台子智能体的 Claude Code 会话会一直显示为在干活，不再过早变成**完成**
  - OpenCode 子智能体发来的请求现在会显示在它的会话上，一经答复，会话立刻回到干活的状态
  - 网络慢的时候，灵动岛可能在一轮进行到一半时变陈旧——**已断开？**。现在插件会重发没送到的内容，而且只要 Mac 确认会话还活着，“会话”标签页就会把陈旧的灵动岛拉回来
  - “状态”标签页、提醒和小组件改为跟随 xAI 的新状态页。此前，设成 xAI 某个 API 的小组件，不管你选的是哪一个，显示的都是列表里的第一个 API
</Update>

<Update label="2026年10月10日" description="2.2.2">
  ## 更多回答方式

  **新增**

  - 批准 Claude Code 的计划时，可以选它接下来怎么干——**批准并自动接受编辑**或**批准并使用自动模式**——不再只有普通的批准。Claude Code 的其他请求则多了**批准并切换到自动模式**
  - 用**其他…**输入你自己的回答，还能用**添加附注**给它附上一句说明，不再只能从列表里选
  - 提供自由文本回答的 Codex 问题同样支持**其他…**
  - 带预览的选项，选中时会在列表下方显示预览
  - 以上各项都需要电脑上的插件 **2.2.2**——在装上之前，App 会一直把它们藏起来
  - 某项限额到达 100% 时，“用量”标签页会给出通往那家服务商自己用量设置的链接——**在 Claude 管理用量**——支持 Claude、Codex、Cursor 和 xAI，适用于美国、欧盟和日本

  **改进**

  - 在计划上，**拒绝并附注…**现在写作**继续规划…**，这才是它实际做的事

  **修复**

  - 打开或恢复后停在空提示符的 Claude Code 会话，会显示**运行中**长达半小时。现在大约 20 秒就会落定为**完成**
  - 没有提示就创建出来的 OpenCode 会话——比如 fork 出来的，或由其他客户端打开的——不会再停在**运行中**
  - 用量可能卡在一份旧快照上，还一直把它当作最新数据显示
</Update>

<Update label="2026年8月" description="2.2">
  ## OpenCode

  **新增**

  - **OpenCode** 加入 Claude Code 和 Codex——它的会话会实时出现在锁定屏幕和灵动岛上，有自己的标志、配色和字体
  - OpenCode 的权限请求和提问都能在锁定屏幕上允许或拒绝，和另外两个智能体一样。卡片会说明拒绝的后果，因为在 OpenCode 里一旦拒绝，这一轮就结束了
  - OpenCode 会话在规划智能体工作时显示“规划中”，轻点“查看计划”就能打开它的待办列表
  - **一键安装**——`bunx nomo-ai`（或 `npx nomo-ai`）会找出电脑上的 Claude Code、Codex 和 OpenCode，把 Nomo 装进你选中的那些

  **改进**

  - 付费页列出了三个智能体，也说清楚了批准到底是做什么的：你可以在锁定屏幕上直接回答，而不只是收到通知
  - 模型服务商正在重试时，会话会显示“重新连接中…”，不再是一串原始错误

  **安全**

  - 单靠一个 `nomo://` 链接不能再配对电脑了——它会先说明这次配对和要连接的服务器，等你确认
  - 订阅状态会分别报给每一台已配对的电脑，任何一台都不会知道其他电脑的存在
  - 断开 Cursor 连接时会一并清除它的 cookie，不会再留下一个可能悄悄把你重新登录的会话

  **修复**

  - 已配对电脑上显示的“本地”被截断成一个字
</Update>
