Pairing links one Mac to one iPhone. You do it once per computer.

<Steps>
  <Step title="Install the Nomo plugin in Claude Code">
    {/* TODO: exact marketplace + install command */}

    ```
    /plugin install nomo-cc
    ```

    Restart Claude Code afterward so the plugin's hooks load.
  </Step>

  <Step title="Run the pair command">
    In Claude Code, run:

    ```
    /nomo-cc:pair
    ```

    A QR code appears in your terminal.

    <Tip>
      On Codex, the same command is `$nomo-pair`.
    </Tip>
  </Step>

  <Step title="Scan it with the Nomo app">
    Open Nomo, go to the **Sessions** tab, and tap the pair button. Point the
    camera at the QR code in your terminal.

    {/* TODO: screenshot of the in-app scanner */}
  </Step>

  <Step title="Confirm it worked">
    Your computer appears in the Sessions tab. Back in the terminal, the pair
    command reports success and exits.
  </Step>
</Steps>

## Why a QR code and not a login

The QR code carries an encryption key, not an account token. Your Mac generates
the key, the QR hands it to your phone, and from then on the two of them share a
secret that Nomo's servers never see.

This is why you scan instead of typing a code: the key is too long to type, and
sending it through a server would defeat the point.

## Checking on it later

To see whether a computer is still connected and delivering events:

```
/nomo-cc:status
```

To disconnect a computer and erase its local pairing data:

```
/nomo-cc:unpair
```

## If pairing doesn't take

- **The QR never appears** — the plugin's hooks probably didn't load. Restart
  Claude Code and try again.
- **The scan succeeds but no computer shows up** — run `/nomo-cc:status` to see
  whether events are being delivered at all.
- **The computer shows up but rows look stale or duplicated** — run
  `/nomo-cc:reset` to clear dead session rows without unpairing.
