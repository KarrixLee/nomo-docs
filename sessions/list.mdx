The Sessions tab lists the Claude Code and Codex sessions running on your paired
computers. One row per session.

## What a row tells you

A row carries the session's title, which computer it's on, and its current
state. The title comes from the agent's own summary of what it's working on, so
it changes as the session moves between tasks — it isn't the folder name.

## Rows that disappear

Sessions retire on their own once they've been finished for long enough. A row
vanishing on its own is normal.

A row that goes stale — its computer went to sleep, the terminal was closed —
gets marked rather than silently dropped, so you can tell "this ended" apart
from "this lost contact."

## Multiple computers

Every paired Mac contributes its own sessions to the same list. The row shows
which computer it came from, so two sessions with similar titles stay
distinguishable.
