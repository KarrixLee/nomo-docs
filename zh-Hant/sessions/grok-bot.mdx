Nomo 不會把 Grok Bot 的聊天顯示成 sessions。Grok Bot 不會出現在 Sessions 列表或動態島上。你會看到的是它的狀態、你的用量，以及你使用它的日子和 Token。這些全都在 iPhone 上就能用，不需要電腦。

## 你會得到什麼

| | 方案 | 需要什麼 |
| --- | --- | --- |
| Grok Bot 的狀態，顯示在小工具和提醒裡 | 免費 | 什麼都不需要 |
| 你的用量，顯示在小工具和提醒裡 | 免費 | 在 Nomo 裡連結 Cursor |
| 用量速度那一行和 Nomo 用量速度小工具 | Nomo Pro | 在 Nomo 裡連結 Cursor |
| Nomo 活動和 Nomo Token 裡的 Grok Bot 日子和 Token | Nomo Pro | 在 Nomo 裡連結 Cursor |

## 在 iPhone 上 {#iphone-only}

每一項都有自己的說明頁：

- **狀態**：在小工具裡選 Cursor 的 **Grok Bot** 服務。請看[狀態](/zh-Hant/status)和[小工具](/zh-Hant/widget)。
- **用量**：連結 Cursor。請看 [Cursor 和 Grok](/zh-Hant/usage#cursor-and-grok)。
- **提醒**：請看[通知](/zh-Hant/notifications)。
- **用量速度**：請看[用量速度](/zh-Hant/usage#pace)和 [Nomo 用量速度](/zh-Hant/widgets#nomo-pace)。
- **日子和 Token**：請看下一節。

## 把 Grok Bot 算進連續紀錄 {#streak}

你需要 Nomo 2.4.2 和 Nomo Pro。

<Warning>
  請連結 **Cursor**，不是 Grok。在 Nomo 裡連結 **Grok** 會顯示你的每週限額，但不會顯示你用 Grok Bot 的日子或 Token。這些只能透過 Cursor 取得。
</Warning>

<Steps>
  <Step title="連結 Cursor">
    1. 打開 Nomo。
    2. 點一下「供應商」分頁。
    3. 點一下 **Cursor**。
    4. 點一下上方的「用量」。
    5. 點一下「連結 Cursor 帳戶」。
    6. iOS 會詢問是否允許使用 **cursor.com** 登入。點一下「繼續」。
    7. 在 Cursor 的頁面上，用你使用 Grok Bot 的同一個帳戶登入。也就是你的 Grok 或 X 帳戶。

    頁面會自動關閉。已經用這個帳戶連結過 Cursor 了嗎？那就跳過這一步。
  </Step>

  <Step title="打開活動頁面">
    打開[活動頁面](/zh-Hant/widgets#activity-screen)。它一打開就會取得你用 Grok Bot 的日子和 Token。你也可以往下拉，再取得一次。
  </Step>

  <Step title="加入小工具">
    加入 Nomo 活動或 Nomo Token 小工具。按住它，點一下「編輯小工具」，點一下「角色」，然後選 **Grok Bot**。請看 [Nomo 活動](/zh-Hant/widgets#nomo-activity)。
  </Step>
</Steps>

## 哪些會算進去

- 只要 Grok Bot 當天用了任何 Token，那一天就算。所以排程的例行工作也算。
- 在 Grok Bot 手機應用程式裡的使用也算。
- Nomo Token 和活動頁面會顯示 Grok Bot 實際的 Token 數。
- 你自己使用 Cursor 的部分，不管是在 Cursor 編輯器還是它的命令列工具，也會顯示出來，在獨立的一行：**Cursor**。
- 使用 The X Subscription 時，Grok Bot 和 Cursor 共用一個每週限額，Nomo 會顯示它。使用較舊的 Cursor 方案時，Grok Bot 有自己的限額，Nomo 不會讀取。

## 隱私 {#privacy}

- Nomo 只讀取每小時的 Token 數。它絕不會讀取你的訊息或你寫的任何內容。
- 這些數字直接從 Cursor 的伺服器傳到你的手機，不會上傳到任何地方。
- 你的 Cursor 登入資訊存放在 iPhone 鑰匙圈中，而且只會送到 Cursor。

想停止的話，在「供應商」分頁打開 Cursor，點一下「用量」，然後點一下「中斷連結」。這也會停止在 Nomo 裡顯示你的 Cursor 用量。
