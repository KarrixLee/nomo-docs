Cursor 的 sessions 出現在同一份列表、同一個動態島上，走的也是同一組配對 — 不管是來自 Cursor 桌面應用程式的代理，還是來自 `cursor-agent` CLI。在這個版本裡它們是**唯讀**的：你在手機上看著一個 Cursor session，回覆則要回到電腦上做。

<Note>
  Sessions 屬於 Nomo Pro，Cursor 和其他每個代理都一樣。Cursor 的 sessions 還需要你手機上的 Nomo 是最新版本。
</Note>

## 相同的部分 {#what-works-the-same}

sessions、資料夾和[動態島](/zh-Hant/sessions/island)的運作和其他代理一樣。所有共用的部分都只寫在一個地方：

- **安裝** → [安裝](/zh-Hant/setup/install)的 **Cursor** 分頁。一次安裝同時涵蓋桌面應用程式和 `cursor-agent`。
- **配對** → [配對](/zh-Hant/setup/pairing)。一次配對涵蓋這台電腦上的每個代理。
- **指令、更新與解除安裝** → [指令](/zh-Hant/sessions/commands)，其中有 [update](/zh-Hant/sessions/commands#update) 和 [uninstall](/zh-Hant/sessions/commands#uninstall)。
- **每個代理能做什麼** → [功能一覽](/zh-Hant/sessions/features)。
- **出了問題** → [疑難排解](/zh-Hant/sessions/troubleshooting)。

## 四個 skills，沒有 approvals 指令 {#four-skills-no-approvals-command}

Nomo 在 Cursor 裡的指令是不帶前綴的 skills。在 Cursor 裡輸入 `/` 來挑選：`/nomo-pair`、`/nomo-status`、`/nomo-reset` 和 `/nomo-unpair`。

Cursor 沒有 approvals 指令 — 沒有遠端批准可以暫停。

## 你會看到什麼 {#what-you-see}

- session 會在你於某個對話裡送出**第一個提示**時出現 — 而不是在對話只是被打開的時候。
- 對話、視窗或 CLI 關閉時，它就會被移除。
- 標題是 Cursor 替那個對話取的名稱 — 也就是對話分頁和歷史紀錄裡的那個。它一開始是你的第一個提示，在這一輪進行中或結束後不久，換成 Cursor 取的名稱。
- 模型標籤顯示的是 Cursor 回報的模型。

## 這個版本的限制 {#what-this-version-doesnt-do}

- **沒有遠端批准**。你無法從手機上「允許」或「拒絕」Cursor 的 Run / Skip 請求，手機也不會顯示 Cursor 正在等你。Cursor 沒有把這些開放給外掛程式。
- **沒有問題，也沒有計畫批准**。Cursor 的問題和計畫批准不會顯示，也無法從手機上回答。
- **沒有「在 Mac 上開啟」**。這個按鈕在 Cursor 的 sessions 上無法使用。
- **沒有「停止」**。[「停止」](/zh-Hant/sessions/list#interrupt-a-running-session)按鈕在 Cursor 的 sessions 上同樣無法使用。
- **沒有雲端代理**。Cursor 的雲端代理和背景代理不會顯示 — 只有跑在你 Mac 上的代理才會。
- **標題可能一直是你的第一個提示**。如果讀不到 Cursor 替對話取的名稱，標題就維持第一個提示 — 這一輪結束後，Nomo 還會繼續檢查大約兩分鐘。用 `cursor-agent` CLI 執行的對話，標題一直是第一個提示。Nomo 只從 Cursor 的本機資料庫讀取對話名稱，其中的其他內容一概不會傳送。
- **當機可能留下一個 session**。如果 Cursor 被強制結束或當機，session 不會立刻結束。會停多久、怎麼清掉，請看[疑難排解](/zh-Hant/sessions/troubleshooting)。

如果有東西沒出現，[疑難排解](/zh-Hant/sessions/troubleshooting)裡關於 Cursor 的那幾項是該先看的地方。

## 技術細節與安全性 {#technical-details-and-security}

Nomo 只會把 session 正在做什麼傳到你的手機，而且是端對端加密。
