全部都在同一頁上：「設定」>「Sessions」。電腦面板右上角的齒輪也是去同一個地方。

這裡的每一項**預設都是關閉的**。Nomo 不會替你打開東西 — 其中好幾項會耗電、耗網路，或需要一次權限請求，而其中一項還決定了你的 Mac 到底要不要把權限決定交給你的手機。

## 區域網路

<ResponseField name="區域網路" type="預設關閉">
  關閉時，Nomo 僅透過雲端連線你的 Mac。開啟後，當兩者位於同一網路時會直接連線已配對的 Mac，並在需要時自動改用雲端。
</ResponseField>

直接連到你的 Mac，而不是繞經中繼伺服器：**200 毫秒以內**，而不是五到十二秒。如果你就坐在書桌前、手機放在旁邊，值得打開。

它嚴格來說只是加法。每個請求都同時走兩條路 — 直接連線和中繼伺服器 — 先回答的那個算數。一台睡著的、被防火牆擋住的，或在另一個網路上的 Mac，拖不慢任何事，因為中繼伺服器那一條從來就沒在等它。

第一次開啟時會請求**區域網路**權限。你 Mac 的位址絕不會以明文傳送，而且直接傳輸的內容會在原本的加密之上再包一層，所以 Wi-Fi 上的任何東西都不會知道它屬於哪個 session 或哪台電腦。

你可以從電腦名稱下方那個綠色的 **⚡ 本機** 標籤看出它真的在運作。那個標籤只有在真的收到直接回應時才會出現 — 絕不會單憑一個位址就出現 — 所以沒有標籤就表示沒有直接連線，不管原因是什麼。

直接連線還會解鎖兩件事：session 列上的「在 Mac 上開啟」，以及重新取回一份長到塞不進加密更新的計畫。

## 動態島

<ResponseField name="更新時展開" type="預設關閉">
  當 session 需要你注意時，會伴隨觸覺回饋短暫展開動態島，並在新的 sessions 出現時自動加入。Nomo 一律顯示最需要你的那一個。
</ResponseField>

震動加閃現。想被通知就打開；寧可自己瞄一眼就別開。

它不會一直煩你。一個安靜下來的 session 最多推你三次，每次間隔五分鐘，之後就保持沉默，直到真的有什麼改變。

<ResponseField name="自動加入新 sessions" type="預設關閉">
  <span className="beta-pill">Beta</span> 每個新的 session 一出現就放上動態島，不必你一個一個開開關。
</ResponseField>

只包含你打開這項設定之後 Nomo **第一次**看到的 sessions。之後才打開它，不會把一堆舊的拖上你的動態島，而且你明確關掉的 session 絕不會被重新加入。

<Info>
  **這一項為什麼是 beta。**iOS 給每個 App 一份固定額度，決定它能多常重繪一個即時動態，而每個加入的 session 都在消耗同一份額度。幾個的話你不會注意到。加入十來個忙碌的，iOS 就會開始合併它們的更新 — 動態島仍然是正確的，但它可能會比你的終端機慢半拍。

  如果你看到的是這個情況：打開下方的「更頻繁的更新」，或是回到只加入你真正在等的那一兩個 session。
</Info>

<Tip>
  正在**請求權限**的 session 無論這兩項如何設定都會到達動態島 — 那正是這項功能的重點。請看[預設不顯示任何 session](/zh-Hant/sessions/island#預設不顯示任何-session)。
</Tip>

## 遠端批准

<ResponseField name="在 iPhone 上回答" type="預設關閉">
  當動態島上的 session 請求權限（執行指令、編輯檔案）時，可從 iPhone 回答「允許」或「拒絕」。關閉後將一律在 Mac 上決定。
</ResponseField>

這一項是大家會漏掉的。關閉時，你的 Mac 絕不會把決定交給你的手機 — 你會看到某個 session 想找你，但你得走到 Mac 前才能回覆。完整說明在[在手機上回覆](/zh-Hant/sessions/approvals)。

還有第二個以電腦為單位的暫停，它住在 Mac 上而不是這裡：[`/nomo-cc:approvals off`](/zh-Hant/sessions/commands#approvals)。當你的手機才是那個聯絡不上的東西時，用那一個。

## 偵錯

<ResponseField name="session 診斷" type="預設關閉">
  在每個 session 下方顯示外掛程式的狀態判斷。
</ResponseField>

在每個展開的 session 列底下加上一行 Nomo 的內部狀態。它不耗任何資源，也不會在動態島上顯示任何東西。除非你要回報問題，否則就讓它關著 — 要回報時再打開它，把那一列傳給我們，做法寫在[回報問題](/zh-Hant/sessions/troubleshooting#回報問題)。

## iOS 權限

「開啟 iOS 設定」會帶你到 iOS 設定裡 Nomo 的頁面，那裡有兩個 Apple 自己的開關很重要：

- **即時動態** — 必須開啟，否則動態島上什麼都出不來。
- **更頻繁的更新** — 提高 iOS 允許 Nomo 重繪動態島的頻率。Nomo 是照預設額度寫的，大約每九秒一次更新。如果動態島的更新感覺落後你的終端機，就打開這一項。

## 每個 session 的開關

不在這一頁上：每一列 session 上的那個開關，它決定*那個* session 能不能佔住動態島。它在電腦的面板裡，每一列的右邊。請看[電腦與 sessions](/zh-Hant/sessions/list#session-列顯示的內容)。

你的選擇在你關掉 App、重新開機之後都還在。如果你切換某項設定時那台電腦聯絡不上，這個變更會被保留，等它回來時再套用。
