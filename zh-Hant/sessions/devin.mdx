在 iPhone 的鎖定畫面和動態島上，看著你的 Devin sessions。當 Devin 請求權限時，手機會問你要「允許」還是「拒絕」。Devin 問你問題時，也可以在手機上回答。

它搭配 Devin CLI 使用，也就是終端機裡的 `devin` 指令，也能搭配 [Devin Desktop](#devin-desktop) 使用。

<Note>
  Sessions 屬於 Nomo Pro。你的手機需要 Nomo **2.5.0** 以上，Mac 上需要外掛程式 **2.5.0** 以上。
</Note>

## 設定步驟 {#set-it-up}

把 Nomo 加進 Devin 有兩種方式：**Devin 外掛程式**，或 **Nomo 安裝工具**。兩者選一個安裝就好。如果兩個都裝了，Nomo 會使用安裝工具那一個，外掛程式則保持安靜。

<Tabs>
  <Tab title="Devin 外掛程式">
    <Steps>
      <Step title="打開終端機">
        在你的 Mac 上打開「終端機」App。它在「應用程式」>「工具程式」裡。
      </Step>

      <Step title="安裝 Devin CLI">
        已經裝好了？跳過這一步。

        複製下面這一行，貼到終端機裡，然後按下 Return：

        ```bash
        brew install --cask devin-cli
        ```

        沒有 Homebrew？改用這一行：

        ```bash
        curl -fsSL https://cli.devin.ai/install.sh | bash
        ```

        然後輸入 `devin` 並按下 Return。如果 Devin 要你登入，照著它的步驟做。
      </Step>

      <Step title="安裝 Nomo 外掛程式">
        這一步要在終端機裡輸入，不是在 Devin 裡面。如果 Devin 開著，請先開一個新的終端機視窗（按下 **⌘N**）。

        複製下面這一行，貼到終端機裡，然後按下 Return：

        ```bash
        devin plugins install KarrixLee/nomo
        ```

        改用 Devin Desktop？前往 **Customize → Plugins → From repository**，然後輸入 `KarrixLee/nomo`。
      </Step>

      <Step title="啟動 Devin">
        在終端機裡輸入 `devin`，然後按下 Return。
      </Step>

      <Step title="輸入 /nomo:pair">
        在 `devin` 裡輸入下面這行並送出：

        ```
        /nomo:pair
        ```

        Devin 會在瀏覽器裡打開一個有 QR code 的頁面。
      </Step>

      <Step title="掃描 QR code">
        在 iPhone 上打開 Nomo → **Sessions** → **配對電腦**，然後掃描 QR code。
      </Step>

      <Step title="確認一下">
        在 `devin` 裡輸入下面這行並送出：

        ```
        /nomo:status
        ```

        如果有一行以 `!` 開頭，照著它底下那行 `→` 做。
      </Step>

      <Step title="在 Devin 裡送出一則訊息">
        在 `devin` 裡隨便送出什麼都可以。

        你應該會看到這個 session 出現在 Nomo 裡，在你那台電腦的 **Devin** 分頁底下。沒有 Devin 分頁？點一下 **+** 按鈕（「選擇代理」），把 Devin 打開。
      </Step>
    </Steps>
  </Tab>

  <Tab title="Nomo 安裝工具">
    <Steps>
      <Step title="打開終端機">
        在你的 Mac 上打開「終端機」App。它在「應用程式」>「工具程式」裡。
      </Step>

      <Step title="安裝 Devin CLI">
        已經裝好了？跳過這一步。

        複製下面這一行，貼到終端機裡，然後按下 Return：

        ```bash
        brew install --cask devin-cli
        ```

        沒有 Homebrew？改用這一行：

        ```bash
        curl -fsSL https://cli.devin.ai/install.sh | bash
        ```

        然後輸入 `devin` 並按下 Return。如果 Devin 要你登入，照著它的步驟做。
      </Step>

      <Step title="執行 Nomo 安裝工具">
        複製下面這一行，貼到終端機裡，然後按下 Return：

        ```bash
        bunx nomo-ai --devin
        ```

        沒有 `bunx`？改用 `npx nomo-ai --devin`。

        在它印出的內容裡，你應該會看到：

        ```
        devin-install: Devin sessions will now show in Nomo — restart devin (and Devin Desktop)
        ```
      </Step>

      <Step title="重新啟動 Devin">
        關掉每一個開著的 `devin`，再重新啟動它。在用 Devin Desktop？也請把它結束後再重新打開。

        <Warning>
          別跳過這一步。在 Devin 重新啟動之前，Nomo 都不會運作。
        </Warning>
      </Step>

      <Step title="開始配對">
        安裝工具不會在 Devin 裡加入 Nomo 指令，所以要從終端機配對。複製下面這一行，貼到終端機裡，然後按下 Return：

        ```bash
        ~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs
        ```

        你應該會看到瀏覽器打開一個有 QR code 的頁面。
      </Step>

      <Step title="等待手機">
        複製下面這一行，貼到終端機裡，然後按下 Return：

        ```bash
        ~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs wait
        ```

        你應該會看到：

        ```
        Waiting for your phone to scan the QR…
        ```
      </Step>

      <Step title="掃描 QR code">
        在 iPhone 上打開 Nomo → **Sessions** → **配對電腦**，然後掃描瀏覽器裡的 QR code。

        你應該會在終端機裡看到一行以 `Paired with` 開頭、以 ✓ 結尾的文字。
      </Step>

      <Step title="在 Devin 裡送出一則訊息">
        在 `devin` 裡隨便送出什麼都可以。

        你應該會看到這個 session 出現在 Nomo 裡，在你那台電腦的 **Devin** 分頁底下。沒有 Devin 分頁？點一下 **+** 按鈕（「選擇代理」），把 Devin 打開。
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Tip>
  **已經從 Claude Code、Codex、OpenCode、Cursor 或 Antigravity 配對過了？**一次配對涵蓋整台電腦。跳過配對的步驟。
</Tip>

<Tip>
  **這台電腦沒有瀏覽器？**改用短代碼，而不是 QR code：用外掛程式的話，在 Devin 裡輸入 `/nomo:pair code`；用安裝工具的話，在終端機裡把 `--show-code` 加到配對那一行的最後面。在 iPhone 上打開 Nomo → **Sessions** → **配對電腦** → **輸入代碼**，把代碼打進去。代碼 10 分鐘後過期。
</Tip>

<Note>
  **Devin Desktop 的 Restricted Mode 會讓 Nomo 停止運作。**它會關掉 Nomo 需要的 hooks，所以它開著的時候，你的 sessions 不會送到手機。
</Note>

## 指令 {#commands}

**使用 Devin 外掛程式時**，在 Devin 裡輸入這些：

| 輸入這個 | 它會做什麼 |
| --- | --- |
| `/nomo:pair` | 把這台電腦連上你的手機 |
| `/nomo:pair code` | 一樣，但改用一組可以打字輸入的短代碼，而不是 QR code |
| `/nomo:status` | 確認一切正常 |

想不再問你的手機，請在 Nomo 的[設定](/zh-Hant/sessions/settings#remote-approvals)裡關閉「在 iPhone 上回答」。這台電腦上也在用 Claude Code？在 Claude Code 裡輸入 `/nomo-cc:approvals off`，就能暫停這台電腦的遠端批准。

**使用 Nomo 安裝工具時**，Devin 的對話裡沒有 Nomo 指令。請改在終端機裡執行這些：

| 它會做什麼 | 把這個貼到終端機裡 |
| --- | --- |
| 把這台電腦連上你的手機 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs` |
| 一樣，但改用短代碼，而不是 QR code | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs --show-code` |
| 等你的手機完成配對 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs wait` |
| 確認一切正常 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/status-cmd.mjs devin` |
| 不再問你的手機 — 改由 Devin 在 Mac 上問 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs off` |
| 重新改回問你的手機 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs on` |
| 從手機上清除卡住的 sessions，連線保持不變 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/reset.mjs` |
| 解除這台電腦和手機的配對 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/unpair.mjs` |

連線和批准開關是這台電腦上所有寫程式的 App 共用的。在這裡關掉批准，Claude Code 和 Codex 的批准也會一起關掉。

## 你會看到什麼 {#what-you-see}

- session 會在你送出**第一則訊息**時出現。
- Devin 工作時它顯示 `執行中`，結束時顯示 `完成`。
- 它的名稱就是 Devin 自己的 session 標題。在 Devin 取好標題之前，會先用你的第一則訊息。
- 標籤顯示 Devin 正在使用的模型。
- [動態島](/zh-Hant/sessions/island)的運作和其他代理一樣。

## 在手機上回覆 {#answering-from-your-phone}

當 Devin 請求權限時 — 例如要執行一個指令 — 手機會問你。

按住那個 session，或使用動態島，然後選擇：

<Frame caption="一個請求執行指令的 Devin session。">
  <div className="device-frame">
    <img className="only-light" src="/images/devin-approval-card.png" alt="Devin session Fix token refresh race 的批准卡片，請求執行 bun test，有「拒絕」、「允許」和「拒絕並附註…」按鈕" />
    <img className="only-dark" src="/images/devin-approval-card-dark.png" alt="Devin session Fix token refresh race 的批准卡片，請求執行 bun test，有「拒絕」、「允許」和「拒絕並附註…」按鈕" />
  </div>
</Frame>

- 「允許」— Devin 繼續做。
- 「一律允許 …（本次 session）」— Devin 繼續做，而且在這個 session 結束前，同樣的事 Nomo 不會再問你。請看[下方](#always-allow)。
- 「拒絕」— Devin 不會做這件事。
- 「拒絕並附註…」— Devin 不會做這件事，並收到你的附註，告訴它原因。

更多內容請看[在手機上回覆](/zh-Hant/sessions/approvals)。

小提醒：

- **Devin 會等你的手機**。如果逾時，Devin 會改在你的 Mac 上問你。
- **手機不在身邊？沒關係**。如果連不上你的手機，或批准已經[暫停](/zh-Hant/sessions/approvals#pausing-it)，Devin 會在你的 Mac 上問你，就和沒有 Nomo 時一樣。

### 一律允許 {#always-allow}

「一律允許」只在**本次 session** 有效。session 結束時，Nomo 就會忘掉它，下一個 session 會重新問你。

- **簡單的指令**會依指令名稱記住。對 `touch b.txt` 選了一律允許，`touch c.txt` 也會被允許 — 但換成別的指令就不行。
- **串在一起的指令** — 含有 `&&`、`;`、`|` 或 `>` 的指令 — 每次都會送到手機，除非它和你已經允許過的指令一模一樣。所以 `touch x && rm -rf ~` 還是會問你。
- **其他操作**，例如寫入檔案，在這個 session 剩下的時間裡都會被允許。

Nomo 把它存在你的電腦上，絕不會改動 Devin 自己的設定。就算你暫停了批准，它在 session 結束前也仍然有效。

### 回答 Devin 的問題 {#questions}

Devin 問你問題時，那個 session 會顯示 `需要回答`。按住它，然後選擇「回答…」：

1. 點一下一個選項。Devin 允許的話，可以選好幾個。
2. 都不合適？點一下「其他…」，輸入你自己的回答。
3. 點一下「提交」。

「新增附註」可以替你的回答加上一段說明。「拒絕」會告訴 Devin 你選擇不回答。

<Note>
  **在 Mac 上，這個問題會顯示為 rejected。這是正常的**。Devin 沒辦法直接從 Nomo 收到回答，所以 Nomo 把你的回答當成關閉 Devin 問題的理由送過去。你會看到問題被標成 **rejected**，旁邊寫著你的回答。Devin 會讀到你的回答，然後繼續工作。
</Note>

## 停止這一輪 {#interrupt}

在 `執行中` 的 Devin session 上點一下 **[停止](/zh-Hant/sessions/list#interrupt-a-running-session)** 就能停下它。它需要綠色的 **⚡ 本機** 標籤 — 也就是 iPhone 和 Mac 在同一個網路上。

Devin 會先做完目前這一步再停下，沒辦法把指令或回覆從中間切斷。session 會顯示 `完成`，Devin 仍然開著 — 送出新的訊息就能繼續。

## Devin Desktop {#devin-desktop}

Devin 的文件說，Devin Desktop 的 **Devin Local** 代理和 Devin CLI 使用同一個引擎，所以 Nomo 在那裡的用法也一樣。Nomo 已經用 Devin CLI 和 Devin 的 ACP 伺服器測試過。

- **手機先回答**。當手機上有權限請求或問題時，Devin Desktop 不會顯示它自己的按鈕。請在手機上回答。想改在 Mac 上回答，請在 Devin 的下一個提示之前[暫停批准](/zh-Hant/sessions/approvals#pausing-it)。
- **哪些會送到手機**。在 Devin Desktop 預設的 **Code** 模式下，Devin 只會在執行指令、抓取網頁，以及在專案之外寫入之前問你。你在手機上看到的就是這些權限請求。
- **Restricted Mode 會讓 Nomo 停止運作**。在你離開它之前，sessions 不會送到手機。

## Devin 有什麼不同 {#whats-different-for-devin}

- **只有 Mac 上的 Devin**。Devin Cloud 的 sessions 不會出現 — Nomo 只顯示在你的 Mac 上執行的 Devin。
- **短的 session 可能沒有模型標籤**。Devin 只在 session 結束時才記下模型。
- **Devin 不支援：**[回覆](/zh-Hant/sessions/antigravity#reply-from-your-phone)和「在 Mac 上開啟」。

## 有東西不能用 {#troubleshooting}

<AccordionGroup>
  <Accordion title="我的手機什麼都沒顯示">
    1. 關掉每一個開著的 `devin`，再重新啟動它。
    2. 檢查 Nomo。用外掛程式的話，在 Devin 裡輸入 `/nomo:status`。用安裝工具的話，在終端機裡執行這行：

       ```bash
       ~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/status-cmd.mjs devin
       ```

    如果 Devin 分頁顯示「**還沒有 Devin sessions**」，請先在 Devin 裡送出一則訊息 — session 要在你送出第一則訊息後才會出現。
  </Accordion>

  <Accordion title="安裝工具說我的設定檔有註解">
    沒關係。Nomo 加入內容後，Devin 的設定檔就留不住註解，所以安裝工具會先把你原本的檔案存在它旁邊：

    ```
    ~/.config/devin/config.json.nomo-backup
    ```

    你所有的設定都還在，只有註解被移除了。
  </Accordion>

  <Accordion title="Devin 把我的回答顯示為 rejected">
    這是正常的。Nomo 把你的回答當成關閉 Devin 問題的理由送過去，所以 Mac 上這個問題會顯示為 **rejected**，旁邊寫著你的回答。Devin 會讀到你的回答，然後繼續工作。
  </Accordion>

  <Accordion title="Devin Desktop 沒有顯示權限請求的按鈕">
    這個請求在你的手機上。請在手機上回答。想改在 Mac 上回答，請在 Devin 的下一個提示之前[暫停批准](/zh-Hant/sessions/approvals#pausing-it)。
  </Accordion>

  <Accordion title="點了停止，Devin 卻沒有馬上停下">
    Devin 會先做完目前這一步 — 已經在執行的指令或回覆會繼續到結束，然後才停下。

    沒有「停止」按鈕？iPhone 和 Mac 需要在同一個網路上，並且顯示綠色的 **⚡ 本機** 標籤。
  </Accordion>

  <Accordion title="我的手機不再問我要不要批准">
    如果你用的是安裝工具，在終端機裡執行這行：

    ```bash
    ~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs on
    ```

    如果批准本來就開著，請檢查[設定](/zh-Hant/sessions/settings#remote-approvals)裡的「在 iPhone 上回答」。
  </Accordion>

  <Accordion title="session 一直卡在「執行中」">
    如果你用的是安裝工具，在終端機裡執行這行：

    ```bash
    ~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/reset.mjs
    ```
  </Accordion>
</AccordionGroup>

## 更新 {#updating}

如果你用的是安裝工具，再執行一次它，然後重新啟動 Devin：

```bash
bunx nomo-ai --devin
```

## 解除安裝 {#uninstalling}

**Devin 外掛程式：**複製下面這一行，貼到終端機裡，然後按下 Return：

```bash
devin plugins remove nomo
```

**Nomo 安裝工具：**

<Steps>
  <Step title="在終端機裡執行這行">
    ```bash
    node ~/.nomo/plugin/scripts/devin-install.mjs --uninstall
    ```

    你應該會看到：

    ```
    devin-install: removed Nomo's hooks from Devin — restart devin
    ```
  </Step>

  <Step title="重新啟動 Devin">
    關掉每一個開著的 `devin`，再重新啟動它。
  </Step>
</Steps>

你的手機會繼續和你其他寫程式的 App 保持連線。如果也要解除這台電腦和手機的配對，請在解除安裝安裝工具**之前**，執行[指令](#commands)裡的解除配對指令。

## 進階 {#advanced}

<AccordionGroup>
  <Accordion title="運作原理" icon="gear">
    - **安裝工具會改什麼**。它把外掛程式 clone 到 `~/.nomo`，並在 `~/.config/devin/config.json` 的 `"hooks"` 鍵裡加入 Nomo 的項目。你其他的 Devin 設定都原封不動。再執行一次也不會改變任何東西。如果檔案裡有註解，它會先把檔案複製成 `config.json.nomo-backup`。解除安裝只會移除 Nomo 的項目。在 `devin` 裡輸入 `/hooks`，就能看到它載入了什麼。
    - **外掛程式會加入什麼**。Devin 外掛程式會加入同樣的兩個 hooks，以及 `/nomo:pair` 和 `/nomo:status` 指令。它不會加入任何規則、MCP 伺服器或代理，而且只在本機的 Devin sessions 裡執行，絕不會在 Devin Cloud 裡執行。只要安裝工具的項目還在，外掛程式的 hooks 就什麼都不送出。
    - **狀態**。`UserPromptSubmit`、`PostToolUse`、`Stop` 和 `SessionEnd` 上的 hook 負責回報狀態。它什麼都不印出，所以不會擋住提示，也不會改變任何工具呼叫 — 唯一的例外是：你點了「停止」之後，它的下一個 `PostToolUse` 會印出 `{"continue":false}`，結束這一輪。
    - **批准**。`PermissionRequest` 上的 hook 會把工具名稱和它的指令或檔案路徑以端對端加密送到你的手機。只有你已配對的手機針對那一個請求點了「允許」，它才會回覆 `approve`；點了「拒絕」則回覆 `block`，並附上你的附註。其他所有情況 — 未配對、批准已暫停、離線、逾時、錯誤 — 它什麼都不印出，把決定交還給 Devin 自己的請求。
    - **問題**。同一個 hook 在 `PreToolUse`（只針對 `ask_user_question`）上把 Devin 的問題和選項以端對端加密送到你的手機。你的回答會以 `block` 的形式傳回，理由就是你的回答，Devin 的模型會讀到它。
    - **一律允許**。授權存放在 `~/.config/cc-status/sessions/<session>.devin-allow`，只有你自己能讀，session 結束時刪除。Devin 自己的設定檔絕不會被寫入。
    - **不會出現重複的列**。Devin 也會執行 Claude Code 的 hooks。Nomo 的 Claude Code 外掛程式在 Devin 裡會保持安靜，所以 Devin 的 session 絕不會顯示成 Claude Code 的 session。

    完整細節在外掛程式的 [README](https://github.com/KarrixLee/nomo#install--devin) 裡。
