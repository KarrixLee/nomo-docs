<Update label="2026年10月22日" description="2.3.3">
  ## iPhone Duo、Kimi、DeepSeek 和 Antigravity

  **新增**

  - 支援 **iPhone Duo**，iPad 版面也更好用了：「供應商」和 Sessions 分頁會把清單和詳細內容並排顯示
  - **Kimi** 和 **DeepSeek** 加入「狀態」分頁、狀態提醒和小工具
  - 支援 **Kimi Code** 用量，有小工具，也有 70%、90%、100% 提醒。在「供應商」分頁裡連結：Nomo 會顯示一組短碼，你在 Kimi 的登入頁面上核准就好
  - Gemini 用量改為 **Antigravity**：讀取你的 Google Antigravity 配額，這家供應商在 App 和小工具裡都顯示為 Antigravity。小型用量小工具可以顯示它的 **Claude & GPT** 限額。如果之前連結過 Gemini，請重新登入
  - 「設定 → 提醒」裡的每家供應商都有了自己的開關，可以一次關掉或重新打開它的所有狀態提醒

  **改進**

  - 用量提醒的每一列也帶上了供應商圖示，和狀態那幾列一樣
  - 歡迎導覽新增「追蹤你的用量」頁面，用來連結你的帳號；提醒也不再標示 Beta

  **修正**

  - 在 iPhone Duo 又窄又直的動態島上，session 的圖示會置中顯示，並用簡短的時間標籤取代一直跳動的計時器
</Update>

<Update label="2026年10月20日" description="2.3.2">
  ## 登入會等你回來

  **修正**

  - 登入 Claude、Codex、Cursor、Gemini 或 Grok 時，每次切換應用程式頁面都會重新載入，需要雙重驗證碼的登入因此永遠無法完成。現在離開去取得驗證碼，回來後可以接著登入
</Update>

<Update label="2026年10月18日" description="2.3.1">

  **新增**

</Update>

<Update label="2026年10月" description="2.3">
  ## Cursor 與停止這一輪

  **新增**

  - **Cursor** 加入 Claude Code、Codex 和 OpenCode — 來自 Cursor 桌面應用程式和 `cursor-agent` 的 sessions 會即時顯示在 Sessions 分頁和動態島上，帶著 Cursor 自己的對話標題和模型。這個版本是唯讀的：你在手機上看，回覆則回到電腦上做。用 `bunx nomo-ai --cursor` 安裝
  - 選擇一台電腦要顯示哪些代理 — 它面板裡的 **+** 按鈕（「選擇代理」）最多可以挑三個分頁
  - 在手機上停下正在執行的 Claude Code 或 Codex 這一輪 — session 列裡「在 Mac 上開啟」旁邊的「停止」。這一輪停下，session 仍然開著：Codex 立刻停，Claude Code 在下一次工具呼叫時停
  - 「停止」需要電腦上的外掛程式 **2.3.0** — 請把 Claude Code 和 Codex 的外掛程式都更新
  - 「停止」需要開啟「區域網路」，而且兩台裝置在同一個網路上：它走直接連線，絕不經過中繼伺服器
  - 設定成 Cursor **Grok Bot** 的小工具，現在會用一個會動的 Grok 機器人取代 Cursor 標誌。它會跟著狀態變化：晚上打瞌睡，服務變慢時一臉擔心，發生中斷時垂頭喪氣

  **改進**

  - 在 Codex 裡按下 Esc，手機會立刻知道，不用再等 20 秒
  - 外掛程式多註冊了三個 Codex hooks。更新之後，請在 Codex 裡執行 `/hooks` 並信任新的項目 — 一共十個
  - 小工具上 Cursor 的狀態文字稍微縮小了，「嚴重中斷」這類較長的狀態更容易放得下

  **修正**

  - 因 API 錯誤而結束的 Claude Code 這一輪，會顯示「執行中」長達半小時。現在會定為「完成」
  - 工具執行失敗後，Claude Code session 可能已經繼續往下做了，卻還顯示在等你
  - 正在等背景子代理的 Claude Code session 會繼續顯示為工作中，不會太早變成「完成」
  - OpenCode 子代理發出的請求現在會顯示在它的 session 上，而且一回覆，session 就回到工作中
  - 連線慢的時候，動態島可能在這一輪進行到一半時就不再更新 — 「已斷線？」。外掛程式現在會重新傳送沒送達的內容，而且只要 Mac 確認 session 還在，Sessions 分頁就會讓停住的動態島恢復
  - 「狀態」分頁、提醒和小工具改為跟隨 xAI 新的狀態頁面。設定成 xAI 某一個 API 的小工具，不管你選哪一個，顯示的都是清單裡的第一個 API
</Update>

<Update label="2026年10月10日" description="2.2.2">
  ## 更多回覆方式

  **新增**

  - 批准 Claude Code 的計畫時，可以選擇它接下來怎麼進行 — 「批准並自動接受編輯」或「批准並使用自動模式」 — 不再只有單純的批准。Claude Code 的其他請求則多了「批准並切換到自動模式」
  - 用「其他…」輸入你自己的回答，再用「新增附註」為它附上說明，不再只能從清單裡選
  - 提供自由輸入答案的 Codex 問題，同樣可以用「其他…」
  - 帶有預覽的選項，在你選取時會把預覽顯示在清單下方
  - 以上都需要電腦上的外掛程式 **2.2.2** — 在那之前，App 會把它們藏起來
  - 某個限額達到 100% 時，「用量」分頁會連到那家供應商自己的用量設定 — 「在 Claude 管理用量」 — 支援 Claude、Codex、Cursor 和 xAI，適用於美國、歐盟和日本

  **改進**

  - 在計畫上，「拒絕並附註…」現在寫成「繼續規劃…」，這才是它實際做的事

  **修正**

  - 開啟或恢復後停在空白提示的 Claude Code session，會顯示「執行中」長達半小時。現在大約 20 秒就會定為「完成」
  - 沒有提示就建立的 OpenCode sessions — 分叉出來的，或由另一個用戶端開啟的 — 不會再停在「執行中」
  - 用量可能卡在一份舊的快照上，卻繼續把它當成最新的顯示
</Update>

<Update label="2026年8月" description="2.2">
  ## OpenCode

  **新增**

  - **OpenCode** 加入 Claude Code 和 Codex — 它的 sessions 會即時顯示在鎖定畫面和動態島上，有自己的標誌、配色和字體
  - OpenCode 的權限請求和提問都能在鎖定畫面上允許或拒絕，和另外兩個代理一樣。卡片會說明拒絕的後果，因為在 OpenCode 裡一旦拒絕，這一輪就結束了
  - OpenCode 的 session 在規劃代理工作時會顯示「規劃中」，點一下「查看計畫」就能打開它的待辦清單
  - **一鍵安裝** — `bunx nomo-ai`（或 `npx nomo-ai`）會找出電腦上的 Claude Code、Codex 和 OpenCode，把 Nomo 裝進你選的那些

  **改進**

  - 付費頁列出三個代理，也說清楚了批准實際上做了什麼：你可以在鎖定畫面上直接回答，而不只是收到通知
  - 模型供應商正在重試時，session 會顯示「重新連線中…」，不再是一串原始錯誤

  **安全**

  - 只靠一個 `nomo://` 連結不能再配對電腦 — 它會先說明這次配對和要連線的伺服器，等你確認
  - 訂閱狀態會分別回報給每一台已配對的電腦，任何一台都不會知道其他電腦的存在
  - 中斷 Cursor 連結時會一併清除它的 cookie，不會再留下一個可能悄悄把你重新登入的 session

  **修正**

  - 已配對電腦上顯示的「本機」被截斷成一個字
</Update>

<Update label="2026年8月19日" description="2.1.1">
  ## 修正與打磨

  **新增**

  - 用量提醒擴充到 **xAI/Grok** 和 **Gemini**，同時支援 Claude 按模型計算的每週上限
  - 可以在手機上讀**完整的計畫**，不再只有開頭一段

  **改進**

  - 所有語言的翻譯都做了訂正 — 有些標籤意思是錯的，還有些對同一個概念用了兩種說法
  - 權限卡片先說 agent 想做什麼，而不是直接丟出原始的 shell 指令
  - 動態島上的 session 標題和計時器不會再被擠壓或截斷
  - iPad 上頁面會限制在易讀的寬度，不再拉滿整個螢幕
  - 安裝檔更小了

  **修正**

  - 明明有付費的優惠方案，付費頁卻只顯示免費試用
  - Codex sessions 裡**在 Mac 上開啟**沒有作用
  - Cursor 的兩個用量額度在小尺寸小工具上又能看到了
  - 首次啟動導覽裡的一處當機
</Update>
