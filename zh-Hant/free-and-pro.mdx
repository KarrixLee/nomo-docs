用 Nomo 配對電腦是免費的。你的連續紀錄、寫程式的時間和每台電腦的狀態也都免費。

Nomo Pro 是即時的部分：鎖定畫面和動態島上的即時 sessions，以及在手機上回覆你的代理。

狀態、用量和提醒完全不需要電腦。請看[狀態與用量](/zh-Hant/status-usage)。

## 功能比較 {#what-you-get}

| | 免費 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| 已配對的電腦 | 一台 | 更多 |
| **首頁**上的[活動](/zh-Hant/activity)：連續紀錄和寫程式的時間 | ✓ | ✓ |
| 活動日曆 | 最近 30 天 | 最近 26 週 |
| [Token](/zh-Hant/activity#tokens-chart)：總數和圖表 | | ✓ |
| [你的回顧](/zh-Hant/activity#wrapped) | **週**和**月** | 增加**年**和 Token |
| 小工具 | 請看[免費小工具](/zh-Hant/free-widgets#free-and-pro) | 全部 |
| **Sessions** 分頁 | 你的電腦，每台都有一行說明它的代理正在做什麼 | 每個即時 session，逐一顯示 |
| 動態島和鎖定畫面上的即時動態 | | ✓ |
| 回覆權限請求和問題、回覆訊息、停止這一輪、閱讀全文 | | ✓ |
| [Grok Bot 和 Cursor](/zh-Hant/widgets#grok-bot) 的活動 | | ✓ |

<Note>
  免費配對從你的電腦送出的內容比 Pro 配對少。確切送出什麼，請看外掛程式 README 裡的
  [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer)。
</Note>

## 免費開始 {#get-the-free-part}

<Steps>
  <Step title="安裝外掛程式">
    在電腦上安裝 Nomo 外掛程式。請看[安裝](/zh-Hant/setup/install)。
  </Step>

  <Step title="配對電腦">
    在 Nomo 裡，點一下**首頁**上的**配對你的 Mac**。請看[配對](/zh-Hant/setup/pairing)。
  </Step>

  <Step title="照常寫程式">
    像平常一樣使用你的代理。連續紀錄和寫程式的時間會出現在**首頁**的[活動](/zh-Hant/activity)裡。
  </Step>
</Steps>

## 換一台電腦 {#use-a-different-computer}

Nomo Free 只連結一台電腦。想換到另一台，請先移除舊的那台。

<Steps>
  <Step title="移除舊電腦">
    在 Nomo 裡打開 **Sessions**。按住那台電腦，然後點一下**移除此電腦**。
  </Step>

  <Step title="確認">
    再點一下**移除此電腦**。
  </Step>

  <Step title="配對新電腦">
    用和第一台一樣的方式配對。請看[配對](/zh-Hant/setup/pairing)。
  </Step>
</Steps>

想同時使用多台電腦？請訂閱 Nomo Pro。

## 加入 Nomo Pro {#add-nomo-pro}

在 **Sessions** 分頁，點一下你的一台電腦，就能看到 Nomo Pro 增加了什麼。

你的電腦會保持配對。訂閱後，即時 sessions 大約一分鐘內就會開始。
