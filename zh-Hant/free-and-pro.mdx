在 Nomo 配對電腦是免費的。你的連續紀錄、寫程式時間和每台電腦的狀態也都免費。

Nomo Pro 是即時的那部分：鎖定畫面和動態島上的即時 sessions，以及在手機上回應你的代理。

狀態、用量和通知完全不需要電腦。請看[狀態與用量](/zh-Hant/status-usage)。

## 功能比較

| | 免費 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| 可配對的電腦 | 一台 | 多台 |
| 目前連續紀錄和最長連續紀錄，每個代理都算 | ✓ | ✓ |
| 活動紀錄（熱度圖） | 最近 30 天 | 全部 |
| 寫程式時間：今天和本週 | ✓ | ✓ |
| Token：總計、圖表、依模型或依代理 | | ✓ |
| 用來分享的**回顧**卡片 | **週**和**月**，可以是**貼文**（4:5）或**限時動態**（9:16）。大數字是你的連續紀錄或寫程式時間 | 多了**年**，大數字也可以是 Token |
| Pro 小工具 | **Nomo 活動**小型（你的連續紀錄） | 全部五個，所有尺寸 |
| **Sessions** 分頁 | 你的電腦列表，每台電腦有一行文字，顯示它的代理現在在做什麼 | 逐一顯示每個即時 session |
| 動態島和鎖定畫面上的即時動態 | | ✓ |
| 回應權限請求和問題、回覆、停止這一輪、查看全文 | | ✓ |
| 從 Cursor 儀表板取得的 Cursor 和 Grok Bot 活動 | | ✓ |

**Nomo** 狀態小工具和 **Nomo 用量**小工具對所有人免費。請看[所有小工具](/zh-Hant/widgets)。

<Note>
  免費配對從你的電腦送出的資料比 Pro 配對少。確切送出哪些內容，請看外掛程式 README 裡的 [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer)。
</Note>

## 免費開始

<Steps>
  <Step title="安裝外掛程式">
    在你的電腦上安裝 Nomo 外掛程式。請看[安裝](/zh-Hant/setup/install)。
  </Step>

  <Step title="配對電腦">
    在 Nomo 裡，點一下**首頁**上的**連結 Mac**，或 **Sessions** 裡的 **+**。請看[配對](/zh-Hant/setup/pairing)。
  </Step>

  <Step title="照常寫程式">
    像平常一樣使用你的代理。你的連續紀錄和寫程式時間會顯示在 Nomo 的**首頁**上。
  </Step>
</Steps>

## 換一台電腦

Nomo Free 可配對一台電腦。要換成另一台，請先移除現在這台。

<Steps>
  <Step title="移除現在這台電腦">
    在 Nomo 打開 **Sessions**。按住這台電腦，然後點一下**移除此電腦**。
  </Step>

  <Step title="確認">
    再點一下**移除此電腦**。
  </Step>

  <Step title="配對新電腦">
    用和第一台一樣的方式配對。請看[配對](/zh-Hant/setup/pairing)。
  </Step>
</Steps>

想同時用多台電腦？請使用 Nomo Pro。

## 加入 Nomo Pro

在 **Sessions** 分頁點一下你的一台電腦，就能看到 Nomo Pro 多了什麼。

你的電腦會保持配對。訂閱後，大約一分鐘內即時 sessions 就會開始。
