這一頁講的東西，在App裡都集中在同一個地方：**設定 → 提醒**。兩種通知預設都是關的，要自己打開；打開任何一個開關時會要求一次通知權限，接著馬上跑一次檢查 — 所以已經中斷、或已經超過門檻的項目會立刻告訴你，不用等下一輪輪詢。

每一則都會寫出供應商，以及確切受影響的項目 — **Cursor · Auto + Composer**、**OpenAI · ChatGPT Conversations** — 所以瞄一眼鎖定畫面就知道自己碰到哪個上限、或哪項服務出了問題，什麼都不用打開。

## 狀態提醒 {#status-alerts}

一個總開關，打開之後底下會多出第二列：

| | |
| --- | --- |
| **狀態提醒** | 某項服務效能降低或中斷時通知你。 |
| **恢復時通知** | 恢復正常時再通知你一次。預設開啟。 |

狀態來自各家供應商公開的狀態頁面，所以這不需要帳號。

### 挑選服務

總開關打開後，下方會出現一個**服務**區塊 — Claude、OpenAI、Cursor、xAI 和 Gemini，每一家都是一個可收合的群組，裡面是該供應商旗下的個別服務。所有服務一開始都是開啟的。

群組預設收合，標題會顯示總共幾項、開了幾項，所以不用一一展開也看得出自己改過什麼。這裡值得花點時間精簡：供應商的狀態頁面列出的東西，遠比你實際會用到的那一項多得多。

## 用量提醒 {#usage-alerts}

在各服務商所報視窗的 **70%**、**90%**、**100%** 提前提醒你 — Claude 和 Codex 有 5 小時*和*每週兩個視窗，Cursor 有兩個月度額度，xAI 是每週，Gemini 是每天。忙了一下午和趕了一整週，各自都會收到提醒。

按帳戶分別開關，而且只對你已登入的帳戶生效。

<Note>
  用量是在你的手機上檢查的。你的登入資訊不會離開裝置，也不會送到 Nomo 的伺服器 — 請見[登入](/zh-Hant/usage#signing-in)。
</Note>

## 如果提醒都不響了 {#if-alerts-go-quiet}

讓 Nomo 留在背景，不要上滑把它關掉。被強制結束的 App，iOS 就不會再喚醒它，提醒也會一直停擺，直到你下次打開它為止。
