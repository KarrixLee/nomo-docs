<Update label="2026年8月11日" description="2.1">
  ## Lock Screen からエージェントに答える

  **新機能**

  - 許可のリクエストが Lock Screen と Dynamic Island に表示されます — 机に戻らなくても承認・拒否ができます
  - 現在のプランと残りの使用量が、セッション上でひと目でわかるようになりました
  - **LAN モード** — iPhone とコンピュータが同じ Wi-Fi ネットワークにいるときは、更新が両者のあいだを直接行き来します。エンドツーエンドの暗号化はそのままです
  - Grok（xAI）と Gemini（Google）が Claude、OpenAI、Cursor に加わりました

  **修正**

  - ウィジェットで日本語などの非ラテン文字が途中で切れる問題
  - ウィジェット、通知、ライブアクティビティ全体のレイアウトと安定性
</Update>

<Update label="2026年7月" description="2.0">
  ## セッション

  **新機能**

  - **Sessions**（セッション）タブ — QR コードのスキャンでコンピュータをペアリングし、Claude Code と Codex のセッションが動く様子を Lock Screen と Dynamic Island でそのまま追えます
  - 実行中・完了・要対応の状態に加えて、使用中のモデルとセッションタイトルを表示
  - AES-256-GCM によるエンドツーエンド暗号化。鍵が端末から出ることはなく、リレーが見るのは暗号文だけです
  - Nomo Pro でライブのセッションが使えるようになります

  **改善**

  - Usage に Used（使用済み）と Left（残り）の両方を表示

  **修正**

  - OpenAI の週次使用量の集計
</Update>
