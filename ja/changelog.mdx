<Update label="2026年10月" description="2.3.5">
  ## Antigravity のセッション

  <Frame>
    <img src="/images/changelog-2-3-5-antigravity.png" alt="Nomo と Antigravity のアイコンと「It asks. You answer.」の見出し。iPhone から浮かび上がる Antigravity の許可リクエストカードに、「拒否」と「許可」のボタンが並んでいます" />
  </Frame>

  **新機能**

  - **Antigravity** が Claude Code、Codex、OpenCode、Cursor に加わりました — Google Antigravity デスクトップアプリと `agy` CLI のセッションが、セッションタブと Dynamic Island にリアルタイムで表示され、Antigravity 自身の会話のタイトルとモデルも付きます。プラグイン 2.3.5 のインストールは `bunx nomo-ai --antigravity` で、そのあと Antigravity を再起動して `/nomo-pair` と入力してください
  - Antigravity のシェルコマンドとファイルの書き込みを、iPhone から許可または拒否できるようになりました。「メモを付けて拒否…」で理由も伝えられます。読み取りと検索が iPhone に届くことはなく、あなた自身の拒否ルールが常に優先されます
  - 実行中の Antigravity のターンを iPhone から止められるようになりました — 「中断」で、現在のステップが終わったところで止まります
  - iPhone から Antigravity のセッションに[返信](/ja/sessions/antigravity#reply-from-your-phone)できるようになりました — 最大 4,000 文字で、次のステップで読み込まれます。返信シートはチャットの形になっていて、Antigravity からのリクエストが「**拒否**」「**許可**」付きで表示されます。[「**拒否して送信**」](/ja/sessions/antigravity#deny-and-send)を使うと、1 回のタップでコマンドを拒否し、その理由を Antigravity に伝えられます。終わった `agy` のセッションは Mac で再開し、終わったデスクトップアプリのセッションは Mac でのみ続けられます。現在、返信には iPhone と Mac が同じ Wi-Fi につながっている必要があります
  - Cursor のステータスに **BugBot**、**Cursor IDE (iOS)**、**Enterprise Dashboard** が加わり、それぞれにステータスアラートが付きました。Cursor のアラートをすべてオフにしていた場合は、新しい項目も最初からオフになります

  **改善**

  - セッションのボタンを一新しました。「計画を表示」「Macで開く」「中断」「返信」が同じデザインになり、それぞれ専用の色が付きます。質問カードの「拒否」も、承認カードと同じく赤ではなくなりました
  - リモート承認が一時停止中のとき、セッションのお知らせに、エージェントごとに承認をオンに戻すコマンドが表示されるようになりました。コマンドをタッチして押さえたままにするとコピーできます
  - 返信欄に入力した文字がそのまま送られるようになりました。`--` がダッシュに変わったり、引用符が曲がった形に変わったりしないので、コマンドが崩れずに届きます

  **修正**

  - Cursor がステータスページを移転してから、Cursor のステータス履歴と稼働状況が空になっていました。再び表示されるようになり、稼働状況は Cursor 自身のステータスページと同じ方法で一部障害を数えるようになりました

  **プラグイン 2.3.5**

  - Antigravity に対応しました。`~/.gemini/config/hooks.json` に `nomo` という名前のブロックを 1 つ追加し、ほかのフックには手を付けません。あわせて、`/nomo-pair`、`/nomo-status`、`/nomo-approvals`、`/nomo-reset`、`/nomo-unpair` を備えた小さな Antigravity プラグイン `nomo` も追加します。`--uninstall` で削除されるのはこの 2 つだけです
</Update>

<Update label="2026年10月23日" description="2.3.4">
  ## セキュリティの強化

  **新機能**

  - 承認に Face ID が必要になりました。iPhone がロックされているとき、ロック画面や Dynamic Island の「許可」は先に Face ID を求めます。「拒否」はワンタップのままです。初期状態でオンです — 「設定」＞「セッション」＞「Face ID」
  - 「ロック解除中も」をオンにすると、iPhone のロックを解除していても、アプリと Dynamic Island で「許可」のたびに Face ID を求めます。初期状態はオフです
  - どちらのスイッチも、オフにするときは Face ID を求めます。「許可にFace IDを使用」をオフにするときは、その前に警告が表示されます

  **改善**

  - 実際のコマンドが見えるようになりました。承認を待っているシェルコマンドは、Dynamic Island にコマンドそのものとして表示されます。長いものは中ほどが省略され、始まりと終わりがわかります。続きがあるときは **+N 行** と表示されます。エージェントによる説明は、その下にキャプションとして表示されます
  - 承認カードがコンピュータで待っているリクエストと一致していることを iPhone が確認できない場合は、「拒否」だけを表示します
  - ペアリングの確認画面では、常にその画面に表示されたコンピュータがペアリングされます
  - 「このコンピュータを削除」は、Nomo のサーバー上のペアリングの取り消しが完了するまで再試行を続けます。タップしたときにオフラインだった場合も同様です
  - 新しいペアリングエラー「このiPhoneを確認できませんでした」を追加しました。Nomo のサーバーが iPhone を確認できない場合に表示されます

  **プラグイン 2.3.4**

  - シェルコマンドの承認カードには、常にコマンドが残ります。エージェントの説明は短く抑えられ、スペースが足りないときは先に省かれます
  - iPhone からの「常に許可」は、そのセッションの中だけで有効です — プロジェクトの設定に保存されることはありません
  - Nomo のフックが、プロジェクトの `bunfig.toml` や `.env` を読み込まなくなりました
  - Bun が CVE-2026-111497 の影響を受けるバージョン（Bun 1.4.4 で修正済み）の場合、`status` が警告するようになりました。警告が表示されたら Bun を更新してください。Node.js 22 が **22.23.4** より古い場合も警告します
  - OpenCode: `/nomo-update` が更新するのは Nomo 自身のクローンだけで、`bunx nomo-ai` が更新するのはグローバルインストールだけになりました。プロジェクトへのインストールは、そのプロジェクトの中で `/nomo-update` を実行して更新してください
</Update>

<Update label="2026年10月" description="2.3">
  ## Cursor 対応とセッションの中断

  **新機能**

  - **Cursor** が Claude Code、Codex、OpenCode に加わりました — Cursor デスクトップアプリと `cursor-agent` のセッションが、セッションタブと Dynamic Island にリアルタイムで表示され、Cursor 自身のチャットのタイトルとモデルも付きます。このバージョンでは読み取り専用です。iPhone から見守り、回答はコンピュータで行います。インストールは `bunx nomo-ai --cursor` です
  - コンピュータごとに、表示するエージェントを選べるようになりました — ドロワーの **+** ボタン（「エージェントを選択」）で、最大 3 つのタブを選びます
  - 実行中の Claude Code または Codex のターンを iPhone から止められるようになりました — セッションの行の「Macで開く」の隣にある「中断」です。ターンだけが止まり、セッションは開いたまま残ります。Codex はすぐに、Claude Code は次のツール呼び出しで止まります
  - 「中断」には、コンピュータ側にプラグイン **2.3.0** が必要です — Claude Code と Codex の両方のプラグインを更新してください
  - 「中断」には、「ローカルネットワーク」をオンにし、両方のデバイスを同じネットワークにつないでおく必要があります。直接接続で送られ、中継サーバーは経由しません
  - Cursor の「Grok Bot」に設定したウィジェットに、Cursor のロゴの代わりにアニメーションする Grok のボットが表示されるようになりました。ステータスに合わせて、夜は眠り、サービスが遅いときは心配そうに、障害中はしょんぼりします

  **改善**

  - Codex で Esc を押すと、すぐに iPhone に反映されるようになりました。これまでは 20 秒かかっていました
  - プラグインが登録する Codex のフックが 3 つ増えました。更新後は Codex で `/hooks` を実行し、新しい項目を信頼してください — 全部で 10 個になります
  - ウィジェットに表示される Cursor のステータスの文字を少し小さくし、「重大な障害」などの長い表示が収まりやすくなりました

  **修正**

  - API エラーで終わった Claude Code のターンが、最大 30 分間「実行中」と表示される問題。「完了」に落ち着くようになりました
  - ツールが失敗すると、Claude Code のセッションが先へ進んだあとも、あなたの対応を求める表示のまま残ることがある問題
  - バックグラウンドのサブエージェントを待っている Claude Code のセッションが、早すぎる段階で「完了」と表示される問題。作業中の表示が続くようになりました
  - OpenCode のサブエージェントからの許可リクエストや質問が、そのセッションに表示されるようになりました。回答するとすぐに、セッションは作業中に戻ります
  - 接続が遅いと、ターンの途中で Dynamic Island が古い状態 — 「接続切れ？」 — になることがある問題。プラグインは届かなかった分を再送するようになりました。また、Mac がセッションの継続を確認すると、セッションタブが古くなった Dynamic Island を元に戻します

<Update label="2026年10月10日" description="2.2.2">
  ## 回答方法の拡充

  **新機能**

  - Claude Code の計画を承認するときに、ただ承認するだけでなく、その後の進め方も選べるようになりました — 「承認して編集を自動承認」または「承認して自動モード」です。Claude Code のそれ以外の許可リクエストには「承認して自動モードに切り替え」が加わります
  - 質問には、一覧から選ぶだけでなく、「その他…」で自分の回答を入力し、「メモを追加」でメモを添えられます
  - 自由入力の回答を受け付ける Codex の質問でも「その他…」を使えます
  - プレビューが付いた選択肢は、選ぶと一覧の下にそのプレビューが表示されます
  - 以上はいずれも、コンピュータ側にプラグイン **2.2.2** が必要です — それが入るまで、アプリはこれらを表示しません
  - 上限が 100% に達すると、使用量タブからそのプロバイダ自身の使用量設定へ移動できます — 「Claudeの使用量を管理」 — 対象は Claude、Codex、Cursor、xAI で、米国、EU、日本で利用できます

  **改善**

  - 計画では、「メモを付けて拒否…」が「計画を続ける…」という表示になりました。実際の動作に合わせた名前です

  **修正**

  - 開いた、または再開したまま何も入力していない Claude Code のセッションが、最大 30 分間「実行中」と表示される問題。約 20 秒で「完了」に落ち着くようになりました
  - プロンプトなしで作成された OpenCode のセッション — フォークや、別のクライアントが開いたもの — が「実行中」のままになる問題
  - 使用量が古いスナップショットのまま止まり、それを最新のものとして表示し続けることがある問題
</Update>

<Update label="2026年8月" description="2.2">
  ## OpenCode

  **新機能**

  - **OpenCode** が Claude Code と Codex に加わりました。セッションはロック画面と Dynamic Island にリアルタイムで表示され、専用のマーク、カラー、書体を持ちます
  - OpenCode の権限リクエストと質問に、他の 2 つと同じようにロック画面から許可または拒否で答えられます。OpenCode では拒否するとそのターンが終わるため、カードにその影響を明記しています
  - OpenCode のセッションは、計画エージェントが動いているあいだ「計画中」と表示され、「計画を表示」でその TODO リストを開けます
  - **コマンド 1 つで導入**: `bunx nomo-ai`（または `npx nomo-ai`）がコンピュータ上の Claude Code、Codex、OpenCode を検出し、選んだものに Nomo をインストールします

  **改善**

  - ペイウォールに 3 つのエージェントすべてが並び、承認機能が実際に何をするのかを説明するようになりました。通知が届くだけでなく、ロック画面から答えられます
  - モデルプロバイダが再試行しているあいだ、セッションは生のエラー文字列ではなく「再接続中…」と表示されます

  **セキュリティ**

  - `nomo://` リンクだけでコンピュータがペアリングされることはなくなりました。ペアリングと接続先のサーバーを示したうえで、確認を求めます
  - サブスクリプションの状態は、ペアリングごとに個別に伝えられます。あるコンピュータが他のコンピュータを知ることはありません
  - Cursor の接続を解除すると Cookie も消去され、知らないうちに再ログインされかねないセッションが残らなくなりました

  **修正**

  - ペアリング済みのコンピュータで「ローカル」が 1 文字に切り詰められて表示される問題
</Update>
