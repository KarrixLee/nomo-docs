<Update label="2026年10月" description="2.2.2">
  ## 回答方法の拡充

  **新機能**

  - Claude Code の計画を承認するときに、ただ承認するだけでなく、その後の進め方も選べるようになりました — 「承認して編集を自動承認」または「承認して自動モード」です。Claude Code のそれ以外の許可リクエストには「承認して自動モードに切り替え」が加わります
  - 質問には、一覧から選ぶだけでなく、「その他…」で自分の回答を入力し、「メモを追加」でメモを添えられます
  - 自由入力の回答を受け付ける Codex の質問でも「その他…」を使えます
  - プレビューが付いた選択肢は、選ぶと一覧の下にそのプレビューが表示されます
  - 以上はいずれも、コンピュータ側にプラグイン **2.2.2** が必要です — それが入るまで、アプリはこれらを表示しません
  - 上限が 100% に達すると、使用量タブからそのプロバイダ自身の使用量設定へ移動できます — 「Claudeの使用量を管理」 — 対象は Claude、Codex、Cursor、xAI で、米国、EU、日本で利用できます

  **改善**

  - 計画では、「メモを付けて拒否…」が「計画を続ける…」という表示になりました。実際の動作に合わせた名前です

  **修正**

  - 開いた、または再開したまま何も入力していない Claude Code のセッションが、最大 30 分間「実行中」と表示される問題。約 20 秒で「完了」に落ち着くようになりました
  - プロンプトなしで作成された OpenCode のセッション — フォークや、別のクライアントが開いたもの — が「実行中」のままになる問題
  - 使用量が古いスナップショットのまま止まり、それを最新のものとして表示し続けることがある問題
</Update>

<Update label="2026年8月" description="2.2">
  ## OpenCode

  **新機能**

  - **OpenCode** が Claude Code と Codex に加わりました。セッションはロック画面と Dynamic Island にリアルタイムで表示され、専用のマーク、カラー、書体を持ちます
  - OpenCode の権限リクエストと質問に、他の 2 つと同じようにロック画面から許可または拒否で答えられます。OpenCode では拒否するとそのターンが終わるため、カードにその影響を明記しています
  - OpenCode のセッションは、計画エージェントが動いているあいだ「計画中」と表示され、「計画を表示」でその TODO リストを開けます
  - **コマンド 1 つで導入**: `bunx nomo-ai`（または `npx nomo-ai`）がコンピュータ上の Claude Code、Codex、OpenCode を検出し、選んだものに Nomo をインストールします

  **改善**

  - ペイウォールに 3 つのエージェントすべてが並び、承認機能が実際に何をするのかを説明するようになりました。通知が届くだけでなく、ロック画面から答えられます
  - モデルプロバイダが再試行しているあいだ、セッションは生のエラー文字列ではなく「再接続中…」と表示されます

  **セキュリティ**

  - `nomo://` リンクだけでコンピュータがペアリングされることはなくなりました。ペアリングと接続先のサーバーを示したうえで、確認を求めます
  - サブスクリプションの状態は、ペアリングごとに個別に伝えられます。あるコンピュータが他のコンピュータを知ることはありません
  - Cursor の接続を解除すると Cookie も消去され、知らないうちに再ログインされかねないセッションが残らなくなりました

  **修正**

  - ペアリング済みのコンピュータで「ローカル」が 1 文字に切り詰められて表示される問題
</Update>

<Update label="2026年8月19日" description="2.1.1">
  ## 修正と細部の調整

  **新機能**

  - 使用量アラートが **xAI/Grok** と **Gemini** に対応。Claude のモデル別の週次上限にも対応しました
  - 計画を**全文**スマートフォンで読めるようになりました。これまでは冒頭だけでした

  **改善**

  - すべての言語で翻訳を修正しました。誤った意味のラベルや、同じ概念に 2 通りの訳語が使われていた箇所があります
  - 許可カードは、生のシェルコマンドではなくエージェントが何をしようとしているかを先頭に表示します
  - Dynamic Island でセッションのタイトルとタイマーが詰まったり切れたりしなくなりました
  - iPad で、画面幅いっぱいに広がらず読みやすい幅に収まるようになりました
  - ダウンロードサイズを削減

  **修正**

  - 有料の導入オファーがあるのに、ペイウォールが無料トライアルしか表示しない問題
  - Codex のセッションで **Macで開く** が動作しない問題
  - Cursor の 2 つの使用量枠に小サイズウィジェットから再びアクセスできるようになりました
  - 初回起動ガイドでのクラッシュ
</Update>

<Update label="2026年8月11日" description="2.1">
  ## ロック画面からエージェントに答える

  **新機能**

  - 許可のリクエストがロック画面と Dynamic Island に表示されます — 机に戻らなくても承認・拒否ができます
  - 現在のプランと残りの使用量が、セッション上でひと目でわかるようになりました
  - **LAN モード** — iPhone とコンピュータが同じ Wi-Fi ネットワークにいるときは、更新が両者のあいだを直接行き来します。エンドツーエンドの暗号化はそのままです
  - Grok（xAI）と Gemini（Google）が Claude、OpenAI、Cursor に加わりました

  **修正**

  - ウィジェットで日本語などの非ラテン文字が途中で切れる問題
  - ウィジェット、通知、ライブアクティビティ全体のレイアウトと安定性
</Update>

<Update label="2026年7月14日" description="2.0">
  ## セッション

  **新機能**

  - **セッション**タブ — QR コードのスキャンでコンピュータをペアリングし、Claude Code と Codex のセッションが動く様子をロック画面と Dynamic Island でそのまま追えます
  - 実行中・完了・要対応の状態に加えて、使用中のモデルとセッションタイトルを表示
  - AES-256-GCM によるエンドツーエンド暗号化。鍵が端末から出ることはなく、中継サーバーが見るのは暗号文だけです
  - Nomo Pro でライブのセッションが使えるようになります

  **改善**

  - 使用量に「使用済み」と「残り」の両方を表示

  **修正**

  - OpenAI の週間使用量の集計
</Update>
