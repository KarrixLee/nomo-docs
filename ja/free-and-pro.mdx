Nomo でのコンピュータのペアリングは無料です。連続記録、コーディング時間、各コンピュータの状態も無料で見られます。

Nomo Pro はリアルタイムの部分です。ロック画面と Dynamic Island に表示されるライブセッションと、iPhone からエージェントに応答する機能が含まれます。

ステータス、使用量、通知にはコンピュータは必要ありません。[ステータスと使用量](/ja/status-usage)をご覧ください。

## 機能の比較 {#what-you-get}

| | 無料 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| ペアリングできるコンピュータ | 1 台 | 2 台以上 |
| 「ホーム」の[アクティビティ](/ja/activity): 連続記録とコーディング時間 | ✓ | ✓ |
| アクティビティのカレンダー | 直近 30 日 | 直近 26 週間 |
| [トークン](/ja/activity#tokens-chart): 合計とグラフ | | ✓ |
| [あなたのまとめ](/ja/activity#wrapped) | 「週」と「月」 | 「年」とトークンが追加 |
| ウィジェット | [無料ウィジェット](/ja/free-widgets#free-and-pro)をご覧ください | すべて |
| 「セッション」タブ | コンピュータの一覧。それぞれに、エージェントがいま何をしているかを示す 1 行が表示されます | ライブセッションを 1 つずつ表示 |
| Dynamic Island とロック画面のライブアクティビティ | | ✓ |
| 許可リクエストや質問への応答、返信、ターンの中断、全文表示 | | ✓ |
| [Grok Bot と Cursor](/ja/widgets#grok-bot) のアクティビティ | | ✓ |

<Note>
  無料のペアリングでは、Pro のペアリングよりもコンピュータから送信されるデータが少なくなります。送信される内容の詳細は、プラグインの README の [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer) にあります。
</Note>

## 無料で始める {#get-the-free-part}

<Steps>
  <Step title="プラグインのインストール">
    コンピュータに Nomo プラグインをインストールします。[インストール](/ja/setup/install)をご覧ください。
  </Step>

  <Step title="コンピュータのペアリング">
    Nomo で、「ホーム」の「Macをペアリング」をタップします。[ペアリング](/ja/setup/pairing)をご覧ください。
  </Step>

  <Step title="いつもどおりコーディング">
    いつもどおりエージェントを使います。連続記録とコーディング時間が、「ホーム」の[アクティビティ](/ja/activity)に表示されます。
  </Step>
</Steps>

## 別のコンピュータを使う {#use-a-different-computer}

Nomo Free でペアリングできるコンピュータは 1 台です。別のコンピュータに切り替えるには、先に古いコンピュータを削除します。

<Steps>
  <Step title="古いコンピュータの削除">
    Nomo で「セッション」を開きます。コンピュータをタッチして押さえたままにし、「このコンピュータを削除」をタップします。
  </Step>

  <Step title="確認">
    もう一度「このコンピュータを削除」をタップします。
  </Step>

  <Step title="新しいコンピュータのペアリング">
    1 台目と同じ方法でペアリングします。[ペアリング](/ja/setup/pairing)をご覧ください。
  </Step>
</Steps>

複数のコンピュータを同時に使いたい場合は、Nomo Pro をご利用ください。

## Nomo Pro の追加 {#add-nomo-pro}

「セッション」タブでコンピュータを 1 台タップすると、Nomo Pro で追加される機能が表示されます。

コンピュータはペアリングされたままです。登録すると、1 分ほどでライブセッションが始まります。
