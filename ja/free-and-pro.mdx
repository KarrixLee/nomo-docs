Nomo でのコンピュータのペアリングは無料です。連続記録、コーディング時間、各コンピュータの状態も無料で見られます。

Nomo Pro はリアルタイムの部分です。ロック画面と Dynamic Island に表示されるライブセッションと、iPhone からエージェントに応答する機能が含まれます。

ステータス、使用量、通知にはコンピュータは必要ありません。[ステータスと使用量](/ja/status-usage)をご覧ください。

## 機能の比較

| | 無料 | Nomo Pro <span className="pro-pill" /> |
| --- | --- | --- |
| コンピュータのペアリング | ✓ | ✓ |
| 現在と最長の連続記録（どのエージェントでもカウントされます） | ✓ | ✓ |
| アクティビティの履歴（ヒートマップ） | 直近 30 日 | すべて |
| コーディング時間（今日と今週） | ✓ | ✓ |
| トークン（合計、グラフ、モデル別・エージェント別） | | ✓ |
| 共有用の**まとめ**カード | **週**と**月**。**投稿**（4:5）または**ストーリーズ**（9:16）で共有できます。大きな数字は連続記録かコーディング時間です | **年**と、大きな数字としてのトークンが追加されます |
| Proウィジェット | **Nomoアクティビティ**の小サイズ（連続記録） | 5 つすべて、すべてのサイズ |
| **セッション**タブ | コンピュータの一覧。それぞれに、エージェントがいま何をしているかを示す 1 行が表示されます | ライブセッションを 1 つずつ表示 |
| Dynamic Island とロック画面のライブアクティビティ | | ✓ |
| 許可リクエストや質問への応答、返信、ターンの中断、全文表示 | | ✓ |
| Cursor のダッシュボードから取得する Cursor と Grok Bot のアクティビティ | | ✓ |

どちらも、ペアリングできるコンピュータは 5 台までです。

**Nomo** ステータスウィジェットと **Nomo使用量** ウィジェットは、誰でも無料で使えます。[すべてのウィジェット](/ja/widgets)をご覧ください。

<Note>
  無料のペアリングでは、Pro のペアリングよりもコンピュータから送信されるデータが少なくなります。送信される内容の詳細は、プラグインの README の [What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer) にあります。
</Note>

## 無料で始める

<Steps>
  <Step title="プラグインのインストール">
    コンピュータに Nomo プラグインをインストールします。[インストール](/ja/setup/install)をご覧ください。
  </Step>

  <Step title="コンピュータのペアリング">
    Nomo で**セッション**を開き、**コンピュータをペアリング**をタップします。[ペアリング](/ja/setup/pairing)をご覧ください。
  </Step>

  <Step title="いつもどおりにコーディング">
    いつもどおりにエージェントを使ってください。連続記録とコーディング時間が、Nomo の**ホーム**に表示されます。
  </Step>
</Steps>

## Nomo Pro を追加する

**セッション**タブでコンピュータをタップすると、Nomo Pro で追加される機能が表示されます。

コンピュータのペアリングはそのまま残ります。登録すると、1 分ほどでライブセッションが始まります。
