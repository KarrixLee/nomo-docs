Nomo は、Grok Bot のチャットをセッションとしては表示しません。Grok Bot は「セッション」リストにも Dynamic Island にも表示されません。表示されるのは、Grok Bot のステータス、使用量、そして使った日とトークンです。どれも iPhone だけで使えます。コンピュータは必要ありません。

## 表示されるもの

| | プラン | 必要なもの |
| --- | --- | --- |
| Grok Bot のステータス（ウィジェットと通知） | 無料 | なし |
| 使用量（ウィジェットと通知） | 無料 | Nomo で Cursor を接続 |
| 消費ペースの行と Nomo消費ペースのウィジェット | Nomo Pro | Nomo で Cursor を接続 |
| Nomoアクティビティと Nomoトークンに Grok Bot を使った日とトークン | Nomo Pro | Nomo で Cursor を接続 |

## iPhone で使えるもの {#iphone-only}

それぞれの行に専用のページがあります。

- **ステータス**: ウィジェットで、Cursor の **Grok Bot** サービスを選びます。[ステータス](/ja/status)と[ウィジェット](/ja/widget)をご覧ください。
- **使用量**: Cursor を接続します。[Cursor と Grok](/ja/usage#cursor-and-grok)をご覧ください。
- **通知**: [通知](/ja/notifications)をご覧ください。
- **消費ペース**: [消費ペース](/ja/usage#pace)と [Nomo消費ペース](/ja/widgets#nomo-pace)をご覧ください。
- **日数とトークン**: 次のセクションをご覧ください。

## Grok Bot を連続記録に数える {#streak}

Nomo 2.4.2 と Nomo Pro が必要です。

<Warning>
  接続するのは Grok ではなく **Cursor** です。Nomo で **Grok** を接続すると週間上限は表示されますが、Grok Bot を使った日やトークンは表示されません。これらは Cursor からしか届きません。
</Warning>

<Steps>
  <Step title="Cursor を接続する">
    1. Nomo を開きます。
    2. 「プロバイダー」タブをタップします。
    3. 「Cursor」をタップします。
    4. 上部の「使用量」をタップします。
    5. 「Cursorアカウントを接続」をタップします。
    6. **cursor.com** を使ったサインインの許可を iOS が求めます。「続ける」をタップします。
    7. Cursor のページで、Grok Bot に使っているのと同じアカウントでサインインします。Grok か X のアカウントです。

    ページは自動で閉じます。そのアカウントで Cursor をすでに接続している場合は、この手順は飛ばしてください。
  </Step>

  <Step title="アクティビティ画面を開く">
    [アクティビティ画面](/ja/widgets#activity-screen)を開きます。開いたときに、Grok Bot を使った日とトークンを取得します。下に引っ張って、もう一度取得することもできます。
  </Step>

  <Step title="ウィジェットを追加する">
    Nomoアクティビティか Nomoトークンのウィジェットを追加します。ウィジェットをタッチして押さえたままにし、「ウィジェットを編集」をタップします。「キャラクター」をタップして、**Grok Bot** を選びます。[Nomoアクティビティ](/ja/widgets#nomo-activity)をご覧ください。
  </Step>
</Steps>

## 数えられるもの

- その日に Grok Bot が少しでもトークンを使っていれば、その日を数えます。スケジュールされたルーティンも数えます。
- Grok Bot のスマートフォンアプリでの利用も数えます。
- Nomoトークンとアクティビティ画面には、Grok Bot の実際のトークン数が表示されます。
- Cursor エディタやそのコマンドラインでのあなた自身の Cursor の利用も、別の行「**Cursor**」に表示されます。
- The X Subscription では、Grok Bot と Cursor が 1 つの週間上限を共有し、Nomo はそれを表示します。以前の Cursor のプランでは Grok Bot に別の上限があり、Nomo はそれを読み取りません。

## プライバシー {#privacy}

- Nomo が読み取るのは、1 時間ごとのトークン数だけです。メッセージや、あなたが書いたものは読み取りません。
- 数値は Cursor のサーバーから直接 iPhone に届きます。どこにもアップロードされません。
- Cursor のサインイン情報は iPhone のキーチェーンに保存され、Cursor にだけ送られます。

やめるには、「プロバイダー」タブで Cursor を開き、「使用量」をタップして、「接続解除」をタップします。これで Nomo での Cursor の使用量の表示も止まります。
