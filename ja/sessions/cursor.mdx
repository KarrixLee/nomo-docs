Cursor のセッションも、同じ一覧、同じ Dynamic Island、同じペアリングの上に表示されます — Cursor デスクトップアプリのエージェントでも、`cursor-agent` CLI でも同じです。このバージョンでは**読み取り専用**です。Cursor のセッションは iPhone から見守り、回答はコンピュータで行います。

<Note>
  セッションは Nomo Pro の機能で、これは Cursor でもほかのエージェントでも変わりません。Cursor のセッションには、iPhone 側に最新バージョンの Nomo も必要です。
</Note>

## セットアップ {#set-it-up}

<Steps>
  <Step title="インストーラーを実行する">
    Mac で実行します。

    <CodeGroup>
    ```bash bunx icon="terminal"
    bunx nomo-ai --cursor
    ```

    ```bash npx icon="terminal"
    npx nomo-ai --cursor
    ```
    </CodeGroup>

    このインストール 1 回で、デスクトップアプリと `cursor-agent` の両方がカバーされます。行うことは 3 つです。

    - プラグインを `~/.nomo` にクローンします。
    - Nomo のフックのエントリを `~/.cursor/hooks.json` に追加します。すでにある内容とマージし、ほかのツールのエントリには手を付けません。
    - `~/.cursor/skills/` の下に 4 つのスキルをインストールします。
  </Step>

  <Step title="Cursor を再起動する — 必須">
    <Warning>
      Cursor がフックを読み込むのは起動時だけです。Cursor を終了して開き直し、開いている `cursor-agent` のセッションがあればそれも再起動してください。そうするまで、プラグインはインストール済みでも何もしません。
    </Warning>
  </Step>

  <Step title="ペアリングする">
    Cursor で `/` と入力してスキルを選び、次を実行します。

    ```
    /nomo-pair
    ```

    QR コードが表示されるので、Nomo アプリでスキャンしてください。ブラウザを開けない環境では、`/nomo-pair code` で代わりに入力できる短いコードが得られます。どちらの手順も[ペアリング](/ja/setup/pairing)で順を追って説明しています。

    ペアリングは、1 台の Mac 上のエージェントで共有されます。Claude Code、Codex、OpenCode のいずれかですでにペアリング済みのコンピュータは、Cursor のためにもう一度ペアリングする必要はありません — インストールするだけで十分で、この手順は飛ばせます。
  </Step>

  <Step title="Cursor タブを表示する">
    アプリでそのコンピュータを開きます。Cursor のセッションは、セッションのドロワーの **Cursor** タブの下に並びます。

    ドロワーに表示されるエージェントのタブは最大 3 つです。Cursor がその中にない場合は、**+** ボタン（「エージェントを選択」）をタップしてオンにしてください。
  </Step>
</Steps>

## コマンド {#commands}

接頭辞のないスキルが 4 つあります。Cursor で `/` と入力して選びます。

| | |
| --- | --- |
| `/nomo-pair` | Nomo アプリでスキャンする QR コードを表示します。`/nomo-pair code` はブラウザを使わない手順です。 |
| `/nomo-status` | ペアリングとフックの状態。 |
| `/nomo-reset` | ペアリングを解除せずに、停止したセッションの行を消去します。 |
| `/nomo-unpair` | このコンピュータのペアリングを解除します。 |

Cursor に approvals コマンドはありません — 一時停止するリモート承認がないからです。そのほかの詳細は[コマンド](/ja/sessions/commands)にあります。

## 表示されるもの {#what-you-see}

- セッションが現れるのは、チャットで**最初のプロンプト**を送ったときです — チャットを開いただけでは現れません。
- エージェントが動いている間は `実行中`、ターンが終わると `完了` と表示されます。
- チャット、ウィンドウ、または CLI を閉じると削除されます。
- タイトルは、Cursor がそのチャットに付ける名前 — チャットのタブや履歴に表示されるもの — です。はじめは最初のプロンプトが表示され、ターンの途中、またはターンが終わって間もなく Cursor の名前に切り替わります。
- モデルのバッジには、Cursor が報告するモデルが表示されます。
- [Dynamic Island](/ja/sessions/island) は、そこに表示すると選んだセッションについて、ほかのエージェントと同じように動作します。

## このバージョンでの制限 {#what-this-version-doesnt-do}

- **リモート承認は非対応**。Cursor の Run / Skip の許可リクエストを iPhone から「許可」または「拒否」することはできず、Cursor があなたを待っていることも iPhone には表示されません。Cursor はそれをプラグインに公開していません。
- **質問と計画の承認は非対応**。Cursor の質問と計画の承認は表示されず、iPhone から回答することもできません。
- **「Macで開く」は非対応**。Cursor のセッションでは、このボタンは使えません。
- **「中断」は非対応**。Cursor のセッションでは、[「中断」](/ja/sessions/list#interrupt-a-running-session)ボタンも使えません。
- **クラウドエージェントは非対応**。Cursor のクラウドエージェントとバックグラウンドエージェントは表示されません — 表示されるのは Mac 上で動いているエージェントだけです。
- **タイトルが最初のプロンプトのままになることがあります**。Cursor が付けたチャット名を読み取れない場合は、最初のプロンプトのままです — Nomo はターンが終わってからおよそ 2 分間、確認を続けます。`cursor-agent` CLI で実行したチャットは、最初のプロンプトのタイトルのままです。Cursor のローカルデータベースから読み取るのはチャット名だけで、それ以外は何も送信されません。
- **クラッシュするとセッションが残ることがあります**。Cursor が強制終了されたりクラッシュしたりすると、セッションはすぐには終了せず、タイムアウトするまで — およそ 30 分 — `実行中` のまま残ることがあります。

## 更新 {#updating}

同じコマンドをもう一度実行し、そのあと Cursor を再起動します。

```bash
bunx nomo-ai --cursor
```

## アンインストール {#uninstalling}

```bash
node ~/.nomo/plugin/scripts/cursor-install.mjs --uninstall
```

そのあと Cursor を再起動します。アンインストールでは 4 つのスキルが削除されますが、ペアリングはそのまま残ります — このコンピュータのほかのエージェントと共有されているためです。コンピュータのペアリングも解除する場合は、アンインストールの前に `/nomo-unpair` を実行してください。

うまく表示されないときは、まず[トラブルシューティング](/ja/sessions/troubleshooting)の Cursor の項目をご覧ください。
