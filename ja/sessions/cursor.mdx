Cursor のセッションも、同じ一覧、同じ Dynamic Island、同じペアリングの上に表示されます — Cursor デスクトップアプリのエージェントでも、`cursor-agent` CLI でも同じです。このバージョンでは**読み取り専用**です。Cursor のセッションは iPhone から見守り、回答はコンピュータで行います。

<Note>
  ライブセッションは Nomo Pro の機能で、これは Cursor でもほかのエージェントでも変わりません。Cursor のセッションには、iPhone 側に最新バージョンの Nomo も必要です。
</Note>

## ほかのエージェントとの共通点 {#what-works-the-same}

セッション、フォルダ、[Dynamic Island](/ja/sessions/island) は、ほかのエージェントと同じように動作します。共通の内容は、それぞれ 1 か所にまとめてあります。

- **インストール** → [インストール](/ja/setup/install)の **Cursor** タブ。1 回のインストールで、デスクトップアプリと `cursor-agent` の両方がカバーされます。
- **ペアリング** → [ペアリング](/ja/setup/pairing)。1 回のペアリングで、そのコンピュータのすべてのエージェントがカバーされます。
- **コマンド、更新、アンインストール** → [コマンド](/ja/sessions/commands)の [update](/ja/sessions/commands#update) と [uninstall](/ja/sessions/commands#uninstall)。
- **エージェントごとにできること** → [できること](/ja/sessions/features)。
- **うまくいかないとき** → [トラブルシューティング](/ja/sessions/troubleshooting)。

## 4 つのスキル、approvals コマンドなし {#four-skills-no-approvals-command}

Cursor 用の Nomo のコマンドは、接頭辞のないスキルです。Cursor で `/` と入力して、`/nomo-pair`、`/nomo-status`、`/nomo-reset`、`/nomo-unpair` から選びます。

Cursor に approvals コマンドはありません — 一時停止するリモート承認がないからです。

## 表示されるもの {#what-you-see}

- セッションが現れるのは、チャットで**最初のプロンプト**を送ったときです — チャットを開いただけでは現れません。
- チャット、ウィンドウ、または CLI を閉じると削除されます。
- タイトルは、Cursor がそのチャットに付ける名前 — チャットのタブや履歴に表示されるもの — です。はじめは最初のプロンプトが表示され、ターンの途中、またはターンが終わって間もなく Cursor の名前に切り替わります。
- モデルのバッジには、Cursor が報告するモデルが表示されます。

## このバージョンでの制限 {#what-this-version-doesnt-do}

- **リモート承認は非対応**。Cursor の Run / Skip の許可リクエストを iPhone から「許可」または「拒否」することはできず、Cursor があなたを待っていることも iPhone には表示されません。Cursor はそれをプラグインに公開していません。
- **質問と計画の承認は非対応**。Cursor の質問と計画の承認は表示されず、iPhone から回答することもできません。
- **「Macで開く」は非対応**。Cursor のセッションでは、このボタンは使えません。
- **「中断」は非対応**。Cursor のセッションでは、[「中断」](/ja/sessions/list#interrupt-a-running-session)ボタンも使えません。
- **クラウドエージェントは非対応**。Cursor のクラウドエージェントとバックグラウンドエージェントは表示されません — 表示されるのは Mac 上で動いているエージェントだけです。
- **タイトルが最初のプロンプトのままになることがあります**。Cursor が付けたチャット名を読み取れない場合は、最初のプロンプトのままです — Nomo はターンが終わってからおよそ 2 分間、確認を続けます。`cursor-agent` CLI で実行したチャットは、最初のプロンプトのタイトルのままです。Cursor のローカルデータベースから読み取るのはチャット名だけで、それ以外は何も送信されません。
- **クラッシュするとセッションが残ることがあります**。Cursor が強制終了されたりクラッシュしたりすると、セッションはすぐには終了しません。どのくらい残るか、どう消すかは[トラブルシューティング](/ja/sessions/troubleshooting)をご覧ください。

うまく表示されないときは、まず[トラブルシューティング](/ja/sessions/troubleshooting)の Cursor の項目をご覧ください。

## 技術的な詳細とセキュリティ {#technical-details-and-security}

Nomo が iPhone に送るのはセッションの状況だけで、送る内容はエンドツーエンド暗号化されます。

内部のしくみはプラグインの README で説明しています: [Nomo と Cursor の連携](https://github.com/KarrixLee/nomo#cursor-integration)、[フックとセキュリティ](https://github.com/KarrixLee/nomo#cursor-hooks)。
