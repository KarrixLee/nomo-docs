Devin のセッションを、iPhone のロック画面と Dynamic Island で確認できます。Devin が許可を求めると、iPhone で「許可」か「拒否」を選べます。Devin からの質問にも、iPhone から回答できます。

Devin CLI、つまりターミナルの `devin` コマンドと、[Devin Desktop](#devin-desktop) で使えます。

<Note>
  セッションは Nomo Pro の機能です。iPhone に Nomo **2.5.0** 以降、Mac にプラグイン **2.5.0** 以降が必要です。
</Note>

## セットアップ {#set-it-up}

Devin に Nomo を追加する方法は 2 つあります。**Devin プラグイン**と **Nomo インストーラー**です。どちらか一方をインストールしてください。両方をインストールした場合は、Nomo はインストーラーのほうを使い、プラグインは何もしません。

## コマンド {#commands}

Devin で次のように入力します。Devin プラグインの場合は、`/nomo-` ではなく `/nomo:` で始まります — たとえば `/nomo:pair` です。

| 入力するもの | Devin プラグインの場合 | すること |
| --- | --- | --- |
| `/nomo-pair` | `/nomo:pair` | このコンピュータを iPhone とペアリングする |
| `/nomo-pair code` | `/nomo:pair code` | 同じことを、QR コードの代わりに入力用の短いコードで行う |
| `/nomo-status` | `/nomo:status` | すべて正常に動いているか確認する |
| `/nomo-approvals off` | `/nomo:approvals off` | iPhone への確認をやめる — 代わりに Mac 上の Devin で確認されます |
| `/nomo-approvals on` | `/nomo:approvals on` | iPhone への確認を再開する |
| `/nomo-reset` | `/nomo:reset` | 止まったままのセッションを iPhone から消去する（ペアリングはそのまま） |
| `/nomo-unpair` | `/nomo:unpair` | このコンピュータと iPhone のペアリングを解除する |

Devin が Nomo のコマンドを実行してよいか確認してきたら、許可してください。Devin がコマンドを認識しない場合は、インストーラーをもう一度実行して Devin を再起動してください — または、[上級者向け](#advanced)にある方法でターミナルから実行します。

ペアリングと承認のスイッチは、このコンピュータのすべてのコーディングアプリで共有されます。ここで承認をオフにすると、Claude Code と Codex でもオフになります。

## 表示されるもの {#what-you-see}

- セッションが現れるのは、**最初のメッセージ**を送ったときです。
- Devin が作業している間は `実行中`、終わると `完了` と表示されます。
- 名前は、Devin 自身が付けるセッションのタイトルです。タイトルが付くまでは、最初のメッセージが使われます。
- バッジには、Devin が使っているモデルが表示されます。
- [Dynamic Island](/ja/sessions/island) は、ほかのエージェントと同じように動作します。

## iPhone からの回答 {#answering-from-your-phone}

Devin が許可を求めると — たとえばコマンドを実行するとき — iPhone で確認されます。

セッションをタッチして押さえたままにするか、Dynamic Island を使って、次から選びます。

<Frame caption="コマンドの実行を求めている Devin のセッション。">
  <div className="device-frame">
    <img className="only-light" src="/images/devin-approval-card.png" alt="Devin のセッション Fix token refresh race の承認カード。bun test の実行を求めていて、「拒否」「許可」「メモを付けて拒否…」のボタンがある" />
    <img className="only-dark" src="/images/devin-approval-card-dark.png" alt="Devin のセッション Fix token refresh race の承認カード。bun test の実行を求めていて、「拒否」「許可」「メモを付けて拒否…」のボタンがある" />
  </div>
</Frame>

- **「許可」** — Devin はそのまま進めます。
- **「…を常に許可（このセッション）」** — Devin はそのまま進め、このセッションが終わるまで、同じ操作について Nomo は確認しなくなります。[下記](#always-allow)をご覧ください。
- **「拒否」** — Devin はその操作を行いません。
- **「メモを付けて拒否…」** — Devin はその操作を行わず、その理由を書いたあなたのメモを受け取ります。

詳しくは [iPhone からの回答](/ja/sessions/approvals)をご覧ください。

知っておくと便利なこと:

- **Devin は iPhone からの回答を待ちます。** タイムアウトした場合は、代わりに Devin が Mac で確認します。
- **iPhone がなくても大丈夫です。** iPhone に接続できないときや、承認を[一時停止中](/ja/sessions/approvals#pausing-it)のときは、Nomo がないときと同じように、Devin が Mac で確認します。

### 常に許可 {#always-allow}

「常に許可」が有効なのは、**このセッションの間だけ**です。セッションが終わると Nomo はこれを忘れ、次のセッションではまた確認されます。

- **単純なコマンド**は、コマンド名で記憶されます。`touch b.txt` を常に許可すると、`touch c.txt` も許可されます — ただし、別のコマンドは許可されません。
- **つなげたコマンド** — `&&`、`;`、`|`、`>` を含むもの — は、すでに許可したものとまったく同じコマンドでない限り、毎回 iPhone で確認されます。そのため、`touch x && rm -rf ~` はやはり確認されます。
- **それ以外の操作**（ファイルの書き込みなど）は、セッションが終わるまで許可されます。

Nomo はこれをコンピュータ上に保存し、Devin 自身の設定は変更しません。承認を一時停止しても、セッションが終わるまでは有効なままです。

### Devin の質問への回答 {#questions}

Devin が質問してくると、セッションに `回答が必要` と表示されます。セッションをタッチして押さえたままにし、「回答…」を選びます。

1. 選択肢をタップします。Devin が許可している場合は、複数選べます。
2. 合うものがない場合は、「その他…」をタップして、自分の回答を入力します。
3. 「送信」をタップします。

「メモを追加」で、回答にコメントを付けられます。「拒否」を選ぶと、回答しないことにしたと Devin に伝わります。

<Note>
  **Mac では、質問が「rejected」と表示されます。これは想定どおりです。** Devin には Nomo から直接回答を受け取る方法がないため、Nomo はあなたの回答を、Devin の質問を閉じる理由として送ります。そのため、質問には **rejected** と表示され、その横にあなたの回答が書かれます。Devin はあなたの回答を読んで、作業を続けます。
</Note>

## 中断 {#interrupt}

`実行中` の Devin のセッションで[「中断」](/ja/sessions/list#interrupt-a-running-session)をタップすると、止められます。緑色の**⚡ ローカル**チップが必要です — iPhone と Mac が同じネットワークにつながっている必要があります。

Devin はいまのステップを終えてから止まります。コマンドや返答を途中で打ち切ることはできません。セッションは `完了` になり、Devin は開いたままなので、続けるには新しいメッセージを送ってください。

## Devin Desktop {#devin-desktop}

Devin のドキュメントによると、Devin Desktop の **Devin Local** エージェントは Devin CLI と同じエンジンで動いているため、Nomo も同じように動作します。Nomo は Devin CLI と、Devin の ACP サーバーで動作を確認しています。

- **iPhone が先に回答します。** iPhone に許可リクエストや質問が届いている間、Devin Desktop にはそのためのボタンが表示されません。iPhone で回答してください。Mac で回答したい場合は、Devin の次のプロンプトの前に[承認を一時停止](/ja/sessions/approvals#pausing-it)してください。
- **iPhone に届くもの。** Devin Desktop の標準の **Code** モードでは、Devin が確認するのは、コマンドの実行、Web ページの取得、プロジェクトの外への書き込みの前だけです。iPhone に届くのは、これらの許可リクエストです。
- **Restricted Mode では Nomo が動きません。** Restricted Mode を終えるまで、セッションは iPhone に届きません。

## Devin での違い {#whats-different-for-devin}

- **Mac 上の Devin だけ。** Devin Cloud のセッションは表示されません — Nomo が表示するのは、Mac で動いている Devin だけです。
- **短いセッションでは、モデルのバッジが表示されないことがあります。** Devin がモデルを保存するのは、セッションが終わったときだけです。
- **Devin では使えないもの:** [「返信」](/ja/sessions/antigravity#reply-from-your-phone)、「Macで開く」。

## うまくいかないとき {#troubleshooting}

<AccordionGroup>
  <Accordion title="iPhone に何も表示されない">
    1. 開いている `devin` をすべて閉じて、もう一度起動します。
    2. Nomo の状態を確認します。Devin で `/nomo-status` と入力します（プラグインの場合は `/nomo:status`）。

    3. `→` で始まる行の指示に従います。

    Devin Desktop を使っている場合は、**Restricted Mode** がオフになっていることを確認してください。

    それでも表示されない場合は、Nomo で **+** ボタン（「エージェントを選択」）をタップして、Devin をオンにしてください。

    Devin タブに「**Devinのセッションはまだありません**」と表示されている場合は、先に Devin でメッセージを送ってください。セッションは最初のメッセージを送ってから表示されます。
  </Accordion>

  <Accordion title="インストーラーに設定ファイルのコメントについて表示される">
    問題ありません。Nomo が項目を追加すると、Devin の設定ファイルにはコメントを残せなくなります。そのため、インストーラーは先に元のファイルを同じ場所に保存しています。

    ```
    ~/.config/devin/config.json.nomo-backup
    ```

    設定はすべて残っています。削除されたのはコメントだけです。
  </Accordion>

  <Accordion title="Devin で回答が「rejected」と表示される">
    これは想定どおりです。Nomo はあなたの回答を、Devin の質問を閉じる理由として送るため、Mac では質問が **rejected** と表示され、その横にあなたの回答が書かれます。Devin はあなたの回答を読んで、作業を続けます。
  </Accordion>

  <Accordion title="Devin Desktop に許可リクエストのボタンが表示されない">
    そのリクエストは iPhone に届いています。iPhone で回答してください。Mac で回答したい場合は、Devin の次のプロンプトの前に[承認を一時停止](/ja/sessions/approvals#pausing-it)してください。
  </Accordion>

  <Accordion title="「中断」しても Devin がすぐに止まらない">
    Devin はいまのステップを先に終えます — すでに実行中のコマンドや返答は、終わるまで続きます。そのあとで止まります。

    「中断」ボタンがない場合は、iPhone と Mac が同じネットワークにつながっていて、緑色の**⚡ ローカル**チップが表示されている必要があります。
  </Accordion>

  <Accordion title="iPhone で承認を求められなくなった">
    Devin で `/nomo-approvals on` と入力します（プラグインの場合は `/nomo:approvals on`）。

    すでにオンだった場合は、[設定](/ja/sessions/settings#remote-approvals)の「iPhoneで回答」を確認してください。
  </Accordion>

  <Accordion title="セッションが「実行中」のまま止まっている">
    Devin で `/nomo-reset` と入力します（プラグインの場合は `/nomo:reset`）。
  </Accordion>
</AccordionGroup>

ほかの対処法は[トラブルシューティング](/ja/sessions/troubleshooting)にあります。

## 更新 {#updating}

インストーラーを使った場合は、もう一度実行してから、Devin を再起動します。

```bash
bunx nomo-ai --devin
```

## アンインストール {#uninstalling}

**Devin プラグイン:** 次の行をコピーしてターミナルに貼り付け、Return キーを押します。

```bash
devin plugins remove nomo
```

**Nomo インストーラー:**

<Steps>
  <Step title="ターミナルで次を実行する">
    ```bash
    bunx nomo-ai --uninstall --devin
    ```

    次のように表示されます。

    ```
    devin-install: removed Nomo's hooks from Devin — restart devin
    ```

    `bunx` がない場合は、`npx nomo-ai --uninstall --devin` か `node ~/.nomo/plugin/scripts/devin-install.mjs --uninstall` を使ってください。
  </Step>

  <Step title="Devin を再起動する">
    開いている `devin` をすべて閉じて、もう一度起動します。
  </Step>
</Steps>

iPhone とのペアリングは、ほかのコーディングアプリのためにそのまま残ります。このコンピュータと iPhone のペアリングも解除したい場合は、アンインストールする**前に** Devin で `/nomo-unpair` と入力してください。

## 上級者向け {#advanced}

<AccordionGroup>
  <Accordion title="コマンドを使わずに実行する" icon="terminal">
    同じコマンドを、Devin のチャットではなくターミナルから実行できます（Nomo インストーラーの場合）。

    | | |
    | --- | --- |
    | ペアリング | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs` |
    | コードを入力してペアリング | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs --show-code` |
    | 状態の確認 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/status-cmd.mjs devin` |
    | 承認の一時停止 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs off` |
    | 承認の再開 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/cc-permission.mjs on` |
    | 止まったセッションの消去 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/reset.mjs` |
    | ペアリングの解除 | `~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/unpair.mjs` |

    ターミナルからペアリングしたあとは、`~/.nomo/plugin/scripts/run.sh ~/.nomo/plugin/dist/pair.mjs wait` を実行して QR コードをスキャンします。インストーラーに `--verbose` を付けると、何を変更するかを確認できます。
  </Accordion>

  <Accordion title="しくみ" icon="gear">
    - **インストーラーが変更するもの。** プラグインを `~/.nomo` にクローンし、`~/.config/devin/config.json` の `"hooks"` キーに Nomo の項目を追加します。ほかの Devin の設定には手を付けません。また、`/nomo-*` コマンドを Devin のスキルとして `~/.config/devin/skills/` に追加します。同じ名前のスキルがすでにある場合は、そのままにします。もう一度実行しても、何も変わりません。ファイルにコメントがある場合は、先に `config.json.nomo-backup` にコピーします。アンインストールで削除されるのは、Nomo の項目とスキルだけです。`devin` で `/hooks` と入力すると、読み込まれたものを確認できます。
    - **プラグインが追加するもの。** Devin プラグインは、同じ 2 つのフックと、同じコマンドを `/nomo:pair`、`/nomo:status`、`/nomo:approvals`、`/nomo:reset`、`/nomo:unpair` として追加します。ルール、MCP サーバー、エージェントは追加しません。動くのはローカルの Devin セッションの中だけで、Devin Cloud では動きません。インストーラーの項目がある間は、プラグインのフックは何も送りません。
    - **状態。** `UserPromptSubmit`、`PostToolUse`、`Stop`、`SessionEnd` のフックが状態を報告します。何も出力しないので、プロンプトをブロックしたり、ツールの呼び出しを変えたりすることはありません — ただし、「中断」をタップしたあとは例外で、次の `PostToolUse` が `{"continue":false}` を出力して、そのターンを終わらせます。
    - **承認。** `PermissionRequest` のフックが、ツール名とそのコマンドまたはファイルパスを、エンドツーエンド暗号化して iPhone に送ります。`approve` を返すのは、ペアリングした iPhone からそのリクエストに対して「許可」が届いたときだけで、「拒否」のときはメモを付けて `block` を返します。それ以外 — ペアリングしていない、承認が一時停止中、オフライン、タイムアウト、エラー — では何も出力せず、判断を Devin 自身の確認に任せます。
    - **質問。** 同じフックが `PreToolUse`（`ask_user_question` のときだけ）で、Devin の質問とその選択肢を、エンドツーエンド暗号化して iPhone に送ります。あなたの回答は、回答を理由にした `block` として返り、Devin のモデルがそれを読みます。
    - **常に許可。** 許可は `~/.config/cc-status/sessions/<session>.devin-allow` に保存されます。このファイルを読めるのはあなただけで、セッションが終わると削除されます。Devin 自身の設定ファイルに書き込むことはありません。
    - **行の重複なし。** Devin は Claude Code のフックも実行します。Nomo の Claude Code プラグインは Devin の中では何もしないので、Devin のセッションが Claude Code のセッションとして表示されることはありません。

    詳しくは、プラグインの [README](https://github.com/KarrixLee/nomo#install--devin) をご覧ください。
