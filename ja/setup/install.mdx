コンピュータごとに 1 回インストールします。**bun** または **node 18 以降**が必要です — プラグインに npm 依存関係はなく、Node の組み込み機能だけで動作します。

## 手動インストール {#install-by-hand}

<Tabs>
  <Tab title="Claude Code" icon="/images/claude-code.svg">
    <Tabs>
      <Tab title="ターミナル" icon="terminal">
        Claude Code のセッション内で実行します。

        ```
        /plugin marketplace add KarrixLee/nomo
        /plugin install nomo-cc@nomo
        ```
      </Tab>

      <Tab title="デスクトップアプリ" icon="window">
        **Settings** → **Plugins** → **Add** → **Add marketplace** と進み、**URL** にリポジトリを入力します。

        ```
        KarrixLee/nomo
        ```

        **Sync** を押し、一覧から **Nomo — Claude Code** をインストールします。

        <Frame caption="GitHub の owner/repo だけで十分です。Nomo のリポジトリ自体がマーケットプレイスです。">
          <img src="/images/claude-desktop-add-marketplace.png" alt="Claude デスクトップアプリの Add marketplace ダイアログ。URL に KarrixLee/nomo が入力されています" />
        </Frame>
      </Tab>
    </Tabs>

    その後 Claude Code を再起動して、プラグインのフックを読み込ませます。

    インストールされたことを確認します。

    ```
    /nomo-cc:status
    ```

    <Tip>
      Claude Code の Nomo コマンドはすべて `nomo-cc:` の名前空間に属します —
      `/nomo-cc:` と入力すると一覧が表示されます。
    </Tip>
  </Tab>

  <Tab title="Codex" icon="/images/codex.svg">
    Codex **0.142 以降**は独自のプラグインシステムを備えているため、Nomo は単体の
    Codex プラグインとしてインストールされます。Claude Code は不要です。

    <Steps>
      <Step title="プラグインをインストールする">
        <Tabs>
          <Tab title="ターミナル" icon="terminal">
            ```
            codex plugin marketplace add KarrixLee/nomo
            codex plugin add nomo@nomo
            ```

            入力するほうが早ければ、デスクトップアプリの内蔵ターミナルでも同じことができます。
          </Tab>

          <Tab title="デスクトップアプリ" icon="window">
            **プラグイン** → **追加** → **マーケットプレイスを追加** と進み、**Source** にリポジトリを入力します。

            ```
            KarrixLee/nomo
            ```

            **Git ref** と **Sparse paths** はそのままで構いません — グレーの文字はプレースホルダーで、入力する値ではありません。**マーケットプレイスを追加**を押し、一覧から **nomo** をインストールします。

            <Frame caption="Nomo のリポジトリ自体がマーケットプレイスです。一覧を探したり申請したりする必要はありません。">
              <img src="/images/codex-app-add-marketplace.png" alt="Codex デスクトップアプリの「マーケットプレイスを追加」ダイアログ。Source に KarrixLee/nomo が入力されています" />
            </Frame>
          </Tab>
        </Tabs>

        <Note>
          ここでいう「マーケットプレイス」は、見て回るストアではありません。GitHub リポジトリ — Nomo 自身のもの — を指すレジストリです。だから先にリポジトリを追加し、そこからプラグインをインストールします。
        </Note>
      </Step>

      <Step title="フックを信頼する — 必須">
        <Tabs>
          <Tab title="ターミナル" icon="terminal">
            ```
            /hooks
            ```

            **7 つの Nomo エントリ**を信頼します。ターミナルでは英語で「trust」と表示されます。
          </Tab>

          <Tab title="デスクトップアプリ" icon="window">
            歯車アイコンから **フック** → **nomo** を開き、オンにします。
          </Tab>
        </Tabs>

        <Warning>
          この手順は省略しないでください。Nomo のフックはプラグインに同梱されていますが、**信頼するまで動作しません**。実行するまで、プラグインはインストール済みでも何もしません — セッションはスマートフォンに届かず、エラーも報告されません。
        </Warning>

        これは Codex 自身の安全ゲートであり、Nomo が事前に承認することはできません。フックのコマンド行はリリース間でバイト単位で安定しているため、一度信頼すれば更新後もそのまま維持されます — フック行が変更された場合にのみ再確認が求められます。
      </Step>

      <Step title="確認する">
        ```
        $nomo-status
        ```

        これはペアリング、ウォッチドッグ、**フックの信頼状態**、最終配信の状態を報告します — つまり、信頼の手順が実際に反映されたかを確認する方法でもあります。
      </Step>
    </Steps>

    <Tip>
      Codex のスキルはスラッシュではなく `$` を接頭辞に使います — `$nomo-pair`、
      `$nomo-status`、`$nomo-reset`、`$nomo-unpair`。
    </Tip>
  </Tab>

  <Tab title="OpenCode" icon="/images/opencode.svg">
    OpenCode にはマーケットプレイスもプラグイン用のコマンドもありません — 自身の設定フォルダにあるものをそのまま読み込みます。そのため Nomo はクローンからインストールし、スクリプト 1 つで、OpenCode がもともと見ている場所へファイルを配置します。

    <Steps>
      <Step title="クローンしてインストーラーを実行する">
        ```bash
        git clone https://github.com/KarrixLee/nomo.git ~/.nomo
        ~/.nomo/plugin/scripts/opencode-install.sh
        ```

        クローン先はどこでも構いません — スクリプトが自身の場所を判断するため、調べるパスも手で書き換える箇所もありません。何を書き込んだかは、そのつど表示されます。

        - `~/.config/opencode/plugins/nomo.js` — クローンを指す 1 行のスタブ。
        - `~/.config/opencode/commands/nomo-*.md` — 6 つのコマンド。

        Claude Code や Codex 向けに Nomo をインストール済みの場合は、2 つ目をクローンせずに、そのコピーをスクリプトに指定してください — 場所は `claude plugin list` または `codex plugin list` で確認できます。

        <Tip>
          `--project` を付けると、グローバルではなく 1 つのリポジトリの `./.opencode` にインストールします。再実行しても安全で、クローンを移動するときもこの方法を使います。新しい場所からもう一度実行してください。
        </Tip>
      </Step>

      <Step title="OpenCode を再起動する — 必須">
        <Warning>
          OpenCode がプラグインを読み込むのはサーバーの起動時の 1 回だけで、ホットリロードはありません。終了して開き直すまで、プラグインはインストール済みでも何もしません。デスクトップアプリも同じサーバーを動かしているので、同じ再起動が必要です。
        </Warning>
      </Step>

      <Step title="確認する">
        ```
        /nomo-status
        ```
      </Step>
    </Steps>

    このインストール 1 回で OpenCode のデスクトップアプリもカバーされます。アプリは OpenCode 自身のサーバーを動かしており、同じプラグインフォルダを読むからです。

    <Note>
      あとから更新するときは、OpenCode の中でコマンド 1 つです。`/nomo-update` はまず確認し、そのうえで取得してこのインストーラーを実行し直します — [動作と、実行を断る条件](/ja/sessions/commands#update)。
    </Note>

    <Tip>
      OpenCode のコマンド名はフラットでグローバルなので、Nomo のコマンドにも接頭辞は一切付きません。`/nomo-cc:pair` でも `$nomo-pair` でもなく `/nomo-pair` です。6 つとも[コマンド](/ja/sessions/commands)にまとめてあります。
    </Tip>

    iPhone 側で違って見える点は[OpenCode での利用](/ja/sessions/opencode)にあります。
  </Tab>
</Tabs>

## コマンド 1 つ {#one-command}

インストーラーがこのマシン上の Claude Code、Codex、OpenCode を検出し、選んだものに Nomo を組み込みます。

<CodeGroup>
```bash bunx icon="terminal"
bunx nomo-ai
```

```bash npx icon="terminal"
npx nomo-ai
```
</CodeGroup>

最初はどれも選択されていません。矢印キー（または `k` / `j`）で移動し、スペースキーで選択、Enter キーで選択したものをまとめてインストールします。そのあと、それぞれのエージェント本来のインストール手順 — 上の 3 つの流れ — が実行されます。グローバルには何もインストールせず、パッケージも残しません。

スクリプトや CI で使うときは、次のオプションが使えます。

| オプション | |
| --- | --- |
| `--claude` `--codex` `--opencode` | 指定したものだけをインストールします。いずれかを指定すると選択画面は出ません |
| `--all` | 検出の有無にかかわらず 3 つすべて |
| `-y`、`--yes` | 選択画面を出さず、検出したものをすべてインストールします |
| `-n`、`--dry-run` | 実行するコマンドを表示するだけで、何も実行しません |

iPhone のペアリングは行いません。そのあとは、上の手順とまったく同じように仕上げます。エージェントを再起動し、Codex ならフックを信頼し、ペアリングします — `/nomo-pair`、Claude Code なら `/nomo-cc:pair`、Codex なら `$nomo-pair` です。

### 更新 {#updating}

同じコマンドが更新も行います。すでに Nomo が入っているエージェントは、インストールではなく更新として表示されます。実行されるのは OpenCode の分だけで、残る 2 つは表示されるだけです。

<Tabs>
  <Tab title="Claude Code" icon="/images/claude-code.svg">
    ```bash
    claude plugin update nomo-cc@nomo
    ```

    自動更新はサードパーティのマーケットプレイスでは無効が既定なので、放っておいてインストールが動くことはありません。有効にするには `/plugin` → **Marketplaces** → Nomo のもの → **Enable auto-update** と進みます。
  </Tab>

  <Tab title="Codex" icon="/images/codex.svg">
    通常、実行するものはありません。Codex はプラグインをそのパスから直接読み込むため、そのクローンで取得することが更新のすべてです。`codex plugin update` という動詞もそもそも存在しません。

    マーケットプレイスを git から追加した場合は、Codex がスナップショットを保持しており、それを更新することが更新にあたります。

    ```bash
    codex plugin marketplace upgrade <マーケットプレイス名>
    ```

    名前は追加したときのもので、必ずしも `nomo` とは限りません。
  </Tab>

  <Tab title="OpenCode" icon="/images/opencode.svg">
    これはインストーラーが行います。OpenCode の中から [`/nomo-update`](/ja/sessions/commands#update) を実行しても同じです。

    どちらの場合も、そのあと OpenCode を再起動してください。プラグインはサーバーの起動時に 1 回だけ読み込まれます。
  </Tab>
</Tabs>

## プラグインの動作

プラグインはセッションを監視し、状態の変化をスマートフォンに報告します。エージェントが何に取り組んでいるか、いつ停止したか、いつ何かの許可を必要としているかです。

[スマートフォンをペアリング](/ja/setup/pairing)するまで、プラグインは何も送信しません。送信されるものはすべて、このマシン上で先に暗号化されます。

プラグインは**オープンソース**です — インストール前に、何を収集し何を送信するかを正確に読むことができます。
