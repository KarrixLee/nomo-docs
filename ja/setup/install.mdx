コンピュータごとに 1 回インストールします。**bun** または **node 18 以降**が必要です — プラグインに npm 依存関係はなく、Node の組み込み機能だけで動作します。

<Tabs>
  <Tab title="Claude Code" icon="/images/claude-code.svg">
    Claude Code のセッション内で実行します。

    ```
    /plugin marketplace add KarrixLee/nomo
    /plugin install nomo-cc@nomo
    ```

    その後 Claude Code を再起動して、プラグインのフックを読み込ませます。

    インストールされたことを確認します。

    ```
    /nomo-cc:status
    ```

    <Tip>
      Claude Code の Nomo コマンドはすべて `nomo-cc:` の名前空間に属します —
      `/nomo-cc:` と入力すると一覧が表示されます。
    </Tip>
  </Tab>

  <Tab title="Codex" icon="/images/codex.svg">
    Codex **0.142 以降**は独自のプラグインシステムを備えているため、Nomo は単体の
    Codex プラグインとしてインストールされます。Claude Code は不要です。

    <Steps>
      <Step title="プラグインをインストールする">
        <Tabs>
          <Tab title="デスクトップアプリ" icon="window">
            **プラグイン** → **追加** → **マーケットプレイスを追加** と進み、**Source** にリポジトリを入力します。

            ```
            KarrixLee/nomo
            ```

            **Git ref** と **Sparse paths** はそのままで構いません — グレーの文字はプレースホルダーで、入力する値ではありません。**マーケットプレイスを追加**を押し、一覧から **nomo** をインストールします。

            <Frame caption="Nomo のリポジトリ自体がマーケットプレイスです。一覧を探したり申請したりする必要はありません。">
              <img src="/images/codex-app-add-marketplace.png" alt="Codex デスクトップアプリの「マーケットプレイスを追加」ダイアログ。Source に KarrixLee/nomo が入力されています" />
            </Frame>
          </Tab>

          <Tab title="ターミナル" icon="terminal">
            ```
            codex plugin marketplace add KarrixLee/nomo
            codex plugin add nomo@nomo
            ```

            入力するほうが早ければ、デスクトップアプリの内蔵ターミナルでも同じことができます。
          </Tab>
        </Tabs>

        <Note>
          ここでいう「マーケットプレイス」は、見て回るストアではありません。GitHub リポジトリ — Nomo 自身のもの — を指すレジストリです。だから先にリポジトリを追加し、そこからプラグインをインストールします。
        </Note>
      </Step>

      <Step title="フックを信頼する — 必須">
        <Tabs>
          <Tab title="デスクトップアプリ" icon="window">
            歯車アイコンから **フック** → **nomo** を開き、オンにします。
          </Tab>

          <Tab title="ターミナル" icon="terminal">
            ```
            /hooks
            ```

            **7 つの Nomo エントリ**を信頼します。ターミナルでは英語で「trust」と表示されます。
          </Tab>
        </Tabs>

        <Warning>
          この手順は省略しないでください。Nomo のフックはプラグインに同梱されていますが、**信頼するまで動作しません**。実行するまで、プラグインはインストール済みでも何もしません — セッションはスマートフォンに届かず、エラーも報告されません。
        </Warning>

        これは Codex 自身の安全ゲートであり、Nomo が事前に承認することはできません。フックのコマンド行はリリース間でバイト単位で安定しているため、一度信頼すれば更新後もそのまま維持されます — フック行が変更された場合にのみ再確認が求められます。
      </Step>

      <Step title="確認する">
        ```
        $nomo-status
        ```

        これはペアリング、ウォッチドッグ、**フックの信頼状態**、最終配信の状態を報告します — つまり、信頼の手順が実際に反映されたかを確認する方法でもあります。
      </Step>
    </Steps>

    <Tip>
      Codex のスキルはスラッシュではなく `$` を接頭辞に使います — `$nomo-pair`、
      `$nomo-status`、`$nomo-reset`、`$nomo-unpair`。
    </Tip>
  </Tab>
</Tabs>

## プラグインの動作

プラグインはセッションを監視し、状態の変化をスマートフォンに報告します。エージェントが何に取り組んでいるか、いつ停止したか、いつ何かの許可を必要としているかです。

[スマートフォンをペアリング](/ja/setup/pairing)するまで、プラグインは何も送信しません。送信されるものはすべて、このマシン上で先に暗号化されます。

プラグインは**オープンソース**です — インストール前に、何を収集し何を送信するかを正確に読むことができます。
