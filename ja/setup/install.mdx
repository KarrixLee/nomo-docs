コンピュータごとに 1 回インストールします。**bun** または **node 18 以降**が必要です — プラグインに npm 依存関係はなく、Node の組み込み機能だけで動作します。bun は **1.4.4** 以降、Node.js 22 は **22.23.4** 以降にしておいてください。それより古い場合は、ステータスコマンドが警告します。

## コマンド 1 つでインストール {#one-command}

<Steps>
  <Step title="インストーラーを実行する">
    ターミナルに次を貼り付けて、Return キーを押します。

    <CodeGroup>
    ```bash bunx icon="terminal"
    bunx nomo-ai
    ```

    ```bash npx icon="terminal"
    npx nomo-ai
    ```
    </CodeGroup>

    このマシンのエージェント（Claude Code、Codex、OpenCode、Cursor、Antigravity、Devin）が見つかり、選択された状態で表示されます。Return キーを押すとインストールします。選択を変えるには、矢印キー（または `k` / `j`）で移動し、スペースキーで選択・解除します。

    あわせて短い `nomo` コマンドも追加され、次のように表示されます。

    ```
    Installed the short command: type nomo pair, nomo status or nomo reset from any folder.
    ```
  </Step>

  <Step title="iPhone をペアリングする">
    `Pair your phone now? [Y/n]` と聞かれたら、Return キーを押して「はい」を選びます。

    ブラウザで QR コードのページが開きます。iPhone で Nomo を開いてスキャンしてください。手順は[ペアリング](/ja/setup/pairing)で詳しく説明しています。ブラウザを開けない場合に入力する短いコード（`nomo pair code`）も同じページにあります。

    <Frame caption="コンピュータ上のペアリングページ。スキャンが届くと自動的に Paired ✓（ペアリング済み）に切り替わります。">
      <img src="/images/pairing-pc-qrcode.png" alt="QR コードとクリックで表示されるワンタイムコードを示す Nomo のペアリングページ" />
    </Frame>

    「いいえ」を選んだ場合や、あとでペアリングしたい場合は、ターミナルで `nomo pair` を実行してください。

    エージェントの中からペアリングすることもできます。Claude Code なら `/nomo-cc:pair`、Codex なら `$nomo-pair`、OpenCode・Cursor・Antigravity・Devin なら `/nomo-pair` です（Devin プラグインの場合は `/nomo:pair`）。

    すでにペアリング済みの場合は、そう表示されてこの手順は飛ばされます。
  </Step>

  <Step title="エージェントを再起動する — 必須">
    Nomo をインストールしたエージェントをそれぞれ終了して、もう一度開いてください。再起動するまで Nomo は動きません。

    OpenCode の場合は、先にペアリングしてから再起動すると Nomo が動き始めます。

    Codex の場合は、Nomo のフックの信頼も必要です。Codex で `/hooks` と入力し、Nomo のエントリを信頼してください。詳しくは[手動インストール](/ja/setup/manual)の **Codex** タブをご覧ください。
  </Step>
</Steps>

エージェント自身のプラグインストアを使いたい場合は、[手動インストール](/ja/setup/manual)をご覧ください。

<Note>
  短い `nomo` コマンドを追加しない場合は `--no-global` を付けてください。あとで `nomo` が見つからない場合は、`bunx nomo-ai` でも同じように動きます。たとえば `bunx nomo-ai pair` です。[`nomo` が見つからない場合](/ja/sessions/commands#nomo-not-found)をご覧ください。
</Note>

<Accordion title="インストーラーのオプション（スクリプトや CI 向け）">
  | オプション | |
  | --- | --- |
  | `--claude` `--codex` `--opencode` `--cursor` `--antigravity` `--devin` | 指定したものだけをインストールします。いずれかを指定すると選択画面は出ません |
  | `--all` | 検出の有無にかかわらずすべて。ただし Cursor、Antigravity、Devin は、このマシンにない場合はスキップされます（それでも試すには `--cursor`、`--antigravity`、`--devin` のいずれかを指定します） |
  | `-y`、`--yes` | 選択画面を出さず、検出したものをすべてインストールします |
  | `-n`、`--dry-run` | 実行するコマンドを表示するだけで、何も実行しません |
  | `--no-global` | 短い `nomo` コマンドを追加しません。[ターミナルから実行する](/ja/sessions/commands#terminal)をご覧ください |
  | `uninstall` | `--cursor`、`--antigravity`、`--devin` のいずれかと一緒に指定すると、そのエージェントから Nomo を削除します（`--uninstall` も使えます）。エージェントは必ず指定してください — 推測はしません。[uninstall](/ja/sessions/commands#uninstall) をご覧ください |

  `-y` を付けた場合や、対話できないターミナル（CI など）で実行した場合は、ペアリングの確認は出ません。
</Accordion>

## プラグインの動作

プラグインはセッションを監視し、状態の変化をスマートフォンに報告します。エージェントが何に取り組んでいるか、いつ停止したか、いつ何かの許可を必要としているかです。

無料のペアリングでは、無料の機能に必要なものだけを送信します。[What leaves your computer](https://github.com/KarrixLee/nomo#what-leaves-your-computer) をご覧ください。

[スマートフォンをペアリング](/ja/setup/pairing)するまで、プラグインは何も送信しません。送信されるものはすべて、このマシン上で先に暗号化されます。

フックはプロジェクトのフォルダで動作しますが、そのプロジェクトの `bunfig.toml` や `.env` ファイルを読み込むことはありません。

プラグインは**オープンソース**です — インストール前に、何を収集し何を送信するかを正確に読むことができます。
