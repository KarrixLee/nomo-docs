## Reading it

A provider isn't one service. Claude alone reports on claude.ai, the Console,
the API, Claude Code, Cowork, and Claude for Government — and they go down
independently, which is why the list breaks them out rather than showing a
single verdict.

Each row carries a coloured dot for the state right now, a strip of recent
days, and the uptime percentage across them. One square per day: green is a
clean day, amber and red are days with trouble.

| Dot | State |
| --- | --- |
| 🟢 | **Operational** — nothing reported |
| 🟡 | **Degraded** — up, but slow or flaky |
| 🟠 | **Partial outage** — some of it is down |
| 🔴 | **Major outage** — it's down |
| ⚪ | **Maintenance** — planned work |

These come from each provider's own public status page, so Nomo says exactly
what the provider says. **Open status page** at the bottom takes you to the
source.

## Outage notifications

Off until you turn them on. Once on, you're told when a service degrades or
goes down — and again when it recovers, which you can switch off separately if
you only want the bad news.

You pick which services count. Every one starts enabled, and it's worth
trimming to the ones you actually use.
